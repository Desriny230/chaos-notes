THE QUESTION · 本章要回答什么

不解方程，能知道结局吗？

第 1 章已经付过账了：三体没有解析解，摆也没有。可我们还是想知道它会怎样。这一章把问题缩到最小——状态只有一个实数 x，方程只有一个 ẋ = f(x)——看看在这么小的世界里，"预测"能不能不靠计算。

三个问题，只靠 f 的形状回答

① 它会停在哪儿？找 f(x*) = 0 的点。
② 停下之后，被推一把还回得来吗？看该点的斜率。
③ 从这儿出发，多久到那儿？看 |f| 的大小，或者看势能落差。

但每一个答案都有边界

有些 f 连「从初值出发只有一条命运」都保证不了；
有些解活不到你以为的那个时刻；
有些不动点，一阶导数给出的答案干脆是空的。

这三个"但是"就是本章后半程的主角。读完你该能拿到一样东西：看见方程就能画出相图，看见相图就能说出命运——不用求积分。

§2.0 引言
§2.1 · 几何的思维方式

把方程画成一条线

一维流（flow on the line）的定义是一句话：状态是一个实数 x(t)，它的变化率只依赖它自己，不显含时间，也不依赖别的东西。

ẋ = f(x)

别把它当方程看，当图看。画出 y = f(x) 的曲线，再把 x 轴想成一条河：f(x) > 0 的河段向右流，< 0 的河段向左流，|f(x)| 只决定流得多快。

于是"解一条曲线"变成了"看一条线的高低"。你不需要积分，也能说出每条初值的去向——这是本书全部方法的原型。

上：f(x) = x − x³ 的曲线。下：同一条数轴上的流向箭头，长度正比于 |f|。填实的点是"汇"，空心点是"源"。
§2.1 几何的思维方式
HOW TO READ · 读图三件事

三个动作，读完一张相图

一、找零点。f(x*) = 0 处画一个点，那叫不动点（fixed point），也叫平衡点、定态。系统停在那里就不动了，而且"停住"是方程本身允许的，不是近似。

二、看符号。相邻两个零点之间 f 的符号不变（否则中间还有零点），所以每一段只有一种流向。x(t) 在段内严格单调：要么一直增，要么一直减，绝不回头。

三、看斜率。零点处斜率为负 → 两侧都往这儿汇；为正 → 两侧都往外推；恰为零 → 一阶信息用完了，得换法子（§2.4 末尾专讲）。

一维流里没有"绕一圈回来"这回事：零点把线切成几段，每段只有一条出路——所以一维系统只会停住，或者跑掉，不会振荡。证明在 §2.6。要振荡，至少需要两个维度：一个存位移，一个存速度（第 6 章）。
§2.1 几何的思维方式
§2.2 · 不动点与稳定性

稳定，是一个带邻域的承诺

"稳定"这两个字最容易被说糊。它不是"看起来不动"，而是两句可以逐字检查的承诺。

稳定（Lyapunov stable，李雅普诺夫稳定）

对任意容差 ε > 0，都存在 δ > 0，使得只要 |x₀ − x*| < δ，就有 |x(t) − x*| < ε 对所有 t > 0 成立。
翻译：起步够近，就永远不会走远。

渐近稳定（asymptotically stable）

它是稳定的，并且存在一个邻域，里面任何初值都满足 x(t) → x*（t → ∞）。
翻译：不但不跑，还真的靠过去。

注意："稳定"不等于"吸引"。这两个性质要到二维以上的非线性系统里才会分家（第 6、7 章的例子）；在线性系统里它们恰好等价，第 5 章会证明这一点。但在本章的条件下它们重合：若 f 连续可微、且 x* 是孤立不动点，则"吸引"与"渐近稳定"是一回事。这句"孤立"不能省——ẋ = 0 那条线上就没有一个孤立点。

另外记住"吸引子"（attractor）这个词的用法：它指一个系统最终住进去的集合。一维流里只有点这一种吸引子；闭轨、奇怪吸引子要等到有第二个维度。

§2.2 不动点与稳定性
ẋ = x² 的 f 与流向。零点只有一个，但两侧箭头朝同一个方向：左边被推进来，右边被推出去。原书用半实心点画这种不动点。
§2.2 · 三种命运

第三种不动点，一半谷底一半山顶

稳定与不稳定各占一头，中间还夹着一种：一侧吸进来、另一侧推出去。它叫半稳定（half-stable）。

例子：ẋ = x²。零点只有 x* = 0。可是 x < 0 时 ẋ > 0——向右，回到 0；x > 0 时 ẋ > 0——还是向右，离开 0。同样是"向右"，一个是回家，一个是离家。

所以判稳时不能只问"有没有被吸进来"，必须两侧都问。

还有一种退化情形：ẋ = 0。整条数轴都是不动点，没有一个能叫孤立。这时"稳定/不稳定"这套词汇整体失效——扰动既不被放大也不被压回，它就停在原地。

这三种"怪点"在下一节会有一个共同的名字：f′(x*) = 0。它们也是第 3 章分岔的前夜：在那一点上，零点成双成对地生灭。

§2.3 · 种群增长

先让增长自己踩刹车

最朴素的假设是无限增长：ẋ = rx，r > 0 是增长率。解是 x(t) = x₀ert，指数爆炸。这个模型只在种群还很小的那段时间里对。

为什么？食物、空间、天敌都是有限的。让"人均增长率"随密度下降，是最省事的修正：把常数 r 换成一个随 x 递减的量。取最简的线性递减——人均增长率 = r(1 − x/K)：

ẋ = rx(1 − x/K)

这就是逻辑斯谛方程（logistic equation）。两个参数各管一件事：r 管快慢，量纲 1/时间；K 管终点，量纲"个体数"，叫环境容量（carrying capacity）。

先手算一遍：x = 0 与 x = K 是不动点；0 < x < K 时 ẋ > 0，单调增；x > K 时 ẋ < 0，退回来。所以 K 两侧都汇入（渐近稳定），而 x = 0 两侧都逃离（不稳定）——只是 x < 0 那半没有生物学意义。f′(0) = r > 0，正正说明了这一点。

这个模型踩了四块地砖：无年龄结构、无时滞、环境不变、个体彼此独立（只通过总数耦合）。后面几章会一块一块地把它们抽走——每抽一块，行为就变一次。

§2.3 种群增长
§2.3 · 丢掉单位

三个参数太多，一个就够

令 u = x/K（状态换成"占容量的比例"），τ = rt（时间以 1/r 为单位，也就是一个 e-folding 时间）。代进去：

dx/dt = rK·du/dτ ， 右边 = r(Ku)(1 − u) = rK·u(1 − u)

两边同除 rK，得

du/dτ = u(1 − u)

两个参数全没了。这不是变魔术，它说明：所有逻辑斯谛系统其实是同一个系统，只是尺子不同。

这叫无量纲化（nondimensionalization）。好处三层：公式更短；数值更稳（各量都在 1 附近，浮点不丢精度）；结论更普适（K = 10³ 的鱼群和 K = 10⁶ 的细菌共用一条曲线）。

代价也要记账：还原的时候必须乘回去。你算出的"1 个时间单位"到底是 1 小时还是 1 天，完全取决于 r；而 r 的值只有具体系统知道。无量纲化能去掉参数，不能去掉物理。

本章后面统一用 du/dτ = u(1 − u)，只是把符号写回 x、t 省事。

§2.3 种群增长
§2.3 · 解长什么样

每一族初值，都汇到同一条地平线

逻辑斯谛是可以解出来的。分离变量 dx/[x(1 − x)] = dt，用部分分式拆开积分，再解出 x：

x(t) = 1 / [ 1 + (1/x₀ − 1)e−t ]

三个自检：① t = 0 时右边等于 x₀ ✓；② t → ∞ 时 → 1，与初值多小无关 ✓；③ 把 K、r 放回去，终点回到 K ✓。

图里五条曲线，初值从 0.02 到 2.5，在 x = 1 处全部压平。注意 0.02 那条：前两个时间单位只从 0.02 爬到 0.13，之后才起飞；到 t = 5 时到 0.75。不是它慢，是它离阈值太近——这也是"小种群容易灭绝"的数学根源：随机扰动一来，它就掉到 0 上再也起不来。

所以逻辑斯谛那句"只要 x₀ > 0 就一定能长到 K"，条件是个体数足够大、且模型里没有随机项。去掉任何一个，结论就变。

逻辑斯谛的一族解，r = 1、K = 1。虚线是环境容量 K。从下方逼近时先快后慢，从上方落下时则一路单调下压。
§2.3 种群增长
§2.3 · 加一只手进去

每年捞走固定的量，会捞出什么

让模型多一项：ẋ = x(1 − x) − h，h 是每单位时间固定捞走的量（已经无量纲化）。现在不动点要解二次方程：

x² − x + h = 0 ⟹ x* = [1 ± √(1 − 4h)] / 2

判别式一出现，故事就分成三段。判据是 h 与 1/4 的比较，而 1/4 正是 x(1 − x) 的最大值：

h < 1/4

两个不动点：大的那个稳定（可持续产量），小的那个不稳定（阈值）。种群掉到阈值以下，就再也回不到大的那个——同样的方程，两种终局。

h = 1/4

两个零点合成一个：x* = 1/2，半稳定。这是临界时刻，收割量正好等于种群的最大自我补充速率。

h > 1/4

没有不动点。ẋ 处处为负，种群必然崩溃。能不能收，取决于 h 是否超过系统自身的再生能力，这件事与初始种群多大无关。

这就是第 3 章"鞍结分岔"（saddle-node bifurcation）的原型：参数越过临界值，两个不动点相撞、一起消失。这里先记住形状，第 3 章给它正式名字。

§2.4 · 线性稳定性分析

只在小范围内，把曲线拉直

有一只更快的办法判稳，不必每次都画图。设 x* 是零点，把状态写成 x = x* + η，其中 η 是"离开平衡点多少"，很小。泰勒展开到一阶：

f(x* + η) = f(x*) + η f′(x*) + O(η²) = η f′(x*) + O(η²)

代回方程，并把 η̇ = ẋ 用上：η̇ = f′(x*)η + O(η²)。丢掉高阶项，得到线性化方程：

η̇ = λη ， λ = f′(x*)

它只有指数解 η(t) = η₀eλt。于是判据成了三个字：

λ < 0 → 稳定

扰动单调压回 0。f 在该点斜率为负：谷底。

λ > 0 → 不稳定

扰动指数放大。f 斜率为正：山顶。

λ = 0 → 判据失效

线性项消失，答案在更高阶项里。下一页专讲。

"只看一阶"之所以合法，靠的是连续可微：f′ 在 x* 附近连续，高阶项比 η 更快趋于 0，不会在 η 很小时翻盘。（二维里这条升格成 Hartman–Grobman 定理，第 6 章。）

λ 还有一个物理读法：1/|λ| 是特征时间。λ = −4 意味着误差每 0.25 个时间单位衰减到 1/e（1/|λ| = 0.25）。所以"稳定"是定性的，"多久稳下来"要另外报数。

§2.4 线性稳定性分析
§2.4 · 当 λ = 0

斜率是零，判据说不出话

λ = 0 说明线性项不存在，命运由第一个非零的高阶项决定。原书例题 2.4.3 用四个例子（图 2.4.1），正好把一阶判据的三处死角都占了：

(a) ẋ = −x³ → 稳定，但慢

x > 0 时 ẋ < 0，x < 0 时 ẋ > 0，两侧都回来。收敛是代数式的（x ~ t−1/2），不是指数式：同样靠近，指数式有个"永远到不了"的尾巴，代数式慢得多，但没有时间尺度。

(b) ẋ = x³ → 不稳定

两侧都被推走，而且越推越快（幂律爆破，同样会在有限时间内跑到无穷）。

(c) ẋ = x² → 半稳定

一侧进、一侧出。上一页的图讲的就是它。

(d) ẋ = 0 → 整条线都是不动点

每个点都不孤立。稳定性、吸引性这类定点词汇全部失效：扰动停在原地，既不放大也不衰减。

f′(x*) = 0 时，出错的不是判据，是"一阶信息"本身不够用。此刻必须回到 f 的符号，或者去看高阶导数。这条教训在后面每一章都会重演：判据失效的地方，正是新现象出现的地方（第 3 章的分岔全部发生在 λ = 0）。
§2.4 线性稳定性分析
PROOF 01 · 完整推导

f′(x*) < 0 为什么真的能保证稳定

完整推导要证的事 + 四步 + 边界

要证．设 f 连续可微，f(x*) = 0，λ = f′(x*) < 0。则存在 δ > 0，使得 |η₀| < δ 时，解 η(t) → 0（t → ∞），而且是指数式地趋于 0。

0出发点．方程是 η̇ = f(x*+η)，记 F(η) = f(x*+η)，则 F(0) = 0、F′(0) = λ。

1取一个严格负的上界．因 F′ 在 0 处连续且 F′(0) = λ < 0，取 a > 0 使 |η| ≤ a 时 F′(η) ≤ λ/2。合法，因为连续性能保证邻域内的值离 λ 任意近，而 λ 与 0 之间有空隙，λ/2 就落在这个空隙里。

2正半轨出不去，而且是指数地出不去．设 0 < η₀ < a。只要 η 还在 (0, a) 内，中值定理给出 η̇ = F(η) = F′(ξ)η ≤ (λ/2)η < 0，所以 η 严格递减。再把两边除以 η > 0：d(ln η)/dt = η̇/η ≤ λ/2，积分得 η(t) ≤ η₀e(λ/2)t。这个不等式顺带证明了η 永远碰不到 0：若在某个有限时刻 T 首次相碰，则 t → T⁻ 时 ln η → −∞，与 ln η(t) ≤ ln η₀ + (λ/2)T（有限）矛盾。于是整条半轨都留在 (0, a)。η₀ < 0 时对 −η 用同一论证（方程关于 η → −η 不必对称，但 η̇ = F′(ξ)η 中 η < 0、F′ ≤ λ/2 < 0，故 η̇ > 0，η 递增且趋近 0）。

3极限只能是 0．η 单调有界，故极限 ℓ 存在。若 ℓ > 0，则 η̇ ≤ (λ/2)ℓ < 0 恒成立，η 会一直往下掉，矛盾。故 ℓ = 0。

4速率．第 2 步已经给出一致上界 η(t) ≤ η₀e(λ/2)t：至少以 2/|λ| 为特征时间指数衰减（真实速率是 1/|λ|，见下面的退化自检）。

退化自检．取线性情形 f = λx，严格解是 η₀eλt；上面的上界给出 e(λ/2)t，同一个结论、常数更保守（2/|λ| ≥ 1/|λ|）。再退化到 λ → 0⁻，"严格负上界"取不到，第 1 步直接崩——这正是判据失效的机理。

失效边界．① f 必须连续可微，尖点处（ẋ = |x|）不适用；② 结论是局部的，δ 可能极小，吸引域之外照样跑掉；③ λ = 0 无话可说，要换高阶项或符号法；④ 证明只用了一侧不等式，反方向（λ > 0 ⇒ 不稳定）把时间倒着走一遍即得。

§2.4 线性稳定性分析
§2.5 · 存在性与唯一性

先问一句：解真的存在吗？

到这里为止，我们一直默认一件事：从某个初值出发，有一条确定的轨迹。这个默认需要一张许可证。原书的态度很诚实——前面几节对向量场的处理相当不正式。

定理（局部存在唯一性）

若 f(x) 连续且满足李普希茨条件（Lipschitz condition）——存在常数 L，使任意 x、y 都有 |f(x) − f(y)| ≤ L|x − y|——则对任意初值 x(0) = x₀，存在一个时间区间 (−τ, τ) 上唯一的解。

f 连续可微就足够：中值定理给出 |f(x) − f(y)| = |f′(ξ)|·|x − y|，取 L = max|f′| 即可。李普希茨比"连续"强，比"可微"弱——中间那条缝里就藏着反例。

注意定理只说"局部"：τ 可能很小，甚至解会在有限时间内跑到无穷。所以它保证的是短时间内的确定性，不是"永远有定义"。

这条定理最值钱的翻译是几何的：向量场不交叉。两条轨迹若在某一时刻相遇，此后必须完全重合。第 1 章推导 1 里那句"相轨迹不相交"，正式依据就在这儿。

§2.5 存在性与唯一性
三条曲线都过 (0, 0)，都满足 ẋ = √x。金点是初值。非唯一性只发生在 f 不可微的那一点上；只要 x₀ > 0，解就唯一。
§2.5 · 唯一性会失手

一个初值，三条未来

方程 ẋ = √x，初值 x(0) = 0。李普希茨条件在这里失效：f′(x) = 1/(2√x) 在 0 处发散，L 取不到。

于是唯一性真的坏了。至少有三条解：

① x ≡ 0：一直不动。
② x = t²/4（t ≥ 0）。
③ 任意 t₀ ≥ 0 的拼接：先 x = 0 待够 t₀，再沿 x = (t − t₀)²/4 走。

逐条验：d/dt(t²/4) = t/2，而 √x = √(t²/4) = t/2 ✓。所以它确实满足方程。

物理含义：在 x = 0 这个点上，推动力是零，但它离开零的"恢复陡度"是无穷大，于是系统可以在那里待任意久再出发。凡是模型里出现 √、x1/3、"接触即粘住"的地方，都要留这个心眼。

§2.5 存在性与唯一性
§2.5 · 解可以"活不到"未来

有限时间爆破：不是算错，是模型越界

方程 ẋ = 1 + x²，x(0) = 0。分离变量：dx/(1 + x²) = dt，积分得 arctan x = t，于是

x(t) = tan t ， t ∈ (−π/2, π/2)

解存在、唯一、光滑——只是它的定义域只有这么长。它在 t = π/2 之前跑向无穷，那个时刻到不了。

判别办法：看 ∫ dx/f(x) 是否收敛。∫₀X dx/(1 + x²) = arctan X → π/2，收敛，所以"跑到无穷"只需要有限的时间。反之，若 f 在远处的增长不超过线性，积分发散，解就活得下去。

逻辑斯谛为什么不会爆破？因为在 x > K 时 f 已经变负，负反馈自己把自己拽住了。这就是饱和项的价值。

教训：数值积分里的"发散"不一定是代码错，可能是模型真的在这一刻失去了意义。判断依据是模型假设，不是程序。

蓝线是精确解 tan t，虚线是它永远到不了的 π/2。橙色折线是步长 h = 0.3 的欧拉法：它照样越过去，但越过的位置和斜率都不对——数值方法不会告诉你模型已经越界。
§2.5 存在性与唯一性
§2.6 · 振动的不可能性

一维流不能振荡，一个单调性就够了

第 1 章的演示里说过一句"一维永远振荡不起来"（第 1 章只给了直观）。这里给证明——它比想象中短。

反证。设存在非恒定的周期解，周期 T > 0，取值落在 [m, M] 上，且 m < M。

1在取到最大值 M 的时刻 t₁ 上，ẋ(t₁) = 0，即 f(M) = 0；同理 f(m) = 0。两个极值点都是不动点。

2把 f 在 [m, M] 上的零点按大小排开。相邻两个零点之间 f 的符号不变，所以在每一小段内部 x(t) 严格单调：要么一直增，要么一直减。又因为零点本身是不动点，轨线不能穿过它（§2.5 的唯一性：穿过就意味着同一点上有两条轨线），所以周期解只能整段住在某两个相邻零点之间。

3可它必须离开某个点再回到它，也就是必须在所住的那一段里折返——与"段内严格单调"矛盾。若它整段停在一个零点上，那它就是恒定的，同样被排除。

所以：一维自治流的解要么趋于不动点，要么跑向无穷，没有第三条路。而且趋于不动点是单调的——它会越来越近，不会冲过目标再荡回来（不超调，zero overshoot）。这一条正是原书在本节强调的：没有超调，就没有振动；「未受迫时不可能自振」正是它的推论。旋转与振荡都需要一个环——圆周上的流（第 4 章）或者相平面上的闭轨（第 6、7 章）。

前提不能省：自治（f 不显含 t）。缺了它反例随手可得：ẋ = cos t 也是一维方程，解 x = sin t 照样周期振荡——真实世界的"一维振动"几乎都是这样骗人的，它在方程里偷偷藏了时间。连续则是第 2 步"符号不变"的技术前提：不连续时零点可能有无穷多个，区间根本切不开。

§2.6 振动的不可能性
§2.7 · 势

给这条线配一个地形

如果能找到一个函数 V(x)，使 f(x) = −dV/dx，那么方程就能改写成一句话：

ẋ = −V′(x) ， V(x) = −∫ f(s) ds

V 叫势（potential，也叫势能）。一维之下它总能找到：取个积分下限积出来就是。二维以上一般不行——那是"保守系统"才有的运气（第 6 章）。

于是方程变成一句直觉：速度正比于负的坡度。系统像一颗滚下山的球，而且是过阻尼地滚——没有惯性，不会冲过谷底，不会来回晃。

从图上直接读：V 的谷底 = 稳定不动点；V 的山顶 = 不稳定不动点；V 的一整段平地 = ẋ = 0 的那段不动点。f 的零点就是 V 的极值点——同一个事实的两种画法。

上：f(x) = x − x³。下：它的原函数 V(x) = x⁴/4 − x²/2。虚线对齐的是同一个 x：f 的零点 ↔ V 的极值点。这叫双井（double well）。
§2.7 势
§2.7 · 类比的边界

"球滚下山"，这句话缺了一半

真实的球有质量：mẍ = −V′(x) − bẋ。它冲到谷底会越过去，于是来回振荡。描述它需要两个状态（位置与速度），属于第 6 章的活。

一维流是过阻尼极限：摩擦大到惯性可以忽略，mẍ 里的 m → 0，方程退化成 bẋ = −V′(x)，也就是 ẋ ∝ −V′。所以看到"势能"两个字，别自动加上振荡——那是质量给的，不是势给的。

类比成立的地方

· 谷底 = 稳定点，山顶 = 不稳定点
· 落差越大，走得越快（速度 ∝ 坡度）
· 到了谷底就停住（没有惯性就不会超调）
· 势能只会减少：V̇ = V′ẋ = −(f)² ≤ 0

类比失真、必须警惕的地方

· "势能的绝对值"没有意义，只有差有意义（V 可以任意加常数）
· 真实小球会振荡，一维流不会；把两者混为一谈，就会误判成"有周期解"
· 双井之间隔着山顶：确定性地永远翻不过去，除非加噪声。而真实系统里，这个"除非"常常是全部内容的来源

顺带回收 §2.6：V 单调下降，就没有一次回到原位的可能，因此没有周期解。同一个事实的两种说法。

§2.8 · 利用计算机解方程

把连续的时间切成格子

一维流大多能解析求解，但二维以上基本不行，所以数值积分是通用工具。最朴素的想法：用差商代替导数，把时间切成 tn = nh。

前向欧拉法（forward Euler）

xn+1 = xn + h f(xn)

几何上：站在 xn，顺着当地的斜率直线走一步。只问一次斜率，误差会一路累积。

四阶龙格–库塔（RK4）

k₁ = f(xn)，k₂ = f(xn + hk₁/2)，
k₃ = f(xn + hk₂/2)，k₄ = f(xn + hk₃)

一步之内问四次斜率，再按 1 : 2 : 2 : 1 加权：xn+1 = xn + (h/6)(k₁ + 2k₂ + 2k₃ + k₄)。

为什么权重恰好是 1、2、2、1？下一页末尾的推导会给你答案：它来自泰勒展开的系数匹配。

先记住差别：同一个方程、同一个终点，步长减半时，欧拉的误差大约减半，RK4 的误差降到十六分之一。这就是"四阶"两个字的全部含义。

还有一个与精度无关的危险：稳定性。欧拉法解 ẋ = −100x 时，必须 h < 0.02 才不发散，否则迭代 xn+1 = (1 − 100h)xn 的系数绝对值超过 1，误差被放大而不是压回。RK4 的门槛宽一些（λh > −2.79），但同样存在。

§2.8 利用计算机解方程
靶子取 ẋ = x − x³（它有解析解，真值可算），终点固定 T = 4。横轴是步长，纵轴是终点误差，双对数。白虚线是斜率 1 与 4 的参考线；左下的平台是机器精度地板。
§2.8 · 误差怎么报

双对数图上，斜率就是阶数

拿 ẋ = x − x³ 当靶子。它可解：x(t) = 1/√(1 + c e−2t)，c = 1/x₀² − 1。所以"真值"是现成的。

固定终点 T = 4，让步长从 1/2 一路减到 1/2048，量终点误差，画在双对数图上。

直线斜率就是阶数：欧拉 ≈ 1（一阶），RK4 ≈ 4（四阶）。步长缩小 10 倍，欧拉误差也缩 10 倍，RK4 缩 10000 倍。

三个实操结论：

① 试水用欧拉，出图用 RK4；
② 左下角变平说明撞到机器精度了，再减步长纯属浪费；
③ 步长不能凭感觉放大——先过稳定性这一关，再谈精度。

条件：以上"阶数"是渐近结论，要求解足够光滑、步长足够小、问题不刚性。刚性方程（快慢时间尺度差很多）需要隐式方法，那超出本章范围。

§2.8 利用计算机解方程
PROOF 02 · 完整推导

RK4 的 1、2、2、1 是从哪儿来的

完整推导线性靶子上的逐步展开 + 一般情形的结论 + 边界

出发点．先在最好算的靶子上把账算清：ẋ = λx，真解 x(t) = x₀eλt。记 z = hλ。数值方法走一步都可以写成 xn+1 = R(z)xn，R 叫稳定函数。用它来衡量"一步走了多远"。

欧拉．RE(z) = 1 + z。而 ez = 1 + z + z²/2 + …。所以一步的偏差是 O(z²) = O(h²)；走 N = T/h 步累积，全局误差 O(h)。一阶。

1把四个斜率算出来．
k₁ = λx
k₂ = λ(x + hk₁/2) = λx(1 + z/2)
k₃ = λ(x + hk₂/2) = λx(1 + z/2 + z²/4)
k₄ = λ(x + hk₃) = λx(1 + z + z²/2 + z³/4)

2加权求和．k₁ + 2k₂ + 2k₃ + k₄ = λx[6 + 3z + z² + z³/4]。除以 6 再乘 h，得到

R(z) = 1 + z + z²/2 + z³/6 + z⁴/24

3对表．ez 的泰勒级数是 1 + z + z²/2! + z³/3! + z⁴/4! + …。逐项比较：前五项完全一致，直到 z⁵/120 才分家。所以一步误差 O(h⁵)，全局误差 O(h⁴)。四阶的意思就是：它把指数函数模仿到了第 4 项。

一般情形．对非线性的 f，把 x(t+h) 按链式法则展开（ẍ = f′f，x⁽³⁾ = f″f² + f′²f …），再把 k₁…k₄ 各自展开，逐项比系数。四个斜率取在 h/2 处、权重取 1:2:2:1，正好让 h、h²、h³ 的系数全部对上——这就是那组数字的来历。

退化自检．取 λ = 0（f ≡ 0）：R(0) = 1，一步之后原地不动，与真解一致 ✓。取 z → 0：任意阶方法都必须退化成"停在原地"，同样满足。

失效边界．① 阶数是渐近结论：h 不够小时，实测斜率会偏离 4；② |R(z)| ≤ 1 才不发散，实轴上要求 z ∈ (−2.79, 0)（欧拉是 (−2, 0)）；③ 真解有奇点（§2.5 的爆破）时，任何阶都救不了表；④ 刚性问题上显式 RK4 会被稳定性而不是精度卡死。

§2.8 利用计算机解方程
CASE · 原书 §2.6 的落地实验

案例 · 一维流在实验室里长什么样

做一个真实的、位置决定力的装置：把滑块放进黏稠液体里，接一根弹簧，或者干脆让重力沿一根弯轨道拉它。牛顿第二定律给出

mẍ + bẋ = F(x) ⟹ (m/b)ẍ + ẋ = F(x)/b

关键的比值是 m/b：它有一个时间的量纲，正好是"速度追得上力"的弛豫时间。把它与实验的观测时间尺度一比：

蜂蜜里的滑块：m/b 很小

惯性项可以丢掉，方程退化成 ẋ = F(x)/b——一个标准的一维流。放手之后，滑块单调地滑向最近的谷底，一次也不越过。

水里的滑块：m/b 不小

惯性项活着，滑块冲过谷底再荡回来。此时它是二维系统（位置 + 速度），不归本章管——见第 6 章。

为什么值得当真做个实验？因为这个装置能用两种方式证伪一维流的两个预言：

① 没有振荡：无论从哪儿松手，轨迹都不会超调。看到超调，说明惯性项不可忽略，你的"一维"假设错了。
② 没有来回：轨迹不会先向右再向左。看到折返，说明 F 显含时间（手在动）或者有第二个自由度。

同一个道理也出现在工程里：指针式仪表（电流计）的过阻尼档就是这么设计的——宁可慢慢爬，也不要来回摆。它的设计方程正是 ẋ = F(x)/b，而临界阻尼附近的行为要用二阶理论算，那是第 5、6 章的事。

三条结论、两把错尺、一个工具

结论一：f 的零点就是全部可能的终点；零点之间只有一种流向，所以一维流的命运是单调的——去某个点，或者跑向无穷。

结论二：稳定与否看 λ = f′(x*) 的符号；λ = 0 时判据失效，必须回到符号法或高阶项。这不是判据不严谨，是一阶信息不够。

结论三：势 V = −∫f 让"往下走"这件事变成地形问题；V 单调下降，因此一维自治流不可能有非平凡周期解。
