§8.0 引言 · 从「有没有环」到「环怎么来」

这一章要做的三件事

第 7 章我们只问静态问题：这个系统有没有极限环？这一章把参数当成旋钮，问三个动态问题：

① 振荡是怎么开始的？

第 3 章的分岔都要求「不动点撞上另一个不动点」。可有些系统里不动点孤零零的，参数一动它就自己失稳，然后长出一条环——这就是霍普夫分岔（§8.2）。

② 环会怎么死？

有的死法是「两条环相撞湮灭」，有的是「环撞上一座鞍点」——周期被拖到无穷大。这类叫全局分岔，它们在局部线性化里完全看不见（§8.4）。

③ 怎么把流的问题变成映射的问题？

受迫系统不是自治的，相图从二维变成三维、四维。办法是每转一圈打一个点——庞加莱映射把连续流压成一张离散映射，维数掉一维（§8.7）。

先记住这条主线

本章所有现象都能用一句话概括：系统的某个吸引子失去稳定性，把轨道让给了新的吸引子。分岔就是「换岗」的那一瞬间。

读法建议：§8.1 是复习（第 3 章的内容，一分钟扫过）；§8.2 与 §8.4 是本章的重心；§8.6–§8.7 为第 9 章的混沌做准备。

§8.0 引言
三张分岔图都是数值采样画的，横轴是参数 μ，纵轴是平衡点位置 x*。蓝实线＝稳定支，橙虚线＝不稳定支。鞍结：μ−x²；跨临界：μx−x²；叉式：μx−x³。
§8.1 · 鞍-结、跨临界、叉式

三张图，一条共同点

鞍结分岔：ẋ = μ − x²。μ 过零时凭空生出一对不动点（一稳一不稳），然后一起离开。跨临界：ẋ = μx − x²。两个不动点迎面相撞，交换稳定性后各自继续走。叉式：ẋ = μx − x³。一个不动点自己失稳，同时生出一对对称的新不动点。

三者的共同点：都是零特征值分岔。在分岔点上线性化给出 f′ = 0，线性化彻底失效，必须看非线性项才能判断稳定性。

而且它们都涉及两个或更多不动点的碰撞（叉式可以看成把鞍结的一支对折过去）。这就逼出一个问题：如果系统里只有一个不动点，它孤零零的，还能失去稳定性吗？

§8.1 鞍-结分岔、跨临界分岔与叉式分岔
§8.1 · 一个统一视角

分岔只有两种走法：穿原点，或穿虚轴

不动点稳不稳，只看雅可比矩阵的特征值在复平面哪一半。要让稳定性发生改变，特征值必须穿过虚轴。二维只有两种穿法：

穿原点：λ = 0

一个实特征值从负变正。这就是第 3 章的三种基本分岔：鞍结、跨临界、叉式。它们的标志是行列式为零（det A = 0）。

穿虚轴：λ = ±iω

一对复共轭特征值从左侧穿到右侧，实部过零而虚部不为零。标志是迹为零（tr A = 0）而 det A > 0。这就是霍普夫分岔。

为什么这个区分重要？因为穿原点时不动点旁边一定还有别的不动点来「接盘」，而穿虚轴时不需要谁来接盘：不动点还在那儿，只是从吸引变成排斥，把轨道推向一条新生的闭轨。

穿原点 → 不动点互相让位；穿虚轴 → 不动点把位子让给一条环。—— 两种分岔的几何差别

提醒：λ = 0 时也可能发生「鞍结分岔」的高维版本（两个不动点相撞），而 λ = ±iω 时也可能什么都不发生（虚部为零的退化情形）。判据必须落在特征值上，不能只看某一个系数是否为零。

§8.1 鞍-结分岔、跨临界分岔与叉式分岔
§8.2 · 霍普夫（Hopf）分岔

不动点不用撞到谁，就能交出稳定性

画面很直白：给一个稳定焦点加一点「负阻尼」，让振幅的衰减率随参数变慢、变零、再变成增长。于是螺旋不再往里收，而是向外张开，最后贴到一条环上——中间没有任何东西撞上来。

原书的标准示例（§8.2）就是这件事的最小模型：

ṙ = μr − r³，　θ̇ = ω + b r²

三个参数各有分工：μ 管原点的稳定性；ω 是小振动的角频率；b 管「频率随振幅怎么变」。μ < 0 时原点稳定；μ > 0 时原点失稳，同时在 r = √μ 处出现一条稳定圆环。

注意 μ = 0 这一点的特殊性：线性化给出纯虚特征值，预测「中心」，但真正发生的是缓慢的衰减（三次项把轨道往里拉）。线性化在分岔点上一律失效，这次也一样。

左：分岔图，μ < 0 只有稳定原点（蓝），μ > 0 原点失稳（橙虚线）而环半径按 √μ 长出来。右侧三幅是数值积分的相图（初始条件相同，只换 μ）：螺旋从收拢变成贴环。
§8.2 霍普夫分岔
§8.2 · 判据

三个条件，缺一条就不是霍普夫

设二维系统 ẋ = f(x, μ) 在 μ = μc 处有不动点 x*，雅可比矩阵 A(μ) 的特征值为 λ(μ) 与 λ̄(μ)。

条件一（存在）：特征值纯虚

λ(μc) = ±iω，且 ω ≠ 0。等价地：tr A = 0 且 det A > 0。

条件二（穿越）：实部确实在变号

d(Re λ)/dμ |μc ≠ 0。保证特征值横穿虚轴，而不是沿着虚轴滑过去。二维里 Re λ = tr A/2，所以这条就是「迹在 μc 处以非零斜率过零」。

条件三（类型）：第一李雅普诺夫系数 a ≠ 0

把系统化到标准形 ṙ = μr + a r³ + …，三次项系数 a 就是第一李雅普诺夫系数。a < 0 → 三次项把轨道往里拉 → 环存在于 μ > 0 一侧，超临界；a > 0 → 环被推到 μ < 0 一侧，亚临界。a = 0 是退化情形，要高阶项才能定案。

两句话记住条件一、二的作用：条件一说「这一刻频率是纯的」，条件二说「它真的在穿过去」。少了条件二，一个参数走到虚轴上又退回来，什么都不会发生。

边界：条件三的 a 要用二阶、三阶导数算（一般系统的公式很长，原书没有展开，实际计算交给符号软件）。所以「判霍普夫是否存在」容易，「判它超临界还是亚临界」要靠算 a 或靠数值。

§8.2 霍普夫分岔
§8.2 · 经验法则

分岔点附近，两件事可以照抄

法则一：环的大小从零长出，按 √(μ − μc) 长大。所以在分岔点附近，振幅对参数极其敏感：μ − μc 只有 1%，振幅已经有 10%。这也是实验上「刚过阈值时振幅很难测准」的原因。

法则二：在 μ = μc 处，环的频率就是 Im λ，周期 T = 2π/Im λ（误差 O(μ − μc)）。离开分岔点后频率会漂：平均地说，振幅变大时频率按 ω + b r² 变，这就是标准形里 b 的作用。

数值核验（本章脚本）

ω=1, b=0.8　实测 vs 公式

μ=0.10　r=0.3162 / √μ=0.3162
　　　　T=5.8180 / 5.8178

μ=0.30　r=0.5477 / 0.5477
　　　　T=5.0680 / 5.0671

μ=0.80　r=0.8944 / 0.8944
　　　　T=3.8320 / 3.8312

半径一栏精确到小数点后四位完全一致（√μ 是精确关系，不是近似）；周期一栏的差异全部来自积分步长 dt = 0.002。

两条法则的边界：它们都是「μ 挨着 μc」时才成立。走远了，环会变椭圆、变歪，甚至变成松弛振荡那样的方框（第 7 章 §7.5）——那时 √μ 和 2π/Imλ 都不再管用。

§8.2 · 亚临界（subcritical）

把三次项反过来，就得到「危险」

原书的亚临界示例只改了一个符号，再加一项五次：

ṙ = μr + r³ − r⁵，　θ̇ = ω + b r²

三次项现在是正的，把轨道往外推。于是 μ < 0 时可以同时住着两个吸引子：稳定原点与一条大振幅稳定环，中间夹着一条虚线的不稳定环当「分水岭」。

把 μ 往上拧到 0：不动点失稳，但环早就存在了。所以系统的响应是跳变——从静止直接跳到有限振幅，中间没有任何「小振幅」的过渡。滞后就跟着来了：把 μ 拧回负值，大振幅振荡也不肯立刻停下，要一直撑到 μ = −1/4 两支环相撞才熄灭。

这就是原书说亚临界「在工程应用中总存在潜在危险性」的意思：它没有预警。超临界的振动是慢慢长大的，亚临界是一步跨过去。

§8.3 · 振荡化学反应

烧杯里的钟：BZ 反应

上世纪 50 年代，苏联化学家别洛乌索夫（B. Belousov）在柠檬酸–溴酸盐–铈盐体系里看到溶液颜色周期性地来回变；这套配方后来经扎鲍京斯基（A. Zhabotinsky）改进推广，于是以两人命名：BZ 反应。当年的结果不容易被接受，最常被引用的理由是「这违反热力学第二定律」。

颜色为什么能周期性变化？因为反应中间物的浓度在振荡：某种离子在两种价态之间来回切换，周期性积累、又周期性被消耗掉。在相空间里，这就是一条稳定极限环。

原书 §8.3 具体分析的是一类二氧化氯（ClO₂）的振荡反应模型：把机理写成几个浓度的方程，找不动点、算雅可比矩阵，看特征值什么时候穿过虚轴——§8.2 的霍普夫判据可以直接套上去。控制参数通常是某个进料浓度或温度。把参数慢慢调过去，振荡会突然开始（还常伴随跳变与滞后）。

一个当年被「不可能」挡回去的现象，后来成了非线性动力学的招牌案例。—— 别轻信「不可能」这三个字

边界：热力学第二定律说的是孤立系统的熵单调增，它禁止的是「整体趋于平衡」。BZ 反应是开放系统（持续进料、持续排废），在远离平衡的地方完全允许出现时间上的有序。这句话值得记住，因为后面所有「自组织」的讨论都靠它。

§8.3 振荡化学反应
§8.3 · 从化学到模型

为什么「振荡的化学」至少要三个变量

第 2 章说过：一维流不可能振荡。第 7 章的庞加莱–本迪克松定理又说：二维可以振荡，但二维里没有混沌。那 BZ 反应属于哪一种？

实际发生的振荡是周期性的，所以二维模型就够描述它的环。但它有几个麻烦：真正的机理里至少有七八种中间物；反应还在空间上不均匀（会出现彩色螺旋波）；某些条件下振荡会变成混沌。要做这些，就必须升高维数。

建模的通例（原书 §8.3 的做法）

把反应写成一组浓度方程 ċi = fi(c, μ)，然后找不动点、算雅可比、看特征值什么时候穿过虚轴。霍普夫分岔的条件可以直接套在化学方程上——这就是 §8.2 的判据最实用的地方。

一个必须带上的前提

浓度方程要么开放（有进料/出料项），要么至少三维。封闭系统最终必然趋于平衡（不动点），不可能长期振荡。所以「化学振荡」这个词本身就隐含了「这个系统不是孤立的」。

与其他章的分工：§4.5 的萤火虫、§8.6 的耦合振子讨论「一群振子怎么同步」；本节只讨论「单个反应器怎么自己荡起来」。两者合起来才是真正的化学/生物节律。

§8.4 · 环的全局分岔 · 鞍结

两条环相撞，一起消失

回到亚临界那个例子。把 ṙ = μr + r³ − r⁵ 的定点方程解出来：令 u = r²，得 u² − u − μ = 0，于是

u = [1 ± √(1 + 4μ)] / 2

判别式在 μ = −1/4 处为零：两支在这一点合并，r = √(1/2) ≈ 0.707。往更负的方向走，两条环就一起消失了。

这就是环的鞍结分岔：一条稳定环与一条不稳定环相撞、湮灭。它与不动点的鞍结分岔是同一个机制（u 的方程就是一条抛物线），只是发生在「环」这个层级上。

数值核对：脚本在 μ = −0.2 处解出外支 r = 0.8507、内支 r = 0.5257；代入 g′(r) = μ + 3u − 5u²（u = r²）得 −0.6472（稳定）与 +0.2472（不稳定）。到 μ = +0.3 只剩外支 r = 1.1143，导数为 −3.6832。符号与图上的虚实线一一对应。

为什么叫「全局」：这条分岔的发生位置取决于大范围的轨道形状，不能只看某一个不动点的线性化。你在原点附近做多少次线性化，都看不见它。

§8.4 环的全局分岔
§8.4 · 环的全局分岔 · 同宿

环撞上鞍点：周期被拖到无穷大

第二种死法更像一场事故：一条环越涨越大，最后碰到一座鞍点，然后沿着鞍点的稳定流形进去、再沿不稳定流形出来，闭轨被「咬断」成一条从鞍点出发又回到鞍点的轨道。

这种连接鞍点到自身的轨道叫同宿轨道（homoclinic orbit）。它出现的那一刻，环的周期会怎样？趋于无穷大——因为轨道越靠近鞍点，速度越小，在鞍点附近要磨蹭无限久才能离开。

怎么在数值上认出来

把参数一点点调，记录环的周期 T：如果 T 单调地涨、像是要发散（1/T 单调趋于 0，注意是同宿特有的对数发散 T ∼ ln(1/|μ−μc|)，不是幂次），同时环的形状贴向了某个不动点，那基本就是同宿分岔。

它为什么危险

同宿分岔之后，吸引子常常变成「一碰就跑很远」的东西（例如长周期环或混沌）。所以它常被当作「系统行为剧烈改变」的界线，而不只是一个技术细节。

与局部判据的关系：同宿分岔不能从雅可比矩阵看出来。鞍点在整个过程中一直是个鞍点，行不行，取决于轨道跑到哪里去撞它——这是全局信息。第 9 章的洛伦兹系统、第 12 章的受迫双井振子里都会反复遇到这类事件。

本章不给出同宿分岔的解析条件（一般系统里它需要数值求解鞍点流形的相交），只要求你认得它的特征：周期发散的环消亡。

§8.4 环的全局分岔
§8.5 · 两个「同一个方程」的系统

钟摆与超导结，写的是一行方程

给阻尼摆加一个周期性外力，方程是

ẍ + γẋ + sin x = F cos ωt

约瑟夫森结（两块超导体夹一层薄绝缘层）在电阻–电容并联模型下（RCSJ），相位差 φ 满足

(ħC/2e) φ̈ + (ħ/2eR) φ̇ + Ic sin φ = I

两式同构：φ ↔ x，偏置电流 I ↔ 外力，电容项 ↔ 惯量。摆是机械版，结是超导版，同一个数学对象。测一个便宜的摆在台面上做的事，等于测一个贵的超导结。

滞后从哪来：驱动摆在不同振幅的「锁相」解之间可以有多于一个稳定答案。当外力慢慢加大和慢慢减小时，系统走的不是同一条路——上限与下限不重合，中间那块就是滞后环。约瑟夫森结的 I–V 曲线里的回滞（同一偏置电流对应两个电压）就是它的实验指纹。

机制上，滞后几乎总是亚临界分岔（§8.2）或双稳态的产物：分岔点附近有两个稳定吸引子并存，走哪条路取决于历史。所以「滞后」这个词本身就告诉你：现在这个状态记住了过去。

§8.5 驱动钟摆与约瑟夫森结滞后现象
§8.6 · 耦合振子与准周期性

两个频率，要么锁住，要么永远错开

两个振子各自有固有频率 ω₁、ω₂，互相耦合。只看相位（振幅已经稳在环上），最简单的一对模型是：

θ̇₁ = ω₁ + K sin(θ₂ − θ₁)
θ̇₂ = ω₂ + K sin(θ₁ − θ₂)

令 Δ = θ₂ − θ₁，两式相减：

Δ̇ = Δω − 2K sin Δ，　Δω = ω₂ − ω₁

这是一个圆周上的一维流（第 4 章的工具直接可用）。Δω 小时方程有稳定不动点 sin Δ* = Δω/2K：相位差停住，两个振子锁相（locked），整体只有一个频率。Δω 大时没有不动点，Δ 一路漂下去：两个频率共存、永不重复，运动是准周期的（quasiperiodic）。

分界就在 |Δω| = 2K：耦合越强，能锁住的频率差越大。

左：K = 0.6 时三条相位差曲线。蓝（Δω = −0.6）与金（Δω = 0.6）都停在同一水平线上 = 锁相；橙（Δω = 1.6 > 2K = 1.2）一路漂下去 = 准周期。右：数值打点落在两条直线 |Δω| = 2K 围出的带子里，带内锁相、带外不锁。

§8.7 · 庞加莱映射（Poincaré map）

每转一圈打一个点，维数掉一维

受迫系统不是自治的（右端显含 t），所以它的相空间其实是三维的：x、ẋ，再加上「驱动走到哪一相位」。三维里看不见图，怎么办？

每个驱动周期取一次样：t = 0, T, 2T, 3T, … 只看这些时刻的状态，得到一列点 x₀, x₁, x₂, …。这列点之间的规律就是一个映射 xn+1 = P(xn)，叫庞加莱映射（频闪映射）。

好处有三条：① 降一维——三维的流变成二维的点列，可以画在纸上；② 周期解变成不动点——环打一次点只落一处；③ 混沌变成点的堆积——点的分布能看出分形结构（第 11–12 章要用）。

代价：丢掉了两次采样之间的全部信息。所以映射只能回答「每圈看一次时系统怎么变」，不能回答「圈内是怎么走的」。这类技巧之所以总好用，是因为受迫系统的长期行为本来就由「圈与圈的对应」决定。

§8.7 庞加莱映射
PROOF 01 · 极坐标 → 直角坐标 → 雅可比 → 特征值

霍普夫标准形是怎么来的

完整推导ṙ = μr − r³ 的直角坐标形式、线性化与两条经验法则

出发点．标准形：ṙ = μr − r³，θ̇ = ω + b r²。

x = r cos θ，　y = r sin θ

1换成直角坐标．对 x 求导，把 ṙ、θ̇ 代进去（这就是第 7 章 §7.6 推平均法时用过的那套替换）：

ẋ = ṙ cos θ − r sin θ · θ̇ = (μr − r³)cos θ − r(ω + br²) sin θ

再用 cos θ = x/r、sin θ = y/r、r² = x² + y² 换回去：

ẋ = μx − ωy − (x² + y²)x − b(x² + y²)y = μx − ωy + 三次项

同理

ẏ = μy + ωx + 三次项

2线性化．在原点 (0,0) 处雅可比矩阵为

A = [[μ, −ω], [ω, μ]]

它的特征值是 λ = μ ± iω（迹 2μ，行列式 μ² + ω²）。这一步同时给出条件一与条件二：μ = 0 时 λ 是纯虚的；Re λ = μ 以斜率 1 穿过零。

3退化自检．令 r³ 项消失（只看线性部分）：ẋ = μx − ωy，这是线性阻尼振子，μ < 0 稳定、μ > 0 不稳定、μ = 0 是中心（闭轨成族，第 6 章）。加入 −r³ 之后，μ = 0 的中心被「打破」成一个慢速衰减的焦点——这正是线性化在分岔点上失效的具体表现。

4解出环并定它的稳定性．ṙ = r(μ − r²)。零点：r* = 0 与 r* = √μ（μ > 0）。对 g(r) = μr − r³ 求导：g′(0) = μ，g′(√μ) = μ − 3μ = −2μ < 0（μ > 0）。所以 原点不稳定、环稳定。

5导出两条经验法则．半径 r* = √μ 直接给出 √ 增长。周期：环上 θ̇ = ω + bμ 是常数，所以

T = 2π / (ω + b r*²) = 2π / (ω + bμ)

在 μ = 0 处退化为 2π/ω = 2π/Im λ，正是法则二。b ≠ 0 时周期随振幅漂移——数值核验（ω = 1, b = 0.8）：μ = 0.1 实测 5.8180，公式 5.8178；μ = 0.8 实测 3.8320，公式 3.8312。

从标准形到一般系统．任意二维系统在霍普夫点附近，都可以通过坐标变换把二次项消掉、三次项化成一个数 a（第一李雅普诺夫系数），从而局部等价于 ṙ = μr + a r³。这里没有「显然」：变换要用近恒等映射，且 a 的表达式含到二阶、三阶导数。所以判据的逻辑是：条件一、二管「有没有」，a 的符号管「哪一种」。

失效边界．① a = 0 时三次项失效，得看五次项（可能出现更复杂的退化分岔）；② ω = 0 时不是霍普夫，而是退化成零特征值分岔（§8.1）；③ 这个「局部等价」只在分岔点附近成立，走远了环的形状、周期都会离开 √μ 与 2π/Imλ。

§8.2 霍普夫分岔
PROOF 02 · 圆周上的一维流

为什么锁相带宽正好是 2K

完整推导Δ̇ = Δω − 2K sin Δ 的不动点、稳定性与锁相带

出发点．两个相位振子 θ̇₁ = ω₁ + K sin(θ₂−θ₁)，θ̇₂ = ω₂ + K sin(θ₁−θ₂)。

1换成相位差．令 Δ = θ₂ − θ₁，两式相减（注意 sin(θ₁−θ₂) = −sin Δ）：

Δ̇ = (ω₂ − ω₁) − 2K sin Δ = Δω − 2K sin Δ

这一步合法，因为两个方程只通过相位差耦合，减完只剩一个变量——这就是「锁相」问题的全部内容，等价于一个圆周上的一维流（第 4 章）。

2不动点．令 Δ̇ = 0：sin Δ* = Δω/(2K)。因为 |sin| ≤ 1，存在条件就是 |Δω| ≤ 2K。这就是锁相带。

3稳定性．把右端记作 g(Δ)，则 g′(Δ) = −2K cos Δ。在 Δ* 处（|Δ*| ≤ π/2，取主值）：

g′(Δ*) = −2K cos Δ* = −2K√(1 − (Δω/2K)²) < 0

严格为负，故 Δ* 稳定。注意它在带子的边缘 |Δω| = 2K 处趋于 0——这正是「临界慢化」：带边缘附近相位要磨蹭很久才锁定，实验上看到的是很长的暂态。

4带外会发生什么．|Δω| > 2K 时 g(Δ) 恒正（若 Δω > 2K）或恒负，Δ 单调绕圈，永不重复：两个频率都保留了，运动是准周期的。在 (θ₁, θ₂) 的环面上它绕出一条稠密的螺线。

5退化自检．令 K → 0（断开耦合）：带子宽度 2K → 0，无论 Δω 多小都不锁相——两个独立振子当然不会自动同步 ✓。

边界．① 这个模型只保留相位，假设振幅已经稳稳压在环上（第 7 章）；振幅参与动力学时，锁相带会变形，甚至出现「振幅死亡」。② 只有两个振子时结论干净；N 个振子会发生部分同步（Kuramoto 模型），要统计描述。③ K 为负（反相耦合）时，锁相解变成反相，带宽仍是 2|K|。

§8.6 耦合振子与准周期性
PITFALLS · 反例与边界

五个容易踩的坑

1　特征值在虚轴上 ≠ 霍普夫分岔

还要看它是否穿过去（d Re λ/dμ ≠ 0）以及 a ≠ 0。参数走到虚轴上又退回来，什么都不会发生。

2　超/亚临界不能靠「看起来」判

要靠第一李雅普诺夫系数的符号，或者数值（看环是在 μ > μc 还是 < μc 一侧存在）。猜错会直接猜错滞后方向。

3　线性化看不见全局分岔

环的鞍结、同宿分岔发生时，所有不动点的特征值可以一直是「安全」的。它们在雅可比矩阵里没有签名。

4　截面上点少不等于周期短

5 个点可能是周期 5，也可能是一条还没跑满的准周期环，甚至是混沌的一小段。判据是「加长观察后点数是否变」。

5　准周期 ≠ 混沌

准周期是可预测的（两个频率的叠加），它的截面是一条光滑闭曲线；混沌的截面是一团有分形结构的点。两者在截面上长得不一样，这是 §8.7 最实用的收获。

一句话总结边界

本章的判据都是局部的（霍普夫）或需要数值的（全局分岔、庞加莱映射）。两者都要，缺一个就会误判。

带走三句话

一、分岔只有两种穿法：穿原点与穿虚轴。穿原点（λ = 0）是第 3 章的三种基本分岔，涉及不动点互相让位；穿虚轴（λ = ±iω）是霍普夫分岔，不动点把位子让给一条新生的极限环。

二、管霍普夫要三个条件：纯虚特征值、非零穿越率、非零第一李雅普诺夫系数。a < 0 超临界（环安静地长大，√(μ−μc)），a > 0 亚临界（跳变 + 滞后 + 无预警）。

三、局部管不了的，交给全局与映射。环的鞍结与同宿分岔只能靠轨道形状或数值看出来；受迫系统用庞加莱映射每圈打一点，把流压成离散映射——单点=周期，闭曲线=准周期，一团=混沌。

我们在 §8.2 里看到亚临界霍普夫会让系统「跳到远处的一个吸引子」，那时提过一句：那个远处的东西，在三维里可以是一个混沌吸引子。
