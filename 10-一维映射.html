§10.0 引言 · 离散时间

把时间掰成一格一格

前三章的时间是连续的：解是一条曲线，轨道在相空间里流动。可有些系统的「时间」本来就是离散的——一年一代的虫口、一次一次的迭代算法、每转一圈打一个点的庞加莱映射（§8.7、§9.4）。

把这种系统写成递推式：xn+1 = f(xn)。没有导数的概念，也就不需要相图；一个函数图像加上一条 45° 对角线，就能把所有信息画完（§10.1 的蛛网图）。

这一章的赌注

我们要验证一件听起来不太可能的事：一个二次函数反复迭代，就足以产生混沌。不需要三个变量，不需要耗散，不需要奇怪的几何——只要「拉伸 + 折叠」。

还会多拿到一样东西

一个普适常数：δ = 4.669…。它不依赖你选哪个函数——只要是「单峰、二次」的一族，倍周期级联的节奏就一样。这是非线性动力学里最出人意料的结论之一。

记号统一：本章一律写 xn+1 = r xn(1 − xn)，参数用 r，区间 x ∈ [0, 1]、r ∈ [0, 4]（原书 §10.2 的取法）。

§10.0 引言
§10.1 · 不动点与蛛网图

判稳只要看一个数：f′(x*)

不动点 x* 满足 x* = f(x*)。设 xn = x* + ηn，做一阶展开：

ηn+1 = f(x* + ηn) − x* ≈ f′(x*) ηn

于是误差每步乘一个常数：ηn ≈ [f′(x*)]n η₀。结论干净利落：

|f′(x*)| < 1 → 稳定（误差指数衰减）；|f′(x*)| > 1 → 不稳定；= 1 → 线性化失效，要看高阶项。

注意这里的「指数衰减」是按步数算的，不是按时间。所以离散映射的稳定性判据里没有「实部为负」这种说法，只有一个绝对值。

三幅数值蛛网图。青线＝抛物线 f，灰虚线＝对角线 xn+1 = xn，金线＝轨道（竖着走到抛物线上，再横着走回对角线）。左：收敛到不动点；中：绕成周期 4；右：在整段上来回乱跑。
§10.1 不动点与蛛网图
§10.1 · 读图

三步一个循环，图就是算盘

蛛网图（cobweb）的规则只有三步，每次迭代一遍：

① 从对角线上的 (xn, xn) 竖着走到抛物线，高度是 f(xn) = xn+1；
② 横着走回对角线，把高度换成新的横坐标；
③ 重复。

于是：不动点是抛物线与对角线的交点；轨迹收敛表现为阶梯越缩越小、盘成一个「蛛网」；周期轨道表现为一个闭合的多边形，绕一圈回到原点；混沌表现为阶梯把整段填满、不闭合。

为什么这个判据这么几何

在不动点附近，抛物线相对对角线的「陡度」就是 f′(x*)。陡度小于 1（更平）→ 每走一步都更靠近交点 → 稳定；陡度大于 1 → 每走一步更远 → 不稳定。绝对值 = 陡度的方向不重要，正负只决定是「直接逼近」还是「左右横跳着逼近」。

边界提醒

蛛网图只是一维的专利。二维以上没有「一条曲线 + 一条对角线」可画，只能退回相图。所以第 9 章才费那么大劲把洛伦兹压成洛伦兹映射——换来画蛛网图的资格。

§10.2 · 逻辑斯谛映射：数值方法

从虫子到抛物线

第 2 章的逻辑斯谛方程 Ṅ = rN(1 − N/K) 描述连续繁殖。若把繁殖看成「一年一代」、下一代只由这一代决定，就得到它的离散版本：

xn+1 = r xn (1 − xn)，　0 ≤ r ≤ 4，　x ∈ [0, 1]

这里 xn 是第 n 代的无量纲虫口，r 是固有增长率。图像是一条抛物线：在 x = 1/2 处取最大值 r/4。

把 r 限制在 [0, 4]，这条抛物线就把 [0, 1] 映到它自己：x 永远不会跑出去。这一点很关键——系统被关在一个盒子里，所有复杂性都只能在盒子里发生。

原书 §10.2 开头提到 Robert May 1976 年那篇综述（同一篇文章的中文页脚上写着「把这类差分方程引入基础数学课程，对学生是一种福音」）：一个中学生能算的递推式，居然能演出混沌。这就是它成为全章主角的原因。

为什么不用别的函数：因为抛物线最简单、又能代表一大类「单峰」形状——而本章最惊人的结论（普适性）恰恰说明：具体形状不重要，只要它是单峰、二次。

§10.2 · 数值：先看三个区间

r 从小到大，先是死活，再是定数

0 < r < 1：灭绝

不管初始虫口多大，最终 xn → 0。算法是「每代减少到原来的 r 倍以下」，撑不住。

1 < r < 3：稳到一个数

收敛到非零不动点 x* = 1 − 1/r。r = 2 时每步直接跳到 x*，r 接近 3 时左右横跳着靠近（阻尼振荡）。

3 < r < 1+√6 ≈ 3.449：周期 2

不动点失稳，轨道改在两个值之间来回。这是倍周期的第一级台阶。

§10.2 逻辑斯谛映射：数值方法
§10.2 · 数值：级联

2 → 4 → 8 → 16 → … → 混沌

继续加 r：周期 2 在 r = 1+√6 ≈ 3.4495 处失稳，变成周期 4；再往上变 8、16、32……每一次翻倍所需的参数增量越来越小，最后在一串收敛的参数值处堆积到无穷：

r∞ = 3.5699456…

越过 r∞ 之后，周期变成无穷大（永不重复），同时轨道被限制在有限区间里——这就是混沌。再往上，混沌区里还嵌着一条条「周期窗口」（§10.4）。

把「倍周期」想成一次挤压

r 越大，抛物线的峰越高，越容易把相邻的两个值「折」到一起。折一次，周期翻倍；折得越来越频繁，翻倍就越来越密。「拉伸 + 折叠」就是混沌的发动机，这条主线从第 9 章一路贯到第 12 章。

为什么这个级联值得单独讲一节：因为它的节奏（相邻两级参数间距的比值）是一个与具体函数无关的常数。那就是下一节之后要讲的 δ。

§10.3 · 逻辑斯谛映射：解析方法

不动点能解出来，稳定区也能

解 x = rx(1 − x)：

x [r(1−x) − 1] = 0　⇒　x* = 0　或　x* = 1 − 1/r

第一个不动点永远存在；第二个只在 r > 1 时有物理意义（在 [0,1] 内）。稳定性用 §10.1 的判据：

f′(x) = r(1 − 2x)　⇒　f′(0) = r，　f′(1 − 1/r) = 2 − r

于是：0 < r < 1 时原点稳定（虫口灭绝）；1 < r < 3 时原点不稳、非零不动点稳定（|2 − r| < 1）。在 r = 1 处两者交换稳定性——跨临界分岔（§8.1）；在 r = 3 处非零不动点失稳——倍周期分岔。

为什么 r = 3 是倍周期而不是别的

因为 f′(1−1/r) = 2 − r 在 r = 3 时等于 −1。乘子等于 −1 意味着：误差每步大小不变、符号翻转。轨道不再收敛到一点，而是被「翻」到点的另一侧——这正是产生 2 周期的机制。

对比连续系统：第 8 章的霍普夫是复特征值穿虚轴（λ = ±iω），这里是一维的乘子穿 −1。都是「越过分界」，但一维没有旋转可言，只能左右翻。

§10.3 逻辑斯谛映射：解析方法
§10.3 · 解析：周期 2

解 f²(x) = x，拿到 2 周期

2 周期点满足 f(f(x)) = x。这是四次方程，但其中两个根就是已经知道的不动点；除掉它们，剩下的二次式给出：

x± = [(r+1) ± √((r−3)(r+1))] / (2r)　（r > 3 时才有实数）

它的稳定性看「一圈乘子」——把两次的导数乘起来才是周期轨道的判据（§10.1 的判据对复合映射 f² 用）：

μ = f′(x₊) f′(x₋) = −r² + 2r + 4

要求 |μ| < 1：μ = +1 给出 r = 3（出生），μ = −1 给出 r = 1 + √6 ≈ 3.44949（失稳）。所以周期 2 的寿命正好是 3 < r < 3.44949——比上一段短得多。

数值核对（本章脚本）：r = 3.2 时 μ = +0.16（稳定）；r = 3.4 时 μ = −0.76（稳定但接近边缘）；r = 3.449 时 μ = −0.9976；r = 3.46 时 μ = −1.05（已失稳）。

规律已经露出来了：每一级周期轨道的「寿命」都比上一级短，而它们左端点越来越密。这个几何级数的比值，就是 δ。

§10.4 · 周期窗口

混沌带里嵌着干净的周期

把 r 慢慢推过 3.57，你会看到混沌带里不断冒出细窄的空白：在这些 r 区间里轨道又变回周期的。最宽的一条在

r = 1 + √8 ≈ 3.8284（周期 3 窗口的起点）

它的机制与前面不同：不是「倍周期」，而是周期 3 的鞍结分岔——f³(x) 的曲线与对角线相切，一下生出一对周期 3 轨道（一稳一不稳）。所以在窗口起点，乘子恰好是 +1（λ = 0）。

窗口内部也不是一片死水：把 r 再往上推，周期 3 会重复同样的剧本——3 → 6 → 12 → …，又一个小级联，又一个小 r∞。再往右，窗口被「危机」突然掐断，回到混沌。

这一节最重要的一句话

「混沌参数区」不是一个干净的区间，而是一把筛子：里面密密麻麻全是周期窗口。你在实验里调参数，很可能恰好落进某个窗口里，看到的却是「周期 3」这种干净结果——不要因此断定「这个系统不是混沌的」。

数值旁证（本章脚本）：λ(3.83) = −0.370（窗口内，周期 3，λ 为负）；λ(3.9) = +0.496（窗口外，混沌）。

§10.5 · 李雅普诺夫指数

把每步的放大倍数乘起来

一维映射上，误差每步乘 f′。走 N 步之后误差是乘积，取对数再除以 N：

λ = limN→∞ (1/N) Σk=0N−1 ln|f′(xk)|

与第 9 章洛伦兹映射完全同一个公式——只是那里 f 是算出来的帐篷形，这里是显式的抛物线。λ > 0 是混沌的定量判据；λ = 0 通常对应周期轨道（或临界情形）；λ < 0 是稳定不动点或稳定周期轨道。

本章数值（脚本）：λ(2.8) = −0.223、λ(3.5) = −0.873、λ(3.83) = −0.370、λ(3.9) = +0.496、λ(4) = 0.693144 ≈ ln2。最后一个不是巧合——下一页的推导会给出它的精确值。

实用提醒：算 λ 时暂态必须够长（本章用 1500 步），否则会测到暂态的增长率；平均步数也要够（900 步以上），否则窗口附近的符号会抖。

§10.5 李雅普诺夫指数
§10.5 · 读图

一张 λ(r)，三种结构

① 左侧的长负区

2.5 < r < 3.57 之间 λ 基本为负：不动点或稳定周期轨道。越接近 3.57，λ 越贴近零——稳定性在变弱，这是级联堆积的前兆。

② r∞ 右边的锯齿

3.57 之后 λ 在正负之间剧烈锯齿：正的段是混沌带，负的尖谷是周期窗口。锯齿本身就是分形结构——放大任意一段，形状相似。

③ 峰值在 r = 4 附近

λ 的最大值出现在 r = 4：正好等于 ln 2 ≈ 0.693。这是本章唯一能精确算出来的 λ，下一节的推导给它。

λ 与「可预测时间」

λ 的单位是「每步的奈培（nat）」。想把误差放大到 O(1)，需要 n ≈ ln(1/δ₀)/λ 步。

λ = 0.69 时，初始误差 10⁻⁶ 大约在 20 步后长到 O(1)；λ = 0.5 时要 28 步。这就是「混沌的时间尺度」——用它来设计控制系统、判断采样频率都直接可用。

注意对比：第 9 章洛伦兹的 λ ≈ 0.92 是每个时间单位；这里 0.69 是每步。两者不能直接比大小，先要统一成「每单位时间」——这正是第 9 章用 λmap/T̄ 换算的原因。

§10.5 李雅普诺夫指数
PROOF 01 · 出发点 → 步骤 → 退化自检 → 边界

把前两级周期轨道的稳定区算干净

完整推导x* = 1−1/r 与 2 周期 x± 的稳定性，r = 3 与 r = 1+√6 的来历

出发点．xn+1 = f(xn)，f(x) = rx(1−x)，0 ≤ r ≤ 4。

1不动点．x = rx(1−x) ⇒ x[1 − r(1−x)] = 0 ⇒ x* = 0 或 x* = 1 − 1/r。（后者在 [0,1] 内要求 r ≥ 1。）

2不动点的稳定性．f′(x) = r(1−2x)：f′(0) = r，f′(1−1/r) = r(1 − 2 + 2/r) = 2 − r。由 §10.1，|·| < 1 即稳定：原点稳定 ⇔ 0 < r < 1；非零不动点稳定 ⇔ |2−r| < 1 ⇔ 1 < r < 3。

3解 2 周期．f²(x) − x 是四次多项式，已知它含因子 x 与 [x − (1−1/r)]（不动点）。把这两因子除出来，剩下的二次式是

r²x² − r(r+1)x + (r+1) = 0

求根得 x± = [(r+1) ± √((r−3)(r+1))]/(2r)。判别式要求 r ≥ 3（与第 2 步的失稳点一致）。

42 周期的乘子．对复合映射 f² 用判据，乘子是两点的导数之积：

μ = f′(x₊)f′(x₋) = r²(1−2x₊)(1−2x₋)

用韦达定理：(1−2x₊)(1−2x₋) = 1 − 2(x₊+x₋) + 4x₊x₋，而 x₊+x₋ = (r+1)/r、x₊x₋ = (r+1)/r²。代入化简：

μ = r² − 2r(r+1) + 4(r+1) = −r² + 2r + 4

5稳定区间．|μ| < 1 即 −1 < −r²+2r+4 < 1：上界给 r² − 2r − 3 > 0 ⇒ r > 3（正是出生点）；下界给 r² − 2r − 5 < 0 ⇒ r < 1 + √6 ≈ 3.44949。所以 2 周期只在 3 < r < 1+√6 内稳定。

退化自检．取 r = 3：x± 的判别式为零，两根合并为 2/3——正好等于不动点 1−1/3 = 2/3 ✓（2 周期在分岔点上与不动点重合）。同时 μ = +1 ✓。再取 r → 1：x* → 0，非零不动点与原点合并，与「r = 1 处跨临界」一致 ✓。

边界．① 这里只说「稳定/不稳」，没给收敛速率——那是 μ 的绝对值（τ = −1/ln|μ| 步衰减 e 倍）。② 乘子恰好为 ±1 时线性化失效，需要更高阶分析（在 r = 3 与 r = 1+√6 两点正是如此，靠的是分岔理论而不是导数）。③ 这套算法对 4 周期、8 周期原则上都能用，但多项式次数指数增长，实际靠数值（本章脚本用二分法直接找超稳定参数）。

§10.3 逻辑斯谛映射：解析方法
PROOF 02 · 换一个变量，混沌就现出原形

为什么 λ(r=4) 正好等于 ln 2

完整推导共轭变换 x = sin²(πθ/2)，把抛物线变成帐篷

出发点．r = 4 时 f(x) = 4x(1−x)。要证明：在变量替换 x = sin²(πθ/2) 之下，它等价于帐篷映射 T(θ) = 1 − |2θ − 1|（θ ∈ [0,1]）。

1代进去算．令 x = sin²(πθ/2)。则

4x(1−x) = 4 sin²(πθ/2) cos²(πθ/2) = [2 sin(πθ/2)cos(πθ/2)]² = sin²(πθ)

（用了 sin 2α = 2 sin α cos α 与 (sin α cos α)² 的配方。）

2读出 θ 的演化．sin²(πθ) = sin²(πθ′) 给出 θ′ = 2θ 或 θ′ = 2 − 2θ（在 [0,1] 上就是 折回）。合并写成

θn+1 = 2θn (mod 1)　⇔　T(θ) = 1 − |2θ − 1|

这正是帐篷映射。抛物线被「拉直」成了两段斜率为 ±2 的直线。

3算 λ．帐篷映射处处 |T′| = 2（除中点），所以

λtent = ⟨ln 2⟩ = ln 2

又因为 x = sin²(πθ/2) 是光滑可逆变换，它不改变指数（每步的对数增量只差一个有界量，取平均后消失）。所以 λlogistic(r=4) = ln 2。数值核对：本章脚本测得 0.693144，与 ln 2 = 0.693147 相差 3×10⁻⁶。

4顺带拿到不变密度．帐篷映射把均匀分布映成均匀分布（两段斜率都是 ±2，每段保测度、两段各占一半），θ 服从均匀分布。换回 x 用变量替换法则：

ρ(x) = ρ(θ)|dθ/dx| = 1/(π√(x(1−x)))

数值核对：本章 20 万步的直方图与这条曲线完全重合（图见下页）。

退化自检．θ = 1/2 ⇒ x = sin²(π/4) = 1/2，而帐篷映射的不动点 θ = 0 对应 x = 0 ✓；θ = 1 也映到 x = 1 ✓。端点对得上，说明变换是双射（除端点外）。

失效边界．① 这个技巧只对 r = 4 成立；r < 4 时抛物线的像不是整段 [0,1]，帐篷映射的共轭要换成别的（用 Chebyshev 多项式或数值）。② 「共轭」保的是拓扑与指数，不保具体数值：xn 与 θn 不是线性对应，别拿它们相互换算轨道。

§10.3 · 一条可以验证的曲线

轨道不是均匀铺满的

上面那幅数值图很值得盯着看：两端高、中间低。也就是说，r = 4 时轨道在 0 和 1 附近逗留的时间远多于在 1/2 附近。

这不奇怪：抛物线在 x = 1/2 处最平（导数 0），附近的点被「挤」得很快离开；而在两端附近曲线很陡，点被「摊」得很开、走得慢。密度正好反映了这件事。

更重要的是：这条密度是可以算出来的——就是上一页推导出的 1/(π√(x(1−x)))。

为什么值得关心？因为「混沌」常被误解成「均匀随机」。这条曲线说明：混沌有自己的统计规律，而且这个规律可以解析地写下来、被 20 万步的数值实验验证到小数点后几位。

§10.6 · 共轭（conjugacy）

长得不一样，动力学一样

上一页的 x = sin²(πθ/2) 做了一件很划算的事：把一条抛物线变成了一把折线。写成定义：若存在可逆的 h 使

h( f(x) ) = g( h(x) )　⇔　f = h⁻¹ ∘ g ∘ h

就说 f 与 g 共轭。这时「先迭代 f 再换坐标」与「先换坐标再迭代 g」结果相同——两条轨道被 h 一一对应。

共轭保什么：不动点与周期的个数、周期轨道的稳定性（乘子相同）、李雅普诺夫指数（相差一个取平均后消失的有界量）、以及「混沌/不混沌」这个定性结论。共轭不保什么：具体的数值、轨道在坐标轴上的位置、以及不变的密度（密度要按 |dh/dx| 换算）。

为什么这个工具值钱

它让你可以挑一个最容易算的代表。r = 4 的抛物线难算，帐篷映射 |T′| = 2 处处成立、λ = ln 2 一步就有；算完再用 h 换回去。这就是「换个坐标把问题变简单」的标准用法。

边界

共轭要求 h 可逆且足够光滑。若 h 只是连续而不是可微（数学上叫拓扑共轭），指数就可能对不上——那时只能保证「有没有混沌」，不能保证「混沌多快」。

下一章的维数会和这一页再碰一次：共轭不保长度，但保「是不是分形」。所以康托尔集可以和别的集合共轭，而维数照样能算。

§10.6 · 普适性与实验

两个数，与函数长什么样无关

倍周期级联里，第 n 级分岔点 rn 的间距之比趋于一个常数：

δ = limn→∞ (rn−1 − rn−2) / (rn − rn−1) = 4.669201…

另一个常数管「几何缩水率」：每一级周期的轨道在 x 方向比上一级窄多少倍：α = 2.50290…

本章脚本的数值（用「超稳定参数」序列，二分法求解）

周期 2　r = 3.236067977
周期 4　r = 3.498561699
周期 8　r = 3.554640863
周期 16　r = 3.566667380
周期 32　r = 3.569243532
周期 64　r = 3.569795294
周期 128　r = 3.569913465

δ 序列：4.681　4.663　4.668　4.669
α 序列：2.655　2.532　2.509　2.504　2.5032　2.5030

δ 与 α 都在向 4.6692 与 2.5029 收敛，误差随级数下降。这两个数列就是「普适」的直接证据。

复算提示：α 的后几级对参数精度极敏感（第 5 级的间距 d₅ ≈ 1e−9），r 必须二分到浮点极限再取；用四舍五入到 9 位小数的 r 会把最后两位 α 污染掉。

「普适」到底什么意思：把抛物线换成任何单峰、二次的映射（例如 r sin(πx)、或者物理实验里测出来的传递函数），只要它有倍周期级联，δ 和 α 就是同样两个数。具体函数只影响前几级和整体位置。

边界：普适性只对「单峰、二次（或更一般：同一普适类）」的映射成立。多峰映射、或者峰不光滑（例如帐篷映射的尖峰），δ 与 α 都会变。

§10.6 普适性与实验
§10.6 · 实验

在电路、流体、化学里都量到了 δ

理论说 δ = 4.669，那实验能测出来吗？能——只要实验里存在「倍周期通向混沌」的路径。被反复验证过的几类系统：

受迫非线性电路

二极管–电感–电容这类非线性振荡电路，加上周期驱动，随驱动幅度上升会经历倍周期级联，测得的 δ 与 4.669 相符。

瑞利–贝纳德对流

第 9 章洛伦兹模型所描述的那类对流系统：在特定几何与参数下，实验上（瑞利–贝纳德对流装置）确实测到倍周期级联，δ 接近 4.669。注意模型不是实验——是实验去印证模型的预言。

为什么这类实验难做：① 要能稳定地调参数并重复；② 级联越往后越密，δ 的收敛需要测到很后面的几级，而噪声会把窗口抹掉；③ 实验系统永远有三维以上的自由度，严格的「一维映射」只是它在某个截面上的近似。

为什么还是值得信：因为 δ 的普适性像是「指纹」——如果在一类完全不同的系统里量到同一个 4.669，那说明背后确实是同一条倍周期机制，而不是巧合。

本节只做定性叙述，不给具体实验数值：不同装置的测量精度与条件差别很大，把数字抄进来反而容易误导。要查数值请看原书 §10.6 列出的原始文献。

§10.6 普适性与实验
§10.7 · 重整化

把「看两次」当成「看一次」

倍周期级联有个惊人的几何事实：把分岔图在 r = r∞ 附近放大，再放大，形状还是那个形状——原来的一棵树在里面套着一棵小树。这就是自相似。

重整化（renormalization）把这个事实变成方程。做法是「两步并一步」：走两次抛物线 f，得到 f²；再把它沿 x 方向放大 α 倍、r 方向调到分岔点上，得到的新函数 应当和原来的 f 长得一样。于是有函数方程：

g(x) = −α g( g(−x/α) )

满足它的函数 g 叫普适函数，它不是抛物线，但所有单峰二次映射在临界点附近都「长成 g 的样子」。方程的解就是这个函数 g，而 α = 2.5029 是与它配对的标度常数；δ = 4.6692 则是「偏离 g 的方向被缩小的速率」——粗略说，δ 是重整化算子在不动点处的一个特征值。

为什么这就解释了「无关函数形状」

重整化一次又一次地作用，把函数往 g 上拉。拉过去之后，原来长什么样已经被「洗掉」了。所以只要属于同一个吸引域（同样单峰、同样二次），最终都收敛到同一个 g、同一对 δ 与 α。这和相空间里「所有轨道都落到同一个吸引子上」是同一件事，只不过这里的「点」是整个函数。

本节只讲思路。解那个函数方程需要数值方法（在原书 §10.7 有展开），本章不做——这里要你记住的是这条逻辑链：自相似 → 重整化方程 → 不动点 → 普适常数。

§10.7 重整化
PITFALLS · 反例与边界

五个容易踩的坑

1　把「一维」当成「简单」

一维映射没有相图、没有体积、只有一个递推式，却照样混沌。复杂度不来自维数，而来自拉伸与折叠。

2　在窗口里以为没有混沌

混沌区是一把筛子，周期窗口密布。看到周期 3 不等于系统「不是混沌系统」，只说明参数落进了窗口（r = 3.83 处 λ = −0.370）。

3　忘记 r ≤ 4 这个前提

只有 0 ≤ r ≤ 4 时抛物线才把 [0,1] 映到自身。r > 4 时这个性质就没了：轨道一旦跑出区间就再也回不来，之后反复乘一个大于 1 的因子，最终发散到 −∞。本章所有结论都不适用。

4　拿瞬时增长率冒充 λ

λ 是长期平均。暂态不够长、平均步数不够多，窗口附近的 λ 符号会乱跳。本章的取法是 1500 步暂态 + 900 步平均。

5　把 δ 当成「所有混沌系统的常数」

δ = 4.669 只属于倍周期通向混沌这一条路、且属于单峰二次的普适类。别的通向混沌的路径（准周期破裂、阵发性）有各自不同的常数。

一句话总结边界

本章所有结论都挂在「一维、单峰、0 ≤ r ≤ 4」这三个条件上。第 11–12 章要处理的是：不满足这些条件时，还能说什么。

TAKE AWAY · 三句话

带走三句话

一、一维就有混沌。xn+1 = r xn(1−xn) 只有一个变量、一个参数，却包含不动点、周期、倍周期、混沌与周期窗口。判据是 f′ 与 λ，不是眼睛。

二、级联有节奏，节奏是普适的。分岔点按 δ = 4.669 收敛，几何按 α = 2.503 缩水。本章数值：δ = 4.681→4.663→4.668→4.669，α = 2.655→…→2.5030。换任何单峰二次映射，还是这两个数。

三、chaos 与「随机」不是一回事。r = 4 时有精确的不变密度 1/(π√(x(1−x)))、精确的 λ = ln 2；这些都是确定性的结果。混沌有自己的秩序，只是那个秩序是统计的、分形的。

回到本章开头的问题

一条抛物线凭什么演出混沌？

因为它同时做两件事：拉伸（把靠近的点分开，斜率 2–4）与折叠（把区间折回自己身上）。分开让你失去记忆，折回让你永远跑不掉。
