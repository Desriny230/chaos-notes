§4.0 · 引言

把数轴的两头接起来

第 2 章有一句判决：一维自治流不会振荡。理由很硬——零点把数轴切成段，每段只有一种流向，进得去出不来。

可是世界上到处都在振荡：钟摆、心跳、激光拍频、萤火虫的闪光。所以一定是某个前提被偷偷换掉了。换掉的是数轴的拓扑。

把数轴两端粘起来，得到的是圆。合法的状态不再是可以无限变大的实数，而是一个角度：θ 与 θ+2π 说的是同一件事。转一整圈不是"跑到无穷"，而是回到出发点。

第 2 章说"不会有周期解"，是因为它默认解回不到起点。把线接成圈，这个前提没了——周期解立刻成了最自然的东西。

本章要回答三件事：圆上的流有哪几种命运？什么时候它"转"，什么时候它"停"？把它们接到真实系统上——摆、萤火虫、超导结——说的是同一件事吗？

§4.0 引言
§4.1 · 例子与定义

圆上的流：一个角度，一条闭曲线

直线上的流，状态是 x ∈ ℝ。圆上的流（flow on the circle），状态是 θ ∈ S¹，而 S¹ 就是实数模 2π：

θ ∈ S¹ = ℝ / 2πℤ ， θ ∼ θ + 2π

方程仍然是 θ̇ = f(θ)，但 f 必须以 2π 为周期。否则同一个状态会给出两个速度，方程就不成立了。

f(θ + 2π) = f(θ)

三个最常见的来源：
· 钟摆的角度：θ 摆动一圈与两圈是同一个姿态；
· 振子的相位：任何周期过程都能只用一个相位描述（心跳的"第几成"）；
· 超导结的相位差：两个波函数的相对相位，物理上天生就是模 2π 的量。

画图时有个方便：把圆剪开、摊平成 θ ∈ [−π, π]。但要记住左右两端是同一个点——忘记这一条，就会漏掉"绕过接缝"的那类解。

§4.1 例子与定义
§4.1 · 与直线的差别

换了个拓扑，结论换了三条

一、没有"跑到无穷"这回事。相空间是紧的（有界无边），轨道只能绕着走。第 2 章那种"有限时间爆破"在圆上不会发生。

二、但也没有"所有轨道都单调"这回事。只要 f 处处不为零且不变号，轨道就会一直转下去，永远不重复。这正是第 2 章被禁掉的那种行为。

三、存在唯一性反而更干净。f 定义在紧集上，连续可微则 f′ 有界，李普希茨常数取 L = max|f′| 就够（§2.5）。于是圆上的流总能解到任意长时间，不会中途"没定义"。

于是圆上只有两种命运

要么最终停在一个不动点（或者无限接近它），要么一直转。中间没有第三种。周期运动不"特殊"，它就是最基本的运动形态。

判断的关键只有一个字

看 f(θ) 有没有零点。
有零点 → 可能停住（稳不稳还要另判）；
没有零点 → f 不变号，只能单向转。

§4.2 · 均匀振子

匀速转动：卷绕数是这样来的

最简单的情形是 f 为常数：

θ̇ = ω （ω 为常数）

解是 θ(t) = ωt + θ₀，周期 T = 2π/|ω|。它每 T 秒转一圈，永远不停——这就是均匀振子（uniform oscillator），钟表匠的理想摆轮。

现在引入本章最重要的量：卷绕数（winding number，也叫平均频率）——单位时间转了几圈：

W = limt→∞ [θ(t) − θ(0)] / (2π t) = ω / 2π

它对初始相位完全不敏感（θ₀ 在分子里被减掉了），所以 W 刻画的是流的"整体转速"，与你在哪一刻开始观察无关。这一点很要紧：轨迹会因初值千差万别，W 却只有一个值。

注意 W 不是整数，它随参数连续变化（§4.3 会算出 W = √(ω²−A²)/2π，在临界处连续降到 0）。真正会"被钉死在一个固定值上"的，是被外部周期驱动抓住的情形——那时平均频率锁在驱动频率上，见阿诺德舌那一页。一个数就能概括整条轨迹，这才是它的价值。

顺带澄清一个常见困惑：W 是"平均"，不是"瞬时"。f 可以忽快忽慢（只要不变号），W 照样可以是常数。

§4.3 非均匀振子
§4.3 · 非均匀振子

非均匀振子：什么时候转不动

让速度随位置变化，取最简单的一种：

θ̇ = ω + A sin θ ， A ≥ 0

两项意思很清楚：ω 是"本来想转"的基础速度，A sin θ 是"位置带来的加减速"。这是全章的原型方程——摆、约瑟夫森结、锁相环都能化成它。

零点：sin θ = −ω/A，有解的条件是 |ω| ≤ A。三种情形一目了然：

· A < ω：无零点，θ̇ 恒正 → 一直转，W ≠ 0；
· A = ω：恰好相切，一个半稳定点（临界情形）；
· A > ω：两个零点，一稳一不稳 → 转向稳定点，锁相，W = 0。

所以 A/ω = 1 是一条硬分界：它把"振荡"变成"停住"。实验上这叫"失锁"或"被俘获"。

左：A = 1.5、ω = 1 时圆上的流向（箭头长度＝|θ̇|，填实点＝稳定不动点）。右：同一族 f(θ) 在三种 A 下的形状，曲线与横轴的交点就是不动点。
§4.3 非均匀振子
§4.3 · 锁相判据

转还是停：一条关于 A/ω 的分界线

把上一页的三种情形写成判据。设 A ≥ 0：

A < ω：转动

θ̇ 恒正、无零点。轨道一直绕，平均角速度（后面会证明）是 √(ω²−A²) > 0。
卷绕数 W > 0。

A = ω：临界

在 sin θ = −1 处恰好相切，出现一个半稳定点。这是转动与锁相之间唯一的过渡：到达那里要花无穷久。

A > ω：锁相

两个零点，一个稳定（吸引）、一个不稳定（排斥）。从任何初值出发都滑向稳定点，W = 0。
系统"停止转动"。

"锁相"（phase locking）这个词的来历：如果把 θ 看成某个外部周期驱动的相位，那么 θ̇ = 0 就意味着振子被驱动信号"抓住"了，两者的相位差固定下来。振幅不必相同，频率却完全一致——这就是锁相。

还有一点必须说清：锁相不要求两个振子"频率本来就一样"。恰恰相反，是耦合把频率差"吃掉"了：能锁住的范围正好是 |ω| ≤ A。参数再变，一旦出了这个范围，就差频、就拍频——那叫失锁。

§4.3 非均匀振子
周期随非均匀度发散：横轴 A/ω，纵轴 T/T₀。虚线是匀速极限 1；A/ω → 1 时周期冲向无穷（青点是复算值）。
§4.3 · 瓶颈

临界附近，绕一圈要无穷久

周期是"走完一圈要多久"，也就是速度倒数的积分：

T = ∫₀2π dθ / (ω + A sin θ)

这个积分可以算出手：令 t = tan(θ/2)，它会化成标准形，结果是

T = 2π / √(ω² − A²) ， ⟨θ̇⟩ = 2π/T = √(ω² − A²)

（推导见本章"完整推导 1"。）两个自检：A = 0 时 T = 2π/ω ✓ 回到匀速；A/ω 很小时 T ≈ T₀(1 + A²/2ω²)，慢下来是二阶小量，所以小扰动几乎看不出区别。

但 A → ω 时，T ∝ 1/√(ω−A) 冲向无穷。物理原因：在 sin θ ≈ −1 那一段，θ̇ ≈ 0，系统在那里"磨"很久才磨过去。这一段叫瓶颈（bottleneck）。

实验上的推论很漂亮：靠近临界，波形会变得极不对称——大部分时间花在瓶颈里，然后猛地蹿过去。看到这种"慢-快"波形，就该怀疑附近有锁相阈值。

§4.4 · 过阻尼摆

过阻尼摆：圆上最经典的例子

把一根摆放进黏稠液体里，摩擦大到惯性可以忽略（同 §2.6 的过阻尼极限）。力矩平衡给出：

bθ̇ = −mgL sin θ ⟹ θ̇ = −sin θ

（无量纲化后，时间以 b/(mgL) 为单位；量纲检查：b 的单位是力矩/(角速度)，右边是力矩，比值确实是角速度 ✓。）

零点：sin θ = 0 → θ* = 0 与 π（在圆上各只有一个，其余都是同一个点加了 2π 的副本）。稳定性：f′ = −cos θ，在 0 处 −1 < 0（稳定，最低点），在 π 处 +1 > 0（不稳定，正上方）。

于是在圆上：最低点是汇，正上方是源。除了正上方那一个点和它的"完全对齐"初值，所有初值最后都滑到最低点。

关键的一点：它不会一直转。因为 θ̇ = −sin θ 有零点，一旦滑到 0 就停了。恒速转动需要 f 处处不为零，而纯重力做不到。

如果把这圈剪开、只看 θ ∈ (−π, π)，得到的正是第 2 章那张 ẋ = −sin x 的图。多出来的信息只有一条：π 与 −π 是同一个点。就这么一条，让"翻过去"变成"落回来"。

§4.4 过阻尼摆
§4.4 · 恒力矩

加一个恒力矩：摆变成转动器

现在给轴上加一个恒定的驱动力矩，方程变成（无量纲化后）

θ̇ = μ − sin θ

这就是 §4.3 的非均匀振子，只是把 ω 换成了 μ、把 A 固定成 1。所以三种情形的判据立刻可用：

μ < 1：摆不动，但你推不动它

两个不动点：稳定的在 θ* = arcsin μ（偏在一边，重力的回拉正好抵住力矩），不稳定的在 π − arcsin μ。摆停下来，但停在偏角上。

μ > 1：它开始转，越推越快

力矩压过重力，无零点，摆一圈圈翻过去，平均角速度 √(μ²−1)。

μ = 1：临界

半稳定点。到达它要无穷久——正是上一页的瓶颈。

这个转变在工程上有名字：从"振荡器"变成"转动器"。转子、电机启动、被风吹转的风向标，都是这个结构。

必须提醒一句边界：真实的摆有惯性，二阶方程会给出双稳与滞后（第 8 章），过阻尼一维模型给不出。所以"μ 慢慢加、一过 1 就转"这个干净的结论，只在摩擦足够大时成立。

§4.5 · 萤火虫

萤火虫：同步是自发长出来的

在东南亚的红树林里，有一类萤火虫会整片树一起明灭：成千上万只，节奏一致，中间没有任何"指挥"。这个现象被反复观察和记录过，也是相位耦合研究最常引用的自然案例。

它有两条容易忽视的事实：

一、每只虫都有自己的内在节律。离群索居时，它照样以接近 1–2 秒的周期闪，只是相位乱七八糟。

二、同步不是"频率变得一样"，而是"相位对齐"。频率本来就很接近，耦合做的是把相位差压到零——这正是 W = 0 的那一类锁定，只不过这里锁的是"彼此"，不是"外部驱动"。

同样的机制还出现在

蟋蟀齐鸣、某些蛙类的合唱、心脏起搏细胞、培养皿里的心肌细胞、以及人会跟着节拍鼓掌。只要个体之间能"看到/听到"彼此，并且会被推一下相位，同步就可能自发出现。

也常常失败

热带雨林里大多数萤火虫并不同步；很多蛙也各叫各的。耦合太弱、个体差异太大、或者时序不对，都会让同步长不出来。"能同步"是条件，不是必然。

§4.5 萤火虫
§4.5 · 相位模型

把同步写成一个相位模型

把每只虫的状态压成一个相位 φi ∈ [0, 1)：φi = 0 是刚闪过，φi → 1 是即将闪。每只虫以同样速率走表：φ̇i = 1。

耦合规则（脉冲耦合，pulse-coupled）：谁闪了，就把别人的相位往前推 ε；闪完的那只复位到 0。如果被推的越过了 1，它就跟着立刻闪（级联）。

右图是八只虫的数值结果：初相位乱放，几条轨迹很快并成一簇，然后一起闪。

为什么收敛？被推的那一下让落后的追上一点；越聚得紧，互相推得越频繁——正反馈。这不是"趋同于平均"，而是"被最快的那只牵着走"。

边界：耦合太弱（ε 太小）时收敛不住——八只虫只会形成几个局部小簇，整体仍彼此错开，谁也不同步；个体频率差异太大时也锁不住；加噪声则会"滑步"、间歇性失步。这些界都要自己算，不能只信定理。

八只脉冲耦合的"萤火虫"，相位 0→1 走表、闪一次复位。初相位乱放，约 2 个时间单位后并成一簇，此后完全重叠（数值模拟：ε = 0.12；实测相位标准差从 0.14 降到 0.000）。
§4.5 萤火虫
§4.5 · 两只振子

两只萤火虫就够了：相位差自己会收敛

八只虫太热闹。先把问题缩到两只，看看"同步"在最简单的情形里究竟是什么。设两只虫各自以 ω 走表、耦合强度 K，互相推相位：

θ̇₁ = ω + K sin(θ₂ − θ₁) ， θ̇₂ = ω + K sin(θ₁ − θ₂)

两式相减，令 Δ = θ₂ − θ₁（相位差）：

Δ̇ = −2K sin Δ

这就是 §4.3 的方程（ω = 0、A = −2K）。所以只有两种命运：Δ = 0（同步，一起闪，稳定）与 Δ = π（反相，轮流闪，不稳定）。

收敛有多快？Δ 很小时 sin Δ ≈ Δ，于是 Δ̇ ≈ −2KΔ：指数收敛，时间常数 1/(2K)。耦合越强，对齐越快——这就是上一页"正反馈"三个字的定量版本。

两只虫频率不一样呢？取 θ̇₁ = ω₁ + K sin(θ₂−θ₁)、θ̇₂ = ω₂ + K sin(θ₁−θ₂)，则

Δ̇ = (ω₂ − ω₁) − 2K sin Δ

又成了非均匀振子——锁相条件 |ω₁−ω₂| ≤ 2K。于是"耦合能吃掉多大的频率差"这句话有了刻度：吃掉两倍耦合强度那么多。超出这个范围，两只虫就各闪各的，拍频出场。

§4.6 · 超导约瑟夫森结

超导约瑟夫森结：一根导线里的圆上的流

两块超导体夹一层极薄的绝缘层，就是一个约瑟夫森结（Josephson junction）。它的两个基本关系是：

I_s = I_c sin φ ， dφ/dt = 2eV/ħ

第一式：超导电流只由相位差 φ 决定，最大是临界电流 I_c。第二式：相位差的变化率正比于结上的电压 V（e 是电子电荷、ħ 是约化普朗克常数）。注意 φ 天生只定义到 2π——它就是一个圆变量。

把真实的结接进电路：结上并联一个电容 C（极板间的电容）和一个电阻 R（漏电）。由基尔霍夫定律，总电流分三路走：

I = I_c sin φ + V/R + C dV/dt

用第二式把 V 换成 φ̇：V = (ħ/2e)φ̇，于是

(ħC/2e) φ̈ + (ħ/2eR) φ̇ + I_c sin φ = I

除以 I_c、再用特征频率无量纲化，就得到标准的 RCSJ 方程（resistively and capacitively shunted junction，电阻电容并联结模型）：

β_c φ″ + φ′ + sin φ = I/I_c

β_c = (2e/ħ)·I_c·R²·C 是无量纲的"阻尼的倒数"：β_c 小 = 过阻尼 = 摆的极限，那时方程退化成 φ̇ = I/I_c − sin φ，与上一节的过阻尼摆一模一样。

§4.6 超导约瑟夫森结
过阻尼结（β_c ≈ 0）的 I–V 曲线：I < I_c 时电压严格为零；越过 I_c 后 ⟨V⟩ = I_cR·√((I/I_c)²−1)。青点是数值积分算出来的平均值。
§4.6 · I–V 曲线

零电压也是一种锁定

取过阻尼极限 β_c → 0，RCSJ 方程退化成

φ̇ = I/I_c − sin φ

这跟上一节的摆一字不差。所以三种情形直接搬过来，只是要用电压来读。注意 φ′ 是对无量纲时间 τ = ω_c t 的导数，所以 V = (ħ/2e)ω_c⟨φ′⟩ = I_cR·⟨φ′⟩——电压就是相位的转速，乘上 I_cR 而已。

· I < I_c：有不动点，φ 停住 → φ̇ = 0 → V = 0。但电流不为零：它全部由超导电流 I_c sin φ 承担。这叫超导态（零电压态），是约瑟夫森结最著名的性质。

· I > I_c：无不动点，φ 一直转 → 出现直流电压：

⟨V⟩ = I_c R · √( (I/I_c)² − 1 )

大电流时 ⟨V⟩ ≈ IR，回到欧姆定律 ✓；在 I = I_c 处电压从零连续长出（又是 √ 标度，因为那也是鞍结式的临界）。

条件：以上是过阻尼（小电容）的情形。真实结的 β_c 常常不小，这时会出现滞后——往上扫和往下扫的曲线不重合，那是第 8 章的内容。

§4.6 超导约瑟夫森结
PROOF 03 · 完整推导

那条 I–V 曲线是怎么算出来的

完整推导周期积分 → 平均电压 → 退化自检 → 边界

出发点．过阻尼结（β_c = 0）：φ′ = i − sin φ，其中 i = I/I_c。电压由相位转速给出：V = I_cR⟨φ′⟩（这一步用了 φ′ 是对 τ = ω_c t 求导，以及 I_cR = (ħ/2e)ω_c）。所以要算的只是平均转速。

1分两种情形．i < 1 时有不动点，φ 停住 → ⟨φ′⟩ = 0 → V = 0（零电压态）。i > 1 时 φ′ > 0 恒成立，φ 一直增，走一圈的时间是

T = ∫₀^{2π} dφ / (i − sin φ)

2认出它．这与 §4.3 那个积分完全同型（把 ω 换成 i、A 换成 −1），所以直接搬结论：

T = 2π / √(i² − 1) ， ⟨φ′⟩ = 2π/T = √(i² − 1)

3换回电压．V = I_cR√((I/I_c)² − 1)。这就是上一页那条红线。不需要新的积分技巧，同一道题做两遍而已。

退化自检．① i → 1⁺：√(i²−1) → 0，V 从零连续长出 ✓（曲线在 I_c 处不跳变，但斜率 dV/dI → ∞）。② i ≫ 1：√(i²−1) ≈ i，于是 V ≈ I_cR·(I/I_c) = IR ✓ 回到欧姆定律。③ i < 1：公式给出虚数，说明根本没有周期解——这正是"锁相"的另一种说法。

失效边界．① 只在 β_c = 0（过阻尼）时成立；β_c ≠ 0 时相位有惯性，平均电压要解二阶方程，而且出现滞后（上行与下行曲线不重合，回滞电流低于 I_c）——第 8 章。② 把 R 当常数：实际准粒子通道是非线性的。③ 高温或强磁场会压低 I_c，整条曲线缩。

方法上的收获．同一个积分，在 §4.3 叫"周期"，在这里叫"电压倒数"，在 §6.7 还会以"钟摆的周期"再出现一次。会认题比会算题值钱。

§4.6 超导约瑟夫森结
§4.6 · 实验证据

Shapiro 台阶：锁相在实验室里的样子

上一页的 I–V 曲线是一根光滑的线。可如果你一边给结通直流，一边用微波照它（频率 f），曲线会变样：出现一串水平的台阶——电压每上一级，电流可以在很大范围内变化，而电压纹丝不动。

台阶的电压值有一个惊人的性质：

V_n = n · h f / (2e) ， n = 0, ±1, ±2, …

只由微波频率决定，与结用什么材料、多大尺寸、什么温度统统无关。原因正是这一章讲的锁相：微波把相位 φ 抓住，锁成"每个微波周期正好转 n 圈"。转一圈要的时间被钉死，电压（∝ φ̇）自然也被钉死。

用本章的语汇说：台阶就是阿诺德舌被"横着切开"看到的样子——把横轴从驱动频率换成电流，锁相区就表现为一段电压恒定的平台。

它变成了"伏特"的定义

因为 V = n·h f/(2e) 只依赖频率，而频率可以做得极准，约瑟夫森结长期被用作电压基准：常数 KJ = 2e/h ≈ 4.836×10¹⁴ Hz/V。一个电学单位，交给一个频率来定义。

条件与失效

台阶要"平"，需要微波功率合适、噪声足够低；温度升到超导转变以上，超导态消失，台阶也就没了。台阶的宽度（电压不变时电流能变的范围）正比于驱动强度——那正是舌头的宽度。

这一页值得停一下：一个纯数学的锁相判据，最后变成了一把国际计量用的尺子。

§4.6 超导约瑟夫森结
§4.5 · 携带范围

锁相在参数平面上长成一条舌头

把振子放到一个外部周期驱动下：振子本来想以 ω 转，驱动以 Ω 推它，耦合强度 A：

θ̇ = ω + A sin(θ − Ωt)

换到随驱动一起转的坐标系：φ = θ − Ωt，于是

φ̇ = (ω − Ω) + A sin φ

又回到了非均匀振子——只是"基础速度"变成了频率失配 ω−Ω。所以锁相条件是

|ω − Ω| ≤ A

把它画在 (Ω, A) 平面上：顶点在 Ω = ω、向两侧以 45° 张开的三角形。三角形内部锁相（平均频率被钉在 Ω 上），外面则差频。这个形状叫阿诺德舌（Arnold tongue）。

为什么叫"舌"：把 1:1、2:1、3:2 等各种共振的锁相区都画出来，它们是从横轴上一串点长出来的尖角，像一排舌头。本章只算 1:1 这一条。

数值扫描出的锁相区（金点）与解析边界 A = |ω₀−Ω|（两条直线）。1891 个网格点里只有 25 格不一致，且全在边界线上——那里收敛极慢，有限积分时长会把"转动"误判成"锁相"。舌外是转动区。
§4.5 萤火虫
§4.5 · 携带范围之外

失锁之后：拍频从零长出来

舌头外面发生了什么？回到旋转坐标系：φ̇ = Δ + A sin φ，其中 Δ = ω−Ω 是频率失配。当 |Δ| > A 时没有零点，φ 一直转——但转得不均匀。

它的平均转速直接套用 §4.3 的结果（把 ω 换成 Δ）：

⟨θ̇⟩ = Ω + sgn(Δ)·√(Δ² − A²)

于是振子的实际频率与驱动频率之间差一个 √(Δ²−A²)。这个差值就是拍频：把两个接近的频率叠在一起，包络会以这个差频周期性涨落——调收音机、听两只略微失谐的音叉，都是它。

注意这个差的形状：它在舌头边界上从零连续长出来，并且以 √ 的方式起步。所以实验上判断"离锁相区还有多远"，最快的办法就是量拍频随参数的走势——√ 的曲线是舌头的指纹。

这件事在工程里天天发生

锁相环（PLL）靠它把本地振荡器锁到输入信号上；激光的注入锁定、电子管的同步、乃至心脏起搏细胞被外部刺激"带走"，用的都是同一个判据：失配不能超过耦合强度。

一个容易搞错的点

失锁不等于"没有相互作用"。即使锁不住，耦合仍然改变了平均频率（上式里的 √(Δ²−A²) 而不是 |Δ|）。锁相只是相互作用的极端情形，不是全部。

§4.5 萤火虫
PROOF 01 · 完整推导

绕一圈要多久：那个根号是怎么来的

完整推导T = 2π/√(ω²−A²) 的换元计算 + 退化自检 + 边界

出发点．设 ω > A ≥ 0（无零点，轨道单调绕圈）。周期是速度倒数的积分：

T = ∫₀^{2π} dθ / (ω + A sin θ)

1换元．令 t = tan(θ/2)。这是 θ ∈ (−π, π) 到 t ∈ (−∞, ∞) 的单调双射，而 θ = ±π 是圆上的同一点，被积函数在那里取有限值（因为 ω > A，分母不为零），所以开区间上的积分等于整圈的积分。合法性就在这里。

2代换．用 sin θ = 2t/(1+t²)、dθ = 2dt/(1+t²)：

T = ∫_{-∞}^{∞} 2 dt / (ω t² + 2At + ω)

3配方．分母 = ω[(t + A/ω)² + k²]，其中 k² = 1 − A²/ω² > 0（这一步用了 ω > A）。于是

T = (2/ω) · (1/k) · [arctan((t+A/ω)/k)]_{-∞}^{∞} = (2/ω)·(π/k)

4回代．ωk = √(ω²−A²)，所以

T = 2π / √(ω² − A²) ， ⟨θ̇⟩ = 2π/T = √(ω² − A²)

退化自检．A = 0：T = 2π/ω ✓ 回到均匀振子。小 A：√(1−A²/ω²) ≈ 1 − A²/2ω²，所以 T ≈ T₀(1 + A²/2ω²) ✓ 慢下来是二阶效应，与数值图上的形状一致。

失效边界．A ≥ ω 时 k² ≤ 0，配方里出现实零点，积分发散——这不是算错，而是没有周期解了（锁相或临界）。发散的速度：k² = (ω−A)(ω+A)/ω² ≈ 2(ω−A)/ω，所以 T ∝ 1/√(ω−A)：1/2 次幂的发散，正是上一页曲线的尾巴。

§4.3 非均匀振子
PROOF 02 · 完整推导

从两个物理关系推出 RCSJ 方程

完整推导约瑟夫森关系 + 基尔霍夫 → 无量纲化 + 量纲自检 + 边界

出发点．两条经验定律：超导电流 I_s = I_c sin φ；相位与电压的关系 dφ/dt = 2eV/ħ。φ 是两块超导体波函数的相位差。

1基尔霍夫．真实结不是一个理想元件：极板间有电容 C，绝缘层有漏电，等效为一个电阻 R 与电容并联。总电流分三路：

I = I_s + I_R + I_C = I_c sin φ + V/R + C dV/dt

2消掉 V．用第二个约瑟夫森关系：V = (ħ/2e)φ̇，于是 dV/dt = (ħ/2e)φ̈。代入：

I = I_c sin φ + (ħ/2eR) φ̇ + (ħC/2e) φ̈

3无量纲化．除以 I_c，并把时间换成 τ = ω_ct，其中 ω_c = 2eI_cR/ħ（结的特征频率）。记 φ′ = dφ/dτ，则 φ̇ = ω_cφ′，φ̈ = ω_c²φ″：

β_c φ″ + φ′ + sin φ = I/I_c ， β_c = ω_c R C

4量纲自检．φ 无量纲 → φ′、φ″ 无量纲；ω_c 的量纲是 1/时间，RC 是时间，所以 β_c = ω_cRC 无量纲 ✓。三个参数（β_c、I/I_c、初值）把一个四元件电路说完了。

退化自检．① β_c → 0：φ′ + sin φ = I/I_c ✓ 正是 §4.4 的过阻尼摆；② I → 0：φ′ = −sin φ ✓ 无电流的纯摆；③ 大电流：φ′ ≈ I/I_c，此时 V = (ħ/2e)ω_c⟨φ′⟩ = I_cR·(I/I_c) = IR ✓ 回到欧姆定律。

失效边界．① 把 R 当常数：真实结的准粒子通道是非线性的（电压大时电阻会变）；② 电容被当成理想集总元件，高频下不对；③ 忽略温度、磁场对 I_c 的影响；④ β_c 不小的时候必须保留二阶项，于是出现滞后——那是第 8 章的话题，一阶模型给不出。

§4.6 超导约瑟夫森结
CHECK · 自测

五道题：把圆和线分清楚

—
TAKEAWAY · 带走

一条判据、一个数字、三个系统

一条判据：θ̇ = ω + A sin θ 有零点 ⟺ A ≥ |ω|。有零点就锁相（W = 0），没零点就一直转。

一个数字：转动时平均角速度 √(ω²−A²)。它在临界处按 1/√(ω−A) 的方式把周期拉长到无穷——瓶颈。

三个系统：过阻尼摆（μ−sinφ）、萤火虫（脉冲耦合的相位）、约瑟夫森结（过阻尼极限的 RCSJ）——同一个方程的三件外衣。

这一章还有一个隐形的收获：我们学会了"只用一个相位"描述系统。下一步是把它扔掉——不再假设状态是一个数或一个角，而是两个数。那时振荡不必再靠圆，相平面上自己就能长出闭轨。

两个常见误读

误读一：把"锁相"当成"频率相同"。锁相是把频率差吃掉了，能吃的范围就那么大（|ω−Ω| ≤ A）。
误读二：以为约瑟夫森结在 I < I_c 时没有电流。恰恰相反：零电压但是有电流，那正是超导态。

下一章的开头

圆上的流只有两种命运，因为相空间只有一个维度。给两个维度，就能同时"转"和"长"：螺旋、鞍点、闭轨全都会出现。
