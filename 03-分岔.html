CH.03 · BIFURCATIONS

分岔
Bifurcations · 参数一动，结构就换

上一章的 f(x) 是死的。现在给它装一根旋钮 μ，慢慢拧。
大多数时候什么都没发生——但在某几个值上，不动点会成对出生、成对死掉，或者交换身份。

鞍结分岔跨临界叉式与对称破缺激光阈值旋转环不完美与滞后昆虫爆发
—
§3.0 · 引言

参数是一根旋钮，拧它会发生什么？

真实系统里总有些量我们不去直接控制、却会慢慢改变：泵浦功率、转速、环境容量、药物剂量。把它们写成一个参数 μ，方程就成了

ẋ = f(x, μ)

每固定一个 μ，你都能画出上一章那张图——零点、箭头、谷底山顶。问题在于：换个 μ，这张图会变吗？怎么变？

答案有两层。第一层很无聊：零点会慢慢挪位置。第二层才有意思：在某几个特殊值上，零点的个数突然变了，或者稳定性突然换了手。那一刻叫分岔（bifurcation），那个参数值叫分岔点 μ_c。

分岔是"定性"的转折，不是"定量"的偏移。μ 稍微变一点，解的个数、稳定性、长期行为就换了一套——这类跳跃没法用"近似"糊过去。

本章要回答：一维流里到底有几种基本的分岔方式？答案是三种（外加它们在不完美条件下的变种）。三种都会给出一张分岔图，而这三张图就是你以后识别一切分岔的字典。

§3.0 引言
HOW TO READ · 分岔图

分岔图：把一整族相图叠在一张纸上

横轴放参数 μ，纵轴放不动点的位置 x*。竖着切一刀，得到的是"这个 μ 下的全部不动点"——也就是上一章那张相图的骨架。整张图，就是无数张相图叠在一起。

读它只要三个动作：

① 看实线与虚线。实线＝稳定不动点（谷底），虚线＝不稳定（山顶）。这条约定全章统一。

② 找数目的突变。某一列上有一个点，旁边一列变成三个——这一列就是分岔点。个数变化才是分岔。

③ 看斜率。分岔点附近分支常以 √ 的形式张开：x* ∝ ±√(μ−μ_c)，曲线在分岔点处竖直。看到垂直切线，就去找分岔。

还有一条容易忽略的：分岔图上没有时间。它只说"哪些状态可以待着"，不说"多久到达"。动力学要看相图；分岔图只看骨架。

01 / 03 · 鞍结

ẋ = μ − x²：两个不动点凭空出生

μ < 0 时一个零点也没有，状态一路向左跑掉。把滑块推过 0，一对不动点同时出现：右边那个稳定（实线），左边那个不稳定（虚线）。

02 / 03 · 跨临界

ẋ = μx − x²：交换身份

这里零点从来不会消失：x* = 0 一直都在。μ 过 0 时它把"稳定"这件外套脱给了新来的 x* = μ。个数不变，只是换了手。

03 / 03 · 叉式

ẋ = μx − x³：对称的两支一起张开

μ < 0 时只有 0 是稳定的。过 0 之后，0 失稳，左右对称地长出两支。系统本来对称，最终却只能挑一边住下——这就是对称破缺。

§3.1 · 鞍-结分岔

鞍结分岔：两个不动点相撞，一起消失

规范形（normal form）是

ẋ = μ − x²

三种情形手算就够：μ > 0 时有两个零点 x* = ±√μ；μ = 0 时合成一个 x* = 0；μ < 0 时一个都没有。

稳定性由 f′ = −2x 给出：x* = +√μ 处 λ < 0（稳定），x* = −√μ 处 λ > 0（不稳定）。所以在分岔图上，一条实线、一条虚线，从 μ_c = 0 处一起竖直地张开。

名字的来历：二维系统里这两个点分别是一个鞍点与一个结点（第 5、6 章），相撞后湮灭。一维里你看不到鞍，但习惯叫法沿用下来了——也叫折叠分岔（fold bifurcation）。

鞍结分岔图：μ < 0 时一片空白，μ > 0 时一支稳定、一支不稳定。两支在 μ_c = 0 处相撞（竖直切线是它的签名）。
§3.1 鞍-结分岔
§3.1 · 机制

为什么是相撞，而不是擦肩而过

把 f(x) = μ − x² 的图画出来，然后把 μ 一点点往下调：整条抛物线在竖直平移。它和横轴的交点，先是两个（一上一下），然后合成一个（相切），然后没有。

"相切"这一刻就是分岔点。此时 f = 0 且 f′ = 0——两个条件同时成立。这就是 §2.4 里判据失效的那个情形，也解释了为什么分岔总发生在 λ = 0 的地方。

分支的形状由什么决定？在 μ 略大于 0 处，x* = ±√μ ∝ (μ−μ_c)1/2。指数 1/2 是可以量出来的：在双对数图上量 x* 与 μ−μ_c，斜率会得到 0.5。数值与实验都这么认。

三个可检查的签名

· 不动点个数：0 → 1 → 2
· 分岔点处 f = 0 且 f′ = 0（切触）
· 分支在 μ_c 处竖直，x* ∝ ±√(μ−μ_c)

一维里它会骗你一次

现实中几乎见不到"恰好相撞"：参数总有别的成分。给 μ 加一个常数偏移，相撞就变成"贴一下又分开"——那就是 §3.6 的不完美分岔。所以实验里说"观察到鞍结分岔"，通常只是"在分辨率尺度内看起来像"。

§3.1 鞍-结分岔
跨临界分岔：x* = 0 与 x* = μ 两条直线在原点交叉。交叉前后，各自把"稳定"让给对方。
§3.2 · 跨临界分岔

跨临界分岔：稳定性换了手

第二种规范形（transcritical bifurcation）：

ẋ = μx − x² = x(μ − x)

零点永远是两个：x* = 0 和 x* = μ。没有一个会凭空出现或消失。变化的是稳定性：

· 对 x* = 0：λ = f′(0) = μ，所以 μ < 0 稳定、μ > 0 不稳定。
· 对 x* = μ：λ = μ − 2μ = −μ，符号正好相反。

于是两条分支在 μ_c = 0 处交叉，稳定性在这一刻交换。分岔图上你看到的是两条直线穿过彼此，而不是一对新点冒出来。

这种分岔为什么"必须有"？因为很多系统里 x = 0 是一个不依赖参数的物理状态（无光、无粒子、无位移）。它不能消失，只能失稳。跨临界分岔就是零点旁边那个新状态把稳定性夺走的标准剧本。

§3.2 跨临界分岔
§3.2 · 判据

什么时候会遇到跨临界，而不是鞍结

看 f(x,μ) 在原点附近的泰勒展开（下标表示偏导，后面乘的是增量）：

f ≈ f(0,μ) + (∂f/∂x) · x + ½(∂²f/∂x²) · x² + …

跨临界的三个条件（缺一不可）：
① f(0,μ) ≡ 0 对一切 μ 成立——平凡解 x = 0 永远在；
② ∂f/∂x(0,μ_c) = 0——线性项恰在这一点过零，也就是稳定性换手的时刻；
③ ∂²f/∂x² ≠ 0 且 ∂²f/∂x∂μ ≠ 0——展开里必须真的有 x² 和 μx 两项。

三者一满足，重标度之后就得到 μx − x²。

反过来，只要 ① 不成立（f(0,μ) 不恒为零），零点就没有"永远存在"的资格，只能靠切触从无到有——那是鞍结。只看到"曲线恰好穿过原点"就判跨临界，是最常见的误判：那可能只是一次恰好路过原点的鞍结。

跨临界的典型场景

平凡解天然存在：无激光时的光子数 n = 0；无人时的种群 x = 0；无疫情时的感染人数 I = 0。这类模型的阈值现象几乎都是跨临界。

一个常用的检验

把 ẋ = f 改写成"ẋ = x · g(x,μ)"。若 g(0,μ_c) = 0，就是跨临界的信号。μx − x² 正好是 x(μ − x)（鞍结写不出这个形式）。

下一节就是它的实物版本——也是全书少数几个"分岔能直接量出来"的实验系统之一。

§3.2 跨临界分岔
§3.3 · 激光阈值

激光是怎么"突然"亮起来的

激光器里有两件事在竞争：受激辐射让光子数增加，逃逸与吸收让光子数减少。设 n = 光子数、N = 上下能级的粒子数反转、G = 增益系数、k = 光子衰减率：

ṅ = GnN − kn

粒子数反转 N 自己也在变：泵浦在补充它，受激辐射在消耗它，严格地说这是两个变量的系统（第 6 章会算）。原书的处理是用准静态拟设把 N 消掉。理由是物理的：受激辐射是逐个消耗反转的——每发出一个光子，就有一个原子从高能级跌回低能级，所以 N 随 n 线性下降，取最简形式

N = N₀ − αn ， α > 0

N₀ 由泵浦决定（泵得越猛，反转越高）；−αn 是"每多一个光子，就多消耗一点反转"。代回上式：

ṅ = k(P − 1)n − Γn² ， P = GN₀/k

其中 P = GN₀/k 是无量纲的泵浦强度（"增益是损耗的几倍"），而 Γ = αG 是常数——它不随泵浦变。这一点很关键：下一页"输出随泵浦线性增长"的斜率就靠它。

这一项的物理作用是把方程从指数增长里救出来：光子越多，每个光子分到的净增益越少；同时它把分岔钉在 P = 1——那里一阶项消失，正是跨临界分岔的签名。
边界要说清：这个模型把受激原子的动力学压成了准静态，而且不含自发发射项，所以 n* = 0 是"精确的零"；真实激光在阈值以下仍有微光。补上这两样就是原书练习 3.3.1／3.3.2 的二维模型。

§3.3 激光阈值
激光的分岔图：泵浦 P < 1 时唯一稳定的状态是 n* = 0（没有激光）。越过 P = 1，零解失稳，n* = P − 1 这支接管。
§3.3 · 阈值

阈值：零解交出稳定性

方程 ṅ = k(P − 1)n − Γn² 是 n 乘出来的，所以 n* = 0 永远是解。另一个解：

n* = k(P − 1)/Γ

稳定性看导数：f′(n) = k(P − 1) − 2Γn。
· 在 n* = 0：λ = k(P − 1)，P < 1 时稳定。
· 在 n* = k(P−1)/Γ：λ = −k(P − 1)，符号相反。

和 §3.2 一模一样：两条分支交叉，稳定性换手。这就是跨临界分岔，阈值在 P = 1：增益刚好补偿损耗。

实验上对得上的三件事：
① 阈值以下是自发辐射——光弱、方向杂、相位乱，这在物理上就是"没有激光"；
② 越过阈值，输出功率随泵浦线性增长（n* ∝ P−1），斜率 k/Γ = 1/α 是常数；
③ 阈值处没有跳跃、没有滞后：跨临界是"软"的，功率从零平滑长出来。

条件：以上三条依赖准静态拟设（原子跟随光子）。弛豫不满足时会出现"开灯前的尖峰"与阻尼振荡——那是原书练习 3.3.1／3.3.2 的二维模型，正式机制是第 8 章的霍普夫分岔；一维模型看不见它。

§3.4 · 叉式分岔

叉式分岔：一支分成三支

第三种规范形（pitchfork bifurcation），超临界版本：

ẋ = μx − x³

零点：x* = 0 永远存在；另有 x* = ±√μ（只在 μ > 0 时是两个实数）。稳定性：

· f′ = μ − 3x²，在 0 处 λ = μ；
· 在两支处 λ = μ − 3μ = −2μ < 0（μ > 0）。

所以 μ < 0 时只有一个稳定点 0；μ > 0 时 0 变不稳，两侧各长出一个稳定点。图上是"丫"字形，所以叫叉式。

关键差异：鞍结是"无中生有一对"，跨临界是"换手"，叉式是一对一地分裂成两支——而它之所以能这么分裂，是因为方程对称：把 x 换成 −x，方程一字不变。这条对称性是叉式分岔的入场券，下一页专讲。

超临界叉式分岔：μ < 0 只有一条稳定支；μ > 0 时中间那支变虚，两侧各长出一条实线。两支严格对称。
§3.4 叉式分岔
§3.4 · 对称破缺

对称的方程，为什么给不对称的解

方程 ẋ = μx − x³ 在 x → −x 下不变。这意味着：若 x(t) 是解，则 −x(t) 也是解。

可系统最终只能待在一处。若它落在 x* = +√μ，那 −√μ 那条路它就再也走不到了——解本身破坏了方程的对称性。这叫对称破缺（spontaneous symmetry breaking）：对称性没丢，只是被"选一个"这件事藏起来了。

对称性在数学上省了什么

把 f 按 x 展开，奇对称一口气杀掉常数项与 x² 项，只剩 a(μ)x + b(μ)x³ + …。
于是"零点"和"三支"这两件事都成了代数结果，不用逐项验证（推导 2 会走一遍）。

现实为什么总是不完美的

真实的环、梁、电路都有微小不对称：加工误差、重力、地磁。只要加一个常数项 h，叉子就断成两支——下面是 §3.6 的故事，也是所有"理想分岔"在实验室里活不长的原因。

还有一件事值得提前记住：如果三次项系数反号（ẋ = μx + x³），非零支会出现在 μ < 0 一侧，并且是不稳定的。那是亚临界叉式分岔，会带来跳跃与滞后——第 8 章的 Hopf 分岔有完全相同的两种版本。

§3.4 叉式分岔
§3.5 · 旋转环上的过阻尼珠子

旋转环上的珠子：一个能拿在手里的分岔

拿一个圆环，让它绕竖直直径以角速度 ω 旋转，环上套一颗珠子（bead），泡在黏稠液体里。这就是原书那个经典装置——因为所有参数都能拧，它几乎是叉式分岔的实体模型。

设 φ 从最低点量起。沿切向有两个力：重力把珠子拉回最低点（−g sin φ），离心力把它推离转轴（切向分量 ∝ ω² sin φ cos φ）。过阻尼时惯性可忽略，力矩平衡给出

φ̇ = (sin φ / b)(ω² cos φ − g/R)

其中 b 是阻尼系数、R 是环半径。定一个临界转速 ω_c² = g/R，再令 μ = ω²/ω_c²：

φ̇ ∝ sin φ · (μ cos φ − 1)

物理读法：转速不够时，重力赢，珠子待在最低点；转速够快时，离心力赢了，最低点不再是舒服的位置——珠子被甩到两侧某个高度上，在那里重力的切向分量恰好抵消离心力的切向分量。

注意这个装置的边界：忽略惯性要求 m/b 足够小（§2.6 案例）。把珠子改放进水里，它就会绕着新平衡点摆动，那时模型是二维的。

§3.5 旋转环上的过阻尼珠子
§3.5 · 解出来

偏出来的角度 ∝ √(ω²−ω_c²)，高度是线性的

零点：f = sin φ(μ cos φ − 1) = 0。
① sin φ = 0 → φ* = 0（最低点）或 π（最高点）；
② cos φ* = 1/μ，只在 μ > 1 时有解，给出对称的两个新平衡位置。

稳定性算一次就够：f′ = μ(2cos²φ − 1) − cos φ。
· φ* = 0：f′ = μ − 1 → μ < 1 稳定 ✓
· φ* = π：f′ = μ + 1 > 0 → 永远不稳定（飞轮不会停在正上方）
· cos φ* = 1/μ：f′ = 1/μ − μ < 0（μ > 1）→ 稳定 ✓

把纵轴取成 cos φ* 而不是 φ*，图就变成标准叉式：一支在顶上（φ* = 0），一支在底下（φ* = π），第三支是 cos φ* = 1/μ。

张开得有多快？令 δ = μ − 1 很小，cos φ* = 1/(1+δ) ≈ 1 − δ，而 1 − cos φ* ≈ φ*²/2，所以 φ* ≈ ±√(2δ)：φ* ∝ √(ω²−ω_c²)。指数又是 1/2——这是叉式分岔的指纹。
顺便把"高度"说清：珠子偏出去的高度是 R(1 − cos φ*) ≈ Rφ*²/2 ∝ δ，角度按 √ 张开，高度却是线性的。量的是哪一个，标度指数就不同——实验报数时必须讲清楚。

左：装置——环绕竖直轴转动，珠子角度 φ 从最低点量起。右：分岔图，纵轴用 cos φ*。最低点那支在 ω_c 处失稳，新平衡位置从 cos φ* = 1 处张开。
§3.5 旋转环上的过阻尼珠子
浅虚线是完美叉式（h = 0）。加一个常数项 h = 0.18 之后，叉子的柄断开了：一支贯穿全场，另一支变成 C 形，与它之间隔着一个鞍结点。
§3.6 · 不完美分岔与突变

加一个常数项，叉子就断了

真实的旋转环不可能绝对对称：重心偏一点、桌面不平一点。把这些统统塞进一个常数 h：

ẋ = h + μx − x³

现在 x → −x 不再是对称操作（因为 h 不跟着变号），奇对称被破坏。后果不是"稍微挪一下"，而是拓扑上的改变：

· 原来看作"一个点分叉成三个"的地方，现在是两个彼此分开的鞍结分岔；
· 中间隔着一段三个不动点（两个稳定、一个不稳定）并存的参数区间；
· 在这段区间里，系统的终局取决于历史——它是从哪边过来的。

h 越小，断口越窄：当 h → 0，两个鞍结点重新贴近，叉式分岔恢复。完美的分岔是"余维 2"的（要同时满足两个条件），而现实中你只能设定一个参数——所以实验室里看到的几乎总是"不完美"的那个版本。

这解释了为什么"突变"这个词会出现在这里：μ 慢慢拧，系统会在某一点突然跳到另一支上去（突变，catastrophe），而拧回来时它不跳回来。下一页算这段滞后。

§3.6 不完美分岔与突变
§3.6 · 突变与滞后

跳过去，就回不来了

拿 ẋ = h + μx − x³，固定 h = 0.18，把 μ 从很小的值慢慢加大，再慢慢减回来。会发生两件不对称的事。

正向：μ 增大

系统停在"靠上的那支"上（x > 0，贯穿全场的那支）。它一路平稳地跟着移动，什么都不会发生——因为它一直存在、一直稳定。

反向：μ 减小

如果系统已经被推到 x < 0 的那一支上，往回拧时它会在鞍结点处被消灭：两个不动点相撞，它无处可去，只能跳到上面那支去。这个跳变不可逆。

把"上去"和"下来"的跳变点画在同一张 x–μ 图上，就得到一个滞后环（hysteresis loop）：两条路径不重合，中间夹着双稳区。

三个必须记住的要点：

① 滞后 = 双稳 + 两个鞍结。没有双稳就没有滞后；双稳的两个边界都是鞍结分岔。
② 跳变点是可预测的：它就是鞍结点，条件 f = 0 且 f′ = 0，解这两个方程即可。
③ 噪声能提前"偷跑"：真实系统里，还没到鞍结点，随机扰动就可能把状态踢过中间的不稳定支。此时跳变的位置依赖噪声强度，不再由分岔图决定。

第 8 章会看到，同一个滞后结构在受迫摆和约瑟夫森结上重演，只不过那里的双稳来自"同宿轨道"而不是鞍结。形状记住了，换系统就不慌。
§3.6 不完美分岔与突变
§3.7 · 昆虫爆发

昆虫爆发：直线与曲线谁高

云杉芽虫（spruce budworm）是北方针叶林的大害虫：多数年份几乎找不到，每隔若干年却会把整片林子吃秃。两种状态都稳定——这正是我们刚学过的双稳。

模型把两件事写在一起：自身增长按逻辑斯谛，被鸟吃掉的部分是饱和的（鸟吃饱了就吃不动，所以捕食率先升后降）：

ẋ = rx(1 − x/K) − Bx²/(A² + x²)

求平衡时把 x 约掉（x = 0 永远是一个解），得

r(1 − x/K) = Bx/(A² + x²)

左边是一条直线，右边是一条驼峰形的曲线。所以非零不动点＝两者的交点。图解法比求根公式更可靠：它一眼告出交点有几个、在哪儿。

别忘了 x = 0 本身也是不动点，而且 f′(0) = r > 0，是不稳定的（种群很小时总是往上长）。所以一共 4 个不动点：0，加上图里数出来的 1 个或 3 个。下面说的"低密度支"指的是那个小的正根，不是 0。

取 r = 0.4、A = B = 1（无量纲）。K = 5 时直线从驼峰上方过，只有一个交点；K = 14 时直线切进驼峰，交点变成三个（实心＝稳定，空心＝不稳定）。
§3.7 昆虫爆发
§3.7 · 两个鞍结

阈值在中间，两个世界在两边

三个交点按大小排开，命运依次是：稳定 → 不稳定 → 稳定。它们各有名字：

低密度支（小根）

虫子藏在树缝里，鸟吃得干净。稳定。
这就是"看不出有虫"的那些年。

阈值支（中间根）

不稳定。它不是能待住的状态，而是一条分界线：虫口超过它，鸟吃不完，森林就失控。

爆发支（大根）

稳定。树木被吃光后食物变少，虫口自己回落一点，但仍停在高位。

交点从 1 个变成 3 个，只需一次切触：直线与驼峰相切的那一瞬（r = 0.4 时在 K ≈ 9.56），一对不动点同时出生。
口径要收窄：本节固定 r = 0.4、只扫 K，所以整条 K 轴上只有一个鞍结。升 K 时中根与大根一起出生；降 K 时它们又在同一点一起湮灭——升 K 时系统一路停在低支（新生的爆发支不会自动接管），降 K 时一路停在爆发支，直到 K ≈ 9.56 两根湮灭才跳回低支。滞后仍然成立，但它只由这一个鞍结束缚。
要真的看到两个鞍结，得固定 K（取在 cusp 之上，例如 K = 8）改扫 r：那才会先后穿过两条分岔曲线，形成完整的滞后环。这两条曲线在 (r, K) 平面上合成一个尖点（cusp），只有尖点张开的那片区域内才有三个不动点。这就是突变理论里最基础的"尖点突变"。

三个必须带上的条件：① 捕食必须饱和（没有驼峰就没有双稳）；② 空间必须均匀（真实林子有斑块，虫口可以在局部先爆）；③ 没有噪声（风、寒潮、病害；真实爆发往往由噪声"点火"，分岔图只说明"点着了就能烧"）。

顺带回收 §3.6：这里的双稳与滞后，和旋转环上的不完美分岔是同一个几何——中间夹一支不稳定，两边各一支稳定。

§3.7 昆虫爆发
PROOF 01 · 完整推导

为什么所有鞍结都长 μ − x² 那个样

完整推导规范形定理的构造性证明 + 退化自检 + 边界

要证．设 f(x,μ) 光滑，在 (x*, μ_c) 处
f = 0（是平衡点）、∂f/∂x = 0（线性判据失效）、∂f/∂μ ≠ 0、∂²f/∂x² ≠ 0。
则存在局部的光滑坐标变换，把方程化成 ẏ = μ̂ − y²（或 μ̂ + y²，两者差一次时间反演）。

1平移．令 x = x* + u、μ = μ_c + ν。因为 ẋ = u̇，在 (0,0) 处展开：

u̇ = a ν + b u² + O(u³, u²ν, uν²)

其中 a = ∂f/∂μ ≠ 0、b = ½∂²f/∂x² ≠ 0。一次项 u 的系数是 ∂f/∂x，按假设为 0，所以第一项就是二次项——这一步是整个定理的心脏。

2标度．令 u = αy、ν = βμ̂，代入并除以 α：

ẏ = (aβ/α) μ̂ + (bα) y² + 高阶

取 α = 1/|b|，则 bα = ±1；再取 β = α/|a|，则 aβ/α = ±1。合法，因为 a、b 都不为零，除法可用。

3定符号．得到的方程是 ẏ = σ₁μ̂ + σ₂y²。把 μ̂ 重新定义成 σ₁μ̂，两种情形只剩 ẏ = μ̂ ± y²。而 ẏ = μ̂ + y² 换 t → −t 并翻 μ̂ 的号就是 ẏ = μ̂ − y²。所以在"差一个时间反演"的意义下只有一种鞍结。

退化自检．取 f = μ − x²：a = 1、b = −1，第 2 步给出 ẏ = μ̂ − y²，即规范形本身 ✓（变换是恒等变换的那一次）。再取 f = μ − x⁴：∂²f/∂x² = 0，第 2 步的 α 取不出来，定理不适用；实际分支是 x* = ±μ1/4，指数从 1/2 变成 1/4。这说明"∂²f/∂x² ≠ 0"不是技术性小条件，它决定了标度指数的值。

为什么它解释了"竖直切线"．由隐函数定理，只要 ∂f/∂x ≠ 0，分支 x*(μ) 就光滑；分岔点恰是隐函数定理失效的地方（∂f/∂x = 0），于是曲线在那里允许出现两支、允许竖直。

失效边界．① ∂²f/∂x² = 0：更高阶退化，指数变 1/4 或更怪；② ∂f/∂μ = 0：拧参数的这条方向恰好切于 f 的等值线，看不到分岔（需要两个参数才能打开）；③ f 不光滑（如 |x|）：展不开；④ 二维以上，先要沿"中心流形"约化成一维，本定理才接得上——那是第 8 章的话。

§3.1 鞍-结分岔
PROOF 02 · 完整推导

对称性怎么逼出一对分支，还逼出 1/2

完整推导奇对称 → 只有奇次项 → 分支位置与指数

出发点．设 ẋ = f(x,μ)，f 光滑且奇对称：f(−x,μ) = −f(x,μ)，对一切 μ 成立。（旋转环在 h = 0 时、对称鞍座、对称电路都满足它。）

1只有奇次项．把 f 在 x = 0 处展开成幂级数。奇对称意味着偶次系数全为零（否则把 x 换成 −x 会多出符号不同的项）：

f = a(μ) x + b(μ) x³ + O(x⁵)

顺带得到一个免费结论：f(0,μ) = 0，所以 x* = 0 对一切 μ 都是不动点。它不可能"生出来"或"死掉"，只可能失稳。

2分支位置．非零不动点由 a(μ) + b(μ)x² = 0 给出：

x* = ±√( −a(μ)/b(μ) )

实数解要求 a/b < 0。设 a(μ_c) = 0 且 a′(μ_c) = A ≠ 0、b(μ_c) = B ≠ 0，则在 μ_c 附近 −a/b ≈ −A(μ−μ_c)/B，符号由 (μ−μ_c) 与 −A/B 决定。

3稳定性与指数．λ(x) = ∂f/∂x = a + 3bx²。
· 在 0 处：λ = a(μ)，恰在 μ_c 过零——分岔点就是线性判据失效点。
· 在非零支：λ = a + 3b(−a/b) = −2a，与 a 反号。
所以当 B < 0、A > 0（超临界）时，μ > μ_c 上 0 不稳、±√(−a/b) 稳定。振幅：

|x*| = √( A(μ−μ_c)/|B| ) ∝ (μ−μ_c)^{1/2}

退化自检．取 a = μ、b = −1（正是 ẋ = μx − x³）：x* = ±√μ ✓。再把 μ 固定在 1：x* = ±1，与第 2 章 ẋ = x − x³ 的三个零点完全一致 ✓。取 b = 0：ẋ = μx − x⁵，同样手法给出 x* ∝ μ1/4，指数变了——和鞍结那里一模一样。

失效边界．① 奇对称是硬前提：加一个常数 h 就破坏它，叉子断成"一支 + 一个 C 形"（§3.6）；② 只在此点附近成立，远处的高阶项会改写分支形状；③ 若 B > 0（亚临界），非零支出现在 μ < μ_c 且不稳定，系统会在 μ_c 处跳变——这是滞后与"硬激发"的来源，第 8 章 Hopf 分岔同构。

§3.4 叉式分岔
CHECK · 自测

五道题：先判断形状，再算数

—
TAKEAWAY · 带走

三张图就是字典

鞍结（μ−x²）：一对不动点相撞后湮灭。签名：个数 0↔2，切触处 f=f′=0，分支竖直，x* ∝ ±√(μ−μ_c)。

跨临界（μx−x²）：零点从不消失，只交换稳定性。签名：能写成 x·g(x,μ)，且 g(0,μ_c)=0。激光阈值就是它。

叉式（μx−x³）：一支分裂为三支，两支对称。签名：方程在 x→−x 下不变，振幅 ∝ √(μ−μ_c)。

但这三张图都是"理想对称"的。真实系统只要加一个常数项，叉子就断成两个鞍结 + 一段滞后。所以分岔图要当字典用，不当预言用：先认形状，再问"哪个不完美条件把它掰弯了"。

两个常见误读

误读一：把分岔图当时间史。它上面没有时间——横轴是参数，不是 t。
误读二：以为"过了分岔点旧状态就没了"。错：它只是失稳，物理上常常还能短暂停留（滞后、亚临界跃迁都靠这个）。
