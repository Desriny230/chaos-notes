§6.0–6.1 · 引言与相图

从一条线，到一张图

第 2 章的世界是一条线：所有命运都写在 f 的零点之间。第 4 章把它接成圆圈，于是"一直转"成了可能。现在再放开一个维度——两个变量，相空间就成了平面。

平面上的东西比线丰富得多，但可用图元只有三类：

① 不动点。矢量场为零的孤立点。局部行为由上一章的六个名字管（结点/鞍点/焦点/中心）。

② 闭轨。首尾相接的轨道。这是线的世界里没有的东西，平面上第一次出现。它可能是一族（保守系统的中心附近），也可能是孤立一条（极限环，第 7 章）。两者天差地别，本章先把前者弄清楚。

③ 分界线（separatrix）。不是轨道本身，而是"命运的分水岭"：落在它两侧的初值走向完全不同的终点。鞍点的稳定流形是最常见的分界线。

读相图的口诀：先找不动点，再找闭轨，最后看分界线怎么切。三样东西找齐，这张图就说完了——哪怕一个公式都解不出来。

§6.1 · 读图规则

相图的四条读法

一、每个点是一个状态，不是一段时间。点 = (x, y) 的某一刻取值；轨道 = 一段时间的历史。时间被"折进"了曲线里：走完全程的时间就是积分的时长。

二、轨道永不相交。同一点上矢量场只有一个方向，所以只有一条轨道经过。这条规则的正式依据是 §6.2 的唯一性定理——它是整章所有几何论证的地基。

三、箭头的朝向表示方向；如果画了长度，长度才表示快慢。本章的图两者都有：靠近不动点处箭头短（走得慢），这是判断"会不会趋近"的第一线索。

四、看终点，不看过程。相图回答的是"最终会怎样"，不是"几点几分到哪儿"。要把时间找回来，得另外积分（或者用 §6.7 的办法从相图算周期）。

还有一条实践建议：零倾线（nullcline，ẋ = 0 或 ẏ = 0 的曲线）先画出来。它们的交点是不动点，它们把平面切成几块；在每一块里，矢量场的四个方向（↗↘↙↖）是确定的。这比一上来就算轨迹快得多。

§6.2 · 存在性、唯一性与拓扑结果

为什么轨道不能相交

定理（局部存在唯一性，二维版）。若 f、g 及其一阶偏导连续，则对每个初值 (x₀, y₀)，存在一个时间区间上唯一的解曲线。

这正是 §2.5 在二维的推广（条件从"f 连续可微"换成"f、g 的偏导连续"）。它给出的几何结论只有一句：轨道不相交。两条轨道若在某点相遇，之后必须完全重合。

由此推出三个在本章反复使用的事实：

① 保守系统的闭轨不吸引。守恒量一存在，轨道就被锁在自己的等能线上，不可能被吸到另一条线上。注意别推广过头：二维里确实存在"吸引的闭轨"，那就是极限环（第 7 章）——本章这些闭轨都是成族的，没有一条特殊。至于"闭轨内部必须有不动点"，那是另一个理由（§6.8 指数定理），与吸引无关。

② 单调性。沿轨道，任何函数（比如能量）的变化率如果是定号的，它就不能回头。这是第 7 章"排除闭轨"的主要武器（李雅普诺夫函数）。

③ 封闭区域里的轨道"出不去也停不住"。若一条轨道被关在一个紧致的、不含不动点的区域里，它就只能永远绕——庞加莱–本迪克松定理（第 7 章）正是把这句话变严格。

边界：唯一性要求右端光滑。像 ẋ = √x 那样在原点丢掉李普希茨条件的系统，轨道可以在奇点处"分叉"（§2.5 反例），相图也就不再是"一族不相交曲线"。

§6.3 · 不动点与线性化

Hartman–Grobman：局部看，它就是线性的

设 (x*, y*) 是不动点。令 u = x−x*、v = y−y*，在不动点处做一阶泰勒展开：

[u̇, v̇]ᵀ ≈ J [u, v]ᵀ ， J = [[f_x, f_y], [g_x, g_y]]

J 叫雅可比矩阵（Jacobian）。于是上一章的全套工具立刻可用：算 τ = tr J、Δ = det J，查表叫名字。

定理（Hartman–Grobman）

若不动点是双曲的——即 J 的所有特征值实部都不为零——则非线性系统在不动点附近与它的线性化拓扑等价：轨道的拓扑布局一一对应（可以把一族连续变形成另一族）。

"拓扑等价"是个恰好的强度：它保证名字对，但不保证形状一模一样。线性化说"稳定焦点"，非线性系统的轨线也绕着螺旋进来，只是螺旋可能略扁、略斜。名字对了，就够了——因为本章关心的正是定性命运。

三个必须记住的条件：① 双曲（Re λ ≠ 0）；② 局部（只在不动点的某个邻域里成立，远处不受管辖）；③ 光滑（f、g 的偏导连续）。

注意判"双曲"不看 τ：τ = 0 但 Δ < 0 的鞍点（特征值 ±√(−Δ)）照样双曲；真正要躲的是纯虚根（中心）与零特征值（Δ = 0）。

§6.3 不动点与线性化
§6.3 · 非双曲的危险

线性化什么时候会骗你

定理的例外只有一类：非双曲不动点。这时线性化给不出结论，一切由高阶项说了算。两个经典反例：

反例一：线性化说是中心，实际是螺旋。系统 ẋ = −y + x(x²+y²)、ẏ = x + y(x²+y²)。J(0,0) = [[0,−1],[1,0]]，τ = 0、Δ = 1 → 线性化判"中心"。但换成极坐标 r² = x²+y²，一眼就看出 ṙ = r³ > 0：它是向外发散的螺旋，越转越远。

反例二：把符号翻过来。把上面那条的 x(x²+y²) 改成 −x(…) 与 −y(…)，则 ṙ = −r³ < 0，变成向内收敛的螺旋。线性化部分一模一样，非线性项改个符号，命运就反了。

所以规矩是：先算线性化，再答一句"双曲吗"。双曲 → 放心用表；非双曲 → 表作废，必须另找办法（守恒量、李雅普诺夫函数、高阶项、或直接数值）。

这两个反例还说明一件事："中心"是最脆的结论（§5.2 推导 2 已经用守恒量解释过为什么）。真实系统里凡是"看起来像中心"的，都值得再确认一下有没有微小的耗散或激励。

§6.4 · 兔子与羊

兔子与羊：同一片草场上的两种结局

一片草场，两种食草动物。设 R = 兔子数、S = 羊数。各自按逻辑斯谛的脾气增长，但吃的是同一份草——于是对方的数量会压低自己的增长率。取最简的线性压制：

Ṙ = R(3 − R − 2S) ， Ṡ = S(2 − R − S)

系数可以读出来：R 的方程里 −2S 说明一只羊顶两只兔子（羊吃得多）；S 的方程里 −R 说明一只兔子对羊的压制与一只羊相当。两个"3"和"2"是各自的内禀增长率。

第一步永远是找零倾线（Ṙ = 0 或 Ṡ = 0 的曲线）：

· Ṙ = 0：R = 0 或 R + 2S = 3；
· Ṡ = 0：S = 0 或 R + S = 2（或 S = 0）。

两条斜线相交于 (1, 1)，再加上轴上的三点，共四个不动点：(0,0)、(3,0)、(0,2)、(1,1)。它们在一个平面上拼出四块区域，每块里矢量场的方向是固定的——这就是相图的骨架。

下一页把它们连同轨线一起画出来，并逐个判定稳定性。

§6.4 · 判稳

双稳：谁先占住草场，谁就赢

雅可比矩阵（对 R 求偏导、对 S 求偏导）：

J = [[3−2R−2S, −2R], [−S, 2−R−2S]]

逐个代入：
· (0,0)：J = [[3,0],[0,2]]，τ = 5、Δ = 6 → 不稳定结点（两个物种都还少时都涨）。
· (3,0)：J = [[−3,−6],[0,−1]]，τ = −4、Δ = 3 → 稳定结点（兔子全胜）。
· (0,2)：J = [[−1,0],[−2,−2]]，τ = −3、Δ = 2 → 稳定结点（羊全胜）。
· (1,1)：J = [[−1,−2],[−1,−1]]，τ = −2、Δ = 1−2 = −1 → 鞍点。

四个点全部双曲（特征值没有零实部），所以线性化的判定全都可信。

结论：双稳（bistability）。草场最终归谁，取决于初始的兔子与羊的比例——鞍点的不稳定流形就是那条分界线。生态学里这叫"优先效应"：先占住的那一方赢，而且一旦赢定就回不来（要恢复对方只能靠外力介入）。

§6.5 · 保守系统

保守系统：轨道被能量锁在等高线上

如果存在一个函数 H(x, y)（不显含 t），沿轨道恒为常数，就称它是系统的首次积分（first integral）或守恒量，系统叫保守系统。检验条件只有一行：

∂H/∂x · ẋ + ∂H/∂y · ẏ = 0 （沿轨道恒成立）

最常见的一类：机械系统 ẍ = −V′(x)，写成 ẋ = y、ẏ = −V′(x)，则

H = ½y² + V(x) ， Ḣ = y·ẏ + V′(x)·ẋ = y(−V′) + V′y = 0

"动能 + 势能"。三个立刻的推论：

① 没有吸引子。轨道不能终止在某个点上——那会要求 H 变化。所以保守系统里既没有稳定结点也没有稳定焦点，只有中心和鞍点。

② 轨道就躺在 H 的等高线上。整张相图 = 一张地形图的等高线。要画相图，先画等高线。

③ 闭轨成族，周期依赖初值。换一条等高线就是另一个周期，且周期一般随能量变（§6.7 会算钟摆）。

边界：大多数二维系统没有首次积分——可积是稀有品。有摩擦、有驱动、有非保守力时，H 不再守恒，等高线会变成螺旋。

§6.5 保守系统
§6.5 · 等高线

相图就是地形图的等高线

取双井势能 V(x) = x⁴/4 − x²/2（两个谷、一个山顶），系统 ẋ = y、ẏ = −V′(x) = x − x³。

等高线 H = ½y² + V(x) = 常数，就是图中那些闭合的环。谷底 (±1, 0) 是中心：V 的极小点，H 的极小点。小能量时，轨道是绕着谷底的小环（在谷里来回荡）。

山顶 (0,0) 是鞍点：V 的极大点。能量刚好等于 0 的那条等高线是分界线——它把左右两个"谷"隔开。

能量高于 0 的轨道不闭合：它会翻过山顶、跑到另一个谷、再翻回来……但它其实是在整条势能曲线上来回跑。（这里势能在无穷远处趋于无穷，所以高能轨道仍是"往返"的，但不再局限在一个井里。）

这张图解释了保守系统的脆弱：等高线是"精确守恒"的结果。加一点点阻尼，H 就单调下降，环立刻变成向内收的螺旋。

双井的等高线族。实心橙点＝两个谷底（中心），空心点＝山顶（鞍点），金色虚线＝分界线（H = 0）：它从鞍点出发、绕成两个"花瓣"，把平面分成"左井""右井"和"外面"三块。

§6.6 · 可逆系统

可逆系统：时间倒着走，图照样对

如果存在一个变换 R（通常是关于某条轴的镜像），使得把时间反过来走（t → −t）同时做这个镜像之后，方程一字不变，就称系统可逆（reversible）。

例子。ẋ = y、ẏ = x − x²，取 R(x, y) = (x, −y)：
· 第一式：左边 ẋ 在 t→−t 下变号，右边 y 在 R 下也变号 → 两边同号，方程不变 ✓
· 第二式：左边 ẏ 变两次号（y 变号 + t 变号）→ 不变；右边 x − x² 只含 x → 不变 ✓

所以这个系统是可逆的。

后果很实用：轨道成对出现——若有一条从 A 走到 B 的轨道，就有一条从 R(A) 走到 R(B) 的轨道（镜像，且走的方向也镜像）。于是：
· 鞍点的稳定流形与不稳定流形互为镜像；
· 图上一半的结构确定了，另一半自动就有；
· 闭轨族非常常见（保守系统就是可逆系统的特例）。

边界：可逆 ≠ 保守。可逆系统未必有守恒量，也未必没有吸引子。可逆性只是"一个对称性"，它能限制相图长什么样，但不能替代动力学分析。

§6.6 可逆系统
同一个系统的轨道族：每一条都有关于 x 轴的镜像伙伴（橙色那一对是特意画粗的）。鞍点 (0,0) 的进出方向也互为镜像；右边那个点在线性化下是中心。
§6.6 · 对称轨线

一条轨道，两条命运：镜像怎么对上

可逆性的用法，看这张图就够了：你只要算出一半，另一半是免费的。

具体到 ẋ = y、ẏ = x − x²：
· (0,0) 处 J = [[0,1],[1,0]]，τ = 0、Δ = −1 → 鞍点；
· (1,0) 处 J = [[0,1],[−1,0]]，τ = 0、Δ = 1 → 线性化给出中心。

注意第二个点非双曲，所以"中心"这个结论需要复核。事实上它确实是中心（这个系统是保守的：H = ½y² − ½x² + x³/3，可以验证 Ḣ = 0），闭合的轨道族就在它周围。

于是左右两边是两种完全不同的世界：左边被鞍点排斥（往外跑，或者绕到右边去），右边被闭轨圈住（原地打转，出不来）。分界线就是鞍点的稳定/不稳定流形。

这也说明可逆性最实用的地方：它让"半边图"变成"整幅图"，还顺便给了你一条复核用的对称线。

§6.7 · 钟摆

钟摆：全书最完整的一张相图

不忽略惯性的钟摆（无阻尼）：

θ̈ = −sin θ ⟺ θ̇ = ω ， ω̇ = −sin θ

它是保守的：H = ½ω² − cos θ（动能加势能；势能的零点可以任取，换零点只差一个常数）。本章统一用这一套：分界线 H = 1，最低点 H = −1。于是整张相图就是 H 的等高线，分三种：

· H < 1（能量不够到顶）：闭合环，来回摆。最低点 θ = 2πk 是中心。
· H = 1（刚好够到顶）：分界线，无限久才爬到正上方。
· H > 1：旋转轨，一圈圈翻过去，ω 永不变号。

正上方 θ = π + 2πk 是鞍点：线性化给 J = [[0,1],[1,0]]，特征值 ±1。

注意这张图的周期性：把 θ 加 2π 图形完全重复。所以整张图是一条无限长的带子，被鞍点串成一串"钟摆世界"。第 4 章的圆上的流，就是这张图卷起来的样子——卷的时候只把 θ 方向粘成环、ω 方向仍然展开，得到的是个圆柱面，不是轮胎面。不过那里是过阻尼（一阶），这里保留了惯性（二阶），于是"停住"变成了"闭轨"。

§6.7 钟摆
§6.7 · 从相图读周期

摆动周期不是常数：能量越大，荡得越慢

相图上一条闭合轨对应一个固定能量 H。走完一圈要多久？把 dt = dθ/ω 沿轨道积一圈：

T(H) = ∮ dθ / ω = 4∫₀^{θ_max} dθ / √( 2(H − V(θ)) )

（因子 4 是因为一个周期要走四段：上、下、各两半。）这个积分只依赖 H——所以"周期"是能量的函数，不是系统常数。

对钟摆，V(θ) = −cos θ（与上一节同一套约定），积分可化成第一类完全椭圆积分 K（第 1 章推导 2 已经算过）：

T/T₀ = (2/π) K( sin(θ₀/2) ) ， T₀ = 2π

三个数（第 1 章复算过）：θ₀ = 10° 时 T/T₀ = 1.0019（钟表匠够用了）；90° 时 1.1803；170° 时约 2.44；θ₀ → 180° 时 T → ∞。

最后的发散正是相图上的分界线：能量刚好够到正上方时，摆爬到顶的速度趋近于零，需要无限久才翻过去。相图上"两条线越来越靠近"，在物理上就是"越来越慢"。

边界：这个公式只对 H < 1（闭合轨）有意义。H > 1 时不存在"来回"，只有"绕圈"，此时该谈的是"绕一圈要多久"，公式要换成另一支。线性化（小角近似）能给出的只有 T₀ = 2π，误差在 θ₀ ≈ 10° 时就已露头。

§6.7 钟摆
§6.8 · 指数理论

指数定理：绕一圈，方向转了几圈

在相平面上画一条简单的闭曲线 C（自己不相交，且不经过任何不动点）。沿着它走一圈，每一处都读一下当地矢量场的方向。走完一圈回来，这个方向也回到原样——但它可能已经绕了若干整圈。绕的圈数（带符号）就叫 C 的指数：

I(C) = (1/2π) ∮_C dφ ， φ = 矢量场的方向角

它一定是整数。因为 φ 沿闭曲线连续变化、回到起点时必须与初值差 2π 的整数倍。整数意味着它不会因为曲线的连续变形而改变——这是拓扑量（同伦不变量），也是它能用来做全局论断的原因。

三个基本事实：
① 曲线内没有不动点时，I = 0。（把曲线缩成一点，方向几乎不变，绕的圈数只能是 0。）
② 闭轨的指数 = +1。（沿闭轨走，速度矢量就是切向量，正好转一整圈。）
③ 一个区域的总指数 = 区域内各不动点指数之和。

由此立刻得到一个漂亮的结论：闭轨内部必然含有不动点，而且这些不动点的指数之和等于 +1。所以"一圈空转、里面什么都没有"的闭轨在相平面上不可能存在——这不是动力学结论，是拓扑结论。

§6.8 · 用法

指数定理能替你排除哪些相图

先记住各类型不动点的指数。做法是围绕该点画一个小圈，看矢量方向怎么转：

指数 +1

结点、焦点、中心：矢量场绕该点"转了一整圈"，与方向盘的转动同向。这三种是"源/汇/涡"，局部方向绕圈而行。

指数 −1

鞍点：进出方向相反，绕一圈时方向角反转了一圈——所以是 −1。鞍点是唯一带负指数的基本不动点。

于是可以不做任何计算就排除掉一批"看起来像"的相图：

· 闭轨里只包一个鞍点？不可能：总指数必须是 +1，而鞍点给 −1。
· 闭轨里包两个鞍点、没有别的点？不可能：−2 ≠ +1。
· 一条闭轨里包一个鞍点和一个结点？不可能：−1 + 1 = 0 ≠ +1——要凑够 +1，还得再有一个 +1 的点。实际上钟摆的"外圈"轨线（H > 1 的旋转轨）不是闭轨，它就是靠这个绕开了限制。
· 整个相平面的所有不动点指数之和（在最外圈算）= +1，这是对"整张图"的一个全局约束。

边界（很重要）：指数定理只说"能不能"，不说"是不是"。它不能告诉你稳定性、不能告诉你周期、也不能保证闭轨真的存在。它是必要条件的筛子，筛掉的可以立刻扔掉，留下的还得逐个数值分析。

PROOF 01 · 完整推导

线性化凭什么可信：双曲是那道闸门

完整推导定理陈述 + 为什么双曲是必需的 + 反例 + 边界

要证（陈述）．设 ẋ = f(x) 的右端 C¹，x* 是不动点，J = Df(x*)。若 J 的所有特征值实部非零（双曲），则存在 x* 的邻域 U 与一个同胚 h，把 U 内的轨道族拓扑地映成线性系统 ẏ = Jy 的轨道族。

1为什么"丢掉高阶项"通常没事．把 f 写成 f(x) = J(x−x*) + R(x−x*)，其中 |R| = O(|x−x*|²)。注意量级：线性项是 O(r)，余项是 O(r²)。只要 r 足够小，余项相对于线性项就是"小扰动"。这就是线性化能用的真正理由。

2为什么"双曲"是必需的．上一段的前提是"线性项不为零"。如果 J 有纯虚特征值，线性部分根本不衰减也不增长（它只是转圈），于是 O(r²) 的余项虽然小，却是唯一决定长期行为的东西——小扰动累积起来就能翻盘。这不是技术性条件，是量级论证本身的要求。

3证明思路（构造）．把非线性系统与线性系统的轨道"逐点对齐"：沿线性流的轨道找一个横向截面，把非线性轨道与它交在同一条截线上，再用连续性把两者粘起来。因为双曲性保证了两族的"骨架"（特征方向）不退化，这个粘贴可以做成连续可逆的。结论是存在性，不是公式——所以叫"拓扑等价"，不叫"相等"。
为什么双曲就够（量级版）．把余项 O(r²) 当小扰动积一小段时间，扰动累积到 O(r²t)；而双曲性保证线性流的谱隙 ν = min|Re λ| > 0，线性部分按 e−νt 收缩。只要 r 小到让 O(r) 追不上 ν，扰动就翻不了盘。这里只给取向；完整证明属于研究生课。

反例（非双曲时整类改判）．ẋ = −y + x(x²+y²)、ẏ = x + y(x²+y²)：J(0) 给中心（τ = 0、Δ = 1，纯虚）。但极坐标下 ṙ = r³，实际是向外螺旋。把最后一个符号改成负号，就是向内螺旋——线性化部分一模一样。

退化自检．若系统本来就是线性的，R ≡ 0，h 取恒等映射即可 ✓，定理退化成"自己等于自己"。

边界．① 局部：U 可能很小，吸引域之外的说法它一概不管。② 要求 C¹（实际上 C¹ 足够，更光滑只影响 h 的光滑度）。③ 非双曲时必须换工具：中心流形约化（把"临界方向"单独留下）、守恒量、或直接数值。本章所有"线性化判稳"的结论后面，都默认挂着"该点双曲"这张许可证。

§6.3 不动点与线性化
PROOF 02 · 完整推导

守恒量怎么找，周期怎么积出来

完整推导一维力学的首次积分 + 周期积分公式 + 自检 + 边界

出发点．机械系统 ẍ = F(x)。如果 F 只依赖位置（没有速度项、不显含时间），就能定义势能 V(x) = −∫F dx。写成两个一阶方程：ẋ = y、ẏ = −V′(x)。

1构造守恒量．令 H = ½y² + V(x)。沿轨道求导：

Ḣ = y·ẏ + V′(x)·ẋ = y(−V′) + V′·y = 0

所以 H 是首次积分 ✓。这不是碰巧：能量守恒就是"力只依赖位置"的直接后果。

2从守恒量解出速度．由 H = 常数解出 y = ±√(2(H − V(x)))。于是轨道被写成"速度关于位置的显式表达式"——整张相图就是这条式子的图像。

3积出周期．由 dt = dx/y，沿一条闭合轨（在转折点 x₁、x₂ 之间来回）有

T(H) = 2∫_{x₁}^{x₂} dx / √( 2(H − V(x)) )

分母在转折点为零，但零点处是"平方根型"奇点，积分收敛（可积）。

退化自检．取谐振子 V = ½x²：H = ½y² + ½x²，转折点 x₂ = √(2H)。则 T = 2∫−√(2H)√(2H) dx/√(2H−x²) = 2π。与 H 无关 ✓ ——这正是"谐振子周期是常数"的几何解释：等高线是圆，半径不影响绕圈角速度。

边界．① 只有"力只依赖位置"（保守）时才有这个 H；有阻尼或驱动力就没有。② 若 V 的形状更复杂（多个谷），同一条 H 可能对应几条不相连的轨道，积分要分片。③ 这个公式给出的是周期；它不告诉你轨道"绕向哪边"（由初值定），也不告诉你稳定性——保守系统没有吸引子，谈不上稳定。

§6.5 保守系统

TAKEAWAY · 带走

三种图元、两道闸门

三种图元：不动点、闭轨、分界线。找齐这三样，相图就读完了——哪怕一个公式也解不出来。

闸门一：双曲。线性化判稳只在双曲不动点处可信（Re λ ≠ 0）。非双曲时（中心、Δ=0），一切由高阶项决定，线性化会骗你。

闸门二：守恒量。有首次积分 H 的系统是保守的：轨道躺在等高线上，没有吸引子，闭轨成族、周期随能量变。

最后那件工具只做一件事：数指数。结点/焦点/中心 +1，鞍点 −1，闭轨内总和必须 +1。它不能告诉你"有没有闭轨"，但能一句话否掉一大批"看起来像"的图。

三个常见误读

① 以为闭轨就是极限环。本章的闭轨都是成族的（改一点初值换一条），极限环是孤立一条、能吸引——第 7 章。
② 以为 τ = 0 就是非双曲。鞍点也有 τ = 0。判双曲只看 Re λ。
③ 以为指数定理能证明存在。它只做筛子，不做存在性。
