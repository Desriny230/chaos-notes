§9.0 引言 · 全书的分水岭

为什么混沌必须等到三维

第 7 章证明过：二维自治系统的有界轨道，最终只能去两个地方——不动点或闭轨。没有第三条路。所以二维里没有混沌，这不是「没找到」，是定理禁止的。

那就加一维。三维里轨道可以既不收敛、也不重复，还能永远待在有限范围内——第三种归宿终于被允许。洛伦兹方程就是最简单的现成例子之一：三个变量、两个二次项、三个参数。

这一章要交代的四件事

① 三个方程从哪来（水车与对流）；② 它的「简单性质」：耗散、对称、不动点、稳定性；③ 奇怪吸引子长什么样，怎么用李雅普诺夫指数说它「奇怪」；④ 怎么把它压成一维映射来算。

读之前先记住一件事

洛伦兹方程没有解析解，也不可能有。整章的结论全部靠「几何 + 数值」，这正是第 1 章立的规矩在这里第一次被完整执行。

第 1 章讲过洛伦兹 1961 年「抄错初值」的故事，这里只补一句：他当时跑的是 12 个方程的大气对流模型，把它砍到 3 个方程之后，才有了本章这一组方程。

§9.0 引言
§9.1 · 混沌水车

一台会自己换方向的轮子

想象一个立着的轮子，边缘挂满小桶。顶上有一股水均匀地往下灌，每个桶底部都有一个小孔在漏水。问：轮子怎么转？

水灌得多、漏得快，轮子可能稳稳地匀速转；水灌得慢，它可能只是晃两下就停；把流量调到某个中间值，它会转一会儿、停一下、再反过来转——而且这个「换向」的节奏没有任何周期。

洛伦兹用一个三变量的模型抓住了这件事：轮子的角速度、以及两组桶之间的质量差。三个变量互相牵制，出来的就是本章要研究的三方程。

物理上它是水车，气象上它是对流：同一组方程，两种读法。—— 这是洛伦兹模型最漂亮的地方

为什么水车值得当模型

因为它把「混沌」需要的东西都凑齐了，而且能用手转起来看：

· 有能量输入（水）与耗散（漏、摩擦）→ 可以稳态；
· 有方向上的对称（顺时针 / 逆时针）→ 可以有两种稳态；
· 有延迟与反馈（桶里的水要转过去才漏掉）→ 可以让两种稳态互相打断。

三件事凑在一起，就是「在两个稳定态之间不规则地跳」——这正是本章要看的现象。

§9.1 混沌水车
§9.1 · 方程与参数

三个方程，三个参数

ẋ = σ(y − x)　　ẏ = rx − y − xz　　ż = xy − bz

三个变量：x 与轮子（或对流卷）的转速成正比，y 与温差有关，z 与温度剖面的偏离有关。三个参数（原书 §9.2 的读法）：

σ > 0　普朗特数

流体「黏」与「导热」的比值。本章固定 σ = 10（水一类流体）。

r > 0　瑞利数（相对值）

驱动强度的度量。本章的旋钮就是它：r 从 1 拧到 60，行为换三次。

b > 0

没有专门名字，与对流卷的纵横比有关。本章固定 b = 8/3。

方程里只有两个非线性项：xz 与 xy。这两个二次项就是全部的复杂性来源——去掉它们，系统是一个线性方程组，只会收敛或发散。

记法约定：本章所有数值都以 σ = 10、b = 8/3 为准，只让 r 变。换掉 σ 或 b，结论的数值会变（门槛、指数都变），但「三个区」的结构不变——§9.5 会给出更一般的口径。

§9.1 混沌水车
§9.2 · 简单性质（一）

体积一直缩，缩到一个零体积集合里

算一下相空间的体积变化率——向量场的散度：

∇·f = ∂ẋ/∂x + ∂ẏ/∂y + ∂ż/∂z = −σ − 1 − b = −(σ + b + 1)

代入 σ = 10、b = 8/3：∇·f = −13.667 < 0，而且是个常数。这意味着：相空间里任何一小团体积都按 V(t) = V₀ e−(σ+b+1)t 指数收缩，半衰期约 0.05 个时间单位。

所以长期行为一定被压在一个体积为零的集合上。这是「吸引子」（attractor）这个词的严格来源：吸引子不是随便一个集合，而是体积为零、却还能让轨道在里面永远跑下去的集合。

同时有对称性

把 (x, y, z) 换成 (−x, −y, z)，三个方程一个不变。所以若某条轨道是解，它关于 z 轴转 180° 的那条也是解。吸引子必须关于 z 轴对称——这就是它长成「两叶」的原因。

两个结论先记下

① 体积收缩：三维里体积缩到零，但轨道还能无限跑——只有「面积/长度」意义上的分形集才能做到（第 11 章算给看）。
② 对称：两叶在几何上完全一样，谁也不是「主叶」。

§9.2 洛伦兹方程的简单性质
§9.2 · 简单性质（二）

三个不动点：原点与一对孪生的 C±

令三个导数都为零，逐步解：ẋ = 0 给出 y = x；ż = 0 给出 xy = bz，代入得 x² = bz；ẏ = 0 给出 x(r − 1 − z) = 0。于是只有两种可能：

原点 (0, 0, 0)

永远存在。它的物理读法是「没有对流，纯导热」——热量靠传导慢慢过去，流体不动。

C± = (±√(b(r−1)), ±√(b(r−1)), r−1)

只有 r > 1 才存在。物理读法是「对流卷转起来了」，而且正转、反转各有一个——对称性的直接后果。

r 从下方穿过 1 时，原点的特征值有一个穿过零，一对孪生不动点从它身上分出来——这是叉式分岔（§8.1），对称破缺的标准剧本。

数值：r = 8 时 C± = (±4.32, ±4.32, 7)（q = √(b(r−1)) = √18.667 = 4.3205）；r = 28 时 C± = (±8.49, ±8.49, 27)。这两个位置后面演示里会看到。

边界：r < 1 时只有原点一个不动点。此时方程对任何初值都收敛到原点（λ < 0，本章扫描给出 r = 0.5 处 λ ≈ −0.49），没有混沌可言。

§9.2 洛伦兹方程的简单性质
§9.2 · 简单性质（三）

再往上拧，C± 也会失稳

在 C± 处线性化，得到一个三次特征方程。原书把这个方程留给读者去写，这里只给关键结果（完整推导见本章推导页）：

λ³ + (σ+b+1)λ² + b(σ+r)λ + 2σb(r−1) = 0

「出现一对纯虚特征值」的充要条件是 a₀ = a₁a₂（把 λ = ±iω 代进去就能看出：多项式必须等于 (λ²+ω²)(λ+c)）。代入三个系数并化简，得到霍普夫门槛：

r_H = σ(σ+b+3) / (σ − b − 1) = 470/19 ≈ 24.7368

于是整个剧本清楚了：r < 1 原点稳定；1 < r < r_H 原点不稳、C± 稳定（对流卷稳稳地转）；r > r_H 连 C± 也不稳了——所有不动点都不稳，轨道无处可去。

而且这个霍普夫分岔是亚临界的（§8.2）：分岔点上并没有小振幅的环安静地长出来，而是直接把轨道甩到很远的地方去。那个「很远的地方」，就是奇怪吸引子。

为什么分母 σ − b − 1 出现在那里：它趋于零时 r_H → ∞，意思是**混沌门槛被推到无穷远**。σ = 10、b = 8/3 时它等于 6.33，不算小，所以门槛落在 24.7——离 1 很远，系统有很长一段「稳定对流」的区间。

§9.2 洛伦兹方程的简单性质
§9.2 · 一个悖论

把所有可能都排除掉，剩下的是什么

原书 §9.2 开头把洛伦兹的推理讲成了一个侦探故事：他一件一件地排除了系统长期行为的所有已知可能——

① 是不是停在某个不动点上？不是。r > r_H 时三个不动点全都不稳定。
② 是不是绕在一条闭轨上？不是。数值上找不到稳定的环，霍普夫还是亚临界的。
③ 那会不会跑到无穷远？看上去不会——数值上所有轨道都被关在一个有界区域里（原书也是靠构造困住轨道的椭球 + 数值证据来说明这一点）。注意：体积收缩本身推不出有界（反例：ẋ = x、ẏ = −3y，散度 = 1 − 3 = −2 < 0，体积按 e−2t 收缩，可 x(t) = x₀et 一路跑到无穷）。所以这一条是「数值事实 + 后续证明」，不是散度的推论。

「当你排除了所有的不可能，剩下的必是真理。」—— 夏洛克·福尔摩斯（柯南·道尔《四个签名》），原书 §9.2 引

剩下的东西必须同时满足三件事：有界、体积为零、轨道在里头永不重复也不收敛。这在 1963 年没有任何现成的数学对象，只能给它起个名字——奇怪吸引子。

严谨性提醒：这个「排除法」不是证明。真正证明洛伦兹吸引子的存在用了很多年（原书 §9.3 提到直到 1999 年这个问题才有定论）。但当下的教学目的很明确：让你知道「没有别的可能」，接下来只管看它长什么样。

§9.2 洛伦兹方程的简单性质
§9.3 · 定义

「奇怪」到底奇在哪

原书的定义（§9.3）

奇怪吸引子是一个对初始条件敏感依赖的吸引子。「奇怪」这个叫法最初来自它通常是分形集；现在学界认为「敏感依赖」这个动力学特征比几何特征更重要。当人们想强调其中之一时，就用「混沌吸引子」或「分形吸引子」这两个术语。

这句话值得逐字拆开：

「吸引子」说的是局部：附近的轨道会进来，进来就不走了。「敏感依赖」说的是内部：进来的轨道彼此会分开（λ > 0）。「分形」说的是几何：体积为零，但又不是线、不是面，维数是个分数（第 11 章）。

三件事互不蕴含：可以有吸引子而不混沌（稳定不动点）；可以混沌而不吸引（一个混沌鞍点）；可以分形但不混沌（一条康托尔集）。洛伦兹吸引子罕见地三样都占。

术语边界：「混沌」通常指轨道的性质（对初值敏感、不周期），「奇怪吸引子」指集合的性质；「混沌吸引子」是两者合起来说。原书这里点名了这个区别，写论文时别混。

§9.3 奇怪吸引子上的混沌
沿 x 轴看过去的投影（即 y–z 平面），r = 28，数值积分 60 个时间单位。蓝线＝x > 0 的一叶，金线＝x < 0 的一叶，绿点是被绕着的两个不动点 C±。轨迹在一叶上绕几圈，忽然跳到另一叶，再绕几圈。
§9.3 · 几何

两片叶子，两个空着的中心

看图上那两个绿点：它们是 C±，此刻已经不稳定了（r = 28 > r_H）。轨道绕它们转，却永远进不去——这就是「不稳定焦点」的几何：中心是空的，周围一圈一圈。

两叶之间的跳转就是 z(t) 的不规则翻转。注意每一叶上的「圈」其实是一层一层的，越靠中心越密——层次是无穷的，这就是分形的影子。

为什么画 y–z 而不画三维透视图？因为沿 x 方向看，两叶正好叠成经典的「蝴蝶」轮廓，而且能看清「绕着哪个不动点转」。换个视角，图就换一种说法——这是相图的基本技能。

读图提醒：颜色不是两个吸引子，而是同一个吸引子的两半。任何一条轨道都会在两种颜色之间来回。

§9.3 奇怪吸引子上的混沌
§9.3 · 时间序列

翻转没有周期

把 z(t) 画出来（r = 28，40 个时间单位）：它在一套振幅上来回爬升、忽然掉下去，换到另一套振幅上，再重复。看上去像有周期——可你数不出来。

数不出来。有些翻转隔得近，有些隔得远，间隔序列本身没有任何周期。这正是「混沌」与「准周期」的分界线：准周期的波形是由两个不可通约频率叠出来的，你虽然写不出周期，但能预报下个峰在哪；混沌的波形连预测都不行——因为初始误差会指数放大。

于是问题被逼到这一步：既然轨道永不重复、也不收敛，那它到底「住在」什么地方？答案就是上一节的奇怪吸引子：一个体积为零、层数无穷的集合。

z(t) 的数值解（r = 28，初值 (1, 1, 1)）。每个「平台」对应在一叶上绕圈的一段时间，陡降对应跳到另一叶。平台高度与持续长度都不规则。
§9.3 奇怪吸引子上的混沌
两个初值只差 10⁻⁶（同一条轨道与它稍微挪动过的副本），纵轴是 log₁₀|Δ|。从 10⁻⁶ 涨到 10⁰ 只需要约 14 个时间单位；之后两条轨道就完全没关系了。金虚线是拟合斜率，换算回去得到 λ ≈ 0.876。
§9.3 · 敏感依赖

误差按指数长：这就是「确定性却不预测」

做一件最朴素的事：跑两条轨道，初值只差 10⁻⁶。如果系统稳定，误差会缩小或保持；在洛伦兹系统里，误差在对数坐标下是一条直线——这就是指数增长：

|Δ(t)| ≈ |Δ(0)| eλt，　λ > 0

把直线斜率乘以 ln10 就得到 λ ≈ 0.88（本章脚本的拟合值；用双轨道重正化法在 r = 28 测到 0.919，差别来自步长与拟合窗口）。

这个数有一个很实用的读法：每过 1/λ ≈ 1.1 个时间单位，误差放大 e 倍。想把预报延长一倍的时间，就得把初值精度提高 eλT 倍——精度换时间的汇率是指数的。天气预报为什么难，这就是根源。

边界：这条直线只在误差还「小」的时候成立。误差长到和吸引子一样大以后就饱和了（图上右侧变平），那时两条轨道只是各自乱跑，谈不上「相关」。

§9.3 奇怪吸引子上的混沌
§9.3 · 一个数判混沌

李雅普诺夫指数：把「分离多快」压成一个数

定义（三维就取最大那个）：沿一条典型轨道放一个无穷小误差，看它平均每单位时间放大多少倍：

λ = limt→∞ (1/t) ln( |δ(t)| / |δ(0)| )

算的时候必须边算边重正化：误差一放大到阈值（比如 10⁻⁶）就把它缩回去，同时把「放大倍数」累加进对数。否则数值上一秒就溢出了。

本章脚本以 σ = 10、b = 8/3、步长 0.008、暂态 300、测量 200 时间单位扫描 r ∈ [0.5, 60]：

r=2 → −1.22　r=10 → −0.60　r=20 → −0.16
r=23 → −0.057　r=24 → +0.79　r=28 → +0.92
r=40 → +1.15　r=60 → +1.40

λ(r) 的数值扫描（步长 0.5）。r ≤ 23 时 λ 为负：轨道落到不动点上。λ 在 r ≈ 24 就转正（这是长暂态，下一页专门解释）；rH ≈ 24.74 是 C± 失稳（霍普夫分岔）的门槛，不是 λ 变号的点。之后 λ 稳定在 0.8–1.4 之间：混沌。
§9.3 奇怪吸引子上的混沌
§9.3 · 一个必须说清的细节

λ > 0 不等于「存在奇怪吸引子」

看上一页的扫描：r = 24 明明低于 r_H = 24.74，λ 却是 +0.79。这看起来矛盾。真相是：我测的是有限时间窗口里的平均增长率，它可以是正的，却不代表存在一个奇怪吸引子。

r 略低于 r_H 时，C± 仍然稳定，但稳定性极弱——指数衰减率接近零（这正是亚临界霍普夫的特征：快要失稳了）。于是轨道先在混沌的「地毯」上晃很久，才慢慢落进不动点。这种状态叫长暂态（或瞬态混沌）。

稳健性核对（本章脚本，r = 24）

RK4 dt=0.008　λ=+0.786　|x−C+| = 20.0
RK4 dt=0.004　λ=+0.801　|x−C+| = 28.2
RK4 dt=0.002　λ=+0.778　|x−C+| = 6.5
Heun dt=0.008　λ=+0.739　|x−C+| = 11.7
Heun dt=0.004　λ=+0.793　|x−C+| = 33.8
RK4 暂态 2000　λ=+0.782　|x−C+| = 20.6

换积分器、把步长减半、把暂态从 300 拉长到 2000：λ 始终在 +0.74 ~ +0.80。而且末态离 C+ 还很远（6 ~ 34）。所以这不是数值假象，是真实的长时间混沌暂态。

更干脆的定案办法：直接算 C± 的特征值。本章脚本（Durand–Kerner 求根）给出 C± 处特征值的最大实部：r = 20 时 −0.155、r = 23 时 −0.054、r = 24 时 −0.0225、r = 24.5 时 −0.0072、r_H 处 −0.0000（正好过零）、r = 26 时 +0.0375。r = 24 时最大实部仍是负的，所以 C± 局部稳定、它确实是吸引子；混沌地毯只是暂态。这比「等 t → ∞」干净得多，也把论证闭合了。

正确的表述：r < r_H 时系统的吸引子是 C±；混沌地毯只是暂态。要区分「吸引子」与「暂态」，标准做法是看 t → ∞ 时轨道到底停在哪个集合上——这也是本章把「吸引子」定义抠得这么细的原因。

实验上的后果：如果观测时间比暂态短，你会以为系统已经混沌了。工程上判断「振荡是否失稳」时，暂态长度必须和观测时间比一比，否则会误判。

§9.4 · 洛伦兹映射

只看峰：三维的流压成一维的映射

洛伦兹 1963 年发现的办法：不管中间的细节，只记录 z 的每个局部极大值，记作 z₁, z₂, z₃, …。神奇的是，下一个峰几乎只由这一个峰决定：

zn+1 = f(zn)

把 (zn, zn+1) 配对画出来，点会铺成一条单峰的、像帐篷一样的曲线（原书 §9.4 的图 9.4.2）。这就是洛伦兹映射。

为什么能做到？因为吸引子上的轨道有个规律：绕得越高，下次掉得越低；而中间那些细节对下一个峰几乎没有影响。这种「近似的一维」是洛伦兹吸引子最实用的性质——它把三维流变成了第 10 章要研究的一维映射。

注意是「近似」：严格说点有厚度（不是完美曲线），因为第三个方向还有一点残留信息。原书 §9.4 也把它当近似处理。

§9.4 洛伦兹映射
§9.4 · 一维映射上的李雅普诺夫指数

斜率大于 1，就是混沌

一维映射上，误差传递是一步一步相乘：δn = f′(zn−1)δn−1，所以

δN = δ₀ Πk=0N−1 f′(zk)　⇒　λ = (1/N) Σk ln|f′(zk)|

也就是说：李雅普诺夫指数就是映射斜率的对数的平均值。帐篷形的两臂很陡：陡处 |f′| ≈ 3–5，峰顶附近 |f′| 接近 1，几何平均约 1.94（本章实测 ⟨ln|f′|⟩ ≈ 0.665 = ln 1.94），所以 ⟨ln|f′|⟩ > 0 —— 映射本身就是混沌发生器。

数值交叉验证（本章脚本）：把散点按 zn 分段做局部线性拟合，得到 ⟨ln|f′|⟩ ≈ 0.665。另一方面，两个峰之间的平均间隔是 0.753 个时间单位，于是「每次迭代的指数 / 每次迭代的时间」= 0.665 / 0.753 ≈ 0.883——与直接对三维流测得的 λ ≈ 0.92 相当接近。两条完全不同的路子给出同一个量级，这就是可信度。

这件事的意义

它说明：混沌不需要三维。一个一维映射（下一章的 xn+1 = rxn(1−xn)）只要斜率够陡，也能混沌。洛伦兹的贡献不是「混沌必须三维」，而是「连续的流要混沌，至少三维」——这是第 7 章 P–B 定理划的界。

§9.4 洛伦兹映射
§9.5 · 探究参数空间

沿着 r 走一遍，三次换岗

r < 1：纯导热

只有原点，稳定。流体不动，热量靠传导。λ < 0。

1 < r < r_H：稳定对流

C± 稳定（正转或反转，取决于初值），原点不稳。这就是「对流卷」——原书 §9.1 末尾把它和水车的稳定旋转直接对应起来。λ < 0。

r > r_H：混沌

三个不动点全不稳，轨道被赶到奇怪吸引子上。λ > 0，且随 r 缓慢上升（r = 28 时 0.92，r = 60 时 1.40）。

中间那块灰色地带

r 从大约 24 到 r_H = 24.74：不动点仍然稳定，但稳定性极弱，混沌暂态能持续几百个时间单位。数值上很容易把它误认成混沌吸引子（上一节给了六组对照数据）。

换 σ 和 b 会怎样

门槛按 rH = σ(σ+b+3)/(σ−b−1) 变。σ − b − 1 → 0 时门槛跑到无穷远：混沌区被推到天边。所以「洛伦兹系统是混沌的」这句话必须带上参数——本章全部结论都属于 σ = 10、b = 8/3。

与实验对照

原书的对照物是瑞利–贝纳德对流：下面加热的流体层，温差小时静止，温差大了出现六边形或卷状的对流，再大就起伏、翻腾。洛伦兹三方程是它的极简模型，不是定量模型。

§9.5 探究参数空间
§9.6 · 一个应用（以及它的软肋）

用混沌当载波：听起来完美，做起来很难

混沌信号有两个对通信很有吸引力的特点：看起来像噪声（难以被截获和识别），频带很宽（能塞下高速数据）。于是 1990 年代有一波思路：把信息「藏」进混沌载波里。

基本玩法：混沌掩蔽

发射端把消息 m(t) 叠加到混沌信号上发出去：s(t) = x(t) + m(t)。接收端需要一个和发射端同步的混沌系统，把 x(t) 复现出来，减掉就得到 m(t)。

关键工具：混沌同步

1990 年前后，佩科拉与卡罗尔（Pecora & Carroll）指出：用「驱动–响应」方式耦合两个相同的混沌系统，可以让它们同步——尽管每条轨道本身对初值敏感。这件事当时很反直觉，也是这一波研究的起点。

软肋在哪：同步要求两个系统几乎完全相同。参数差一点点（σ、b、r 各差 1%），同步就散架，消息就取不出来。真实信道还有噪声、延迟、失真——每一样都在破坏「两个系统一模一样」这个前提。

所以这一节应该这样读：它是一个好例子——说明「混沌的敏感依赖」既是资源也是诅咒：想让别人解不开，靠它；想让自己解得开，也受它限制。工程上它至今主要在实验室与特定场景里，没有取代常规扩频通信。

§9.6 利用混沌传送秘密信息
PROOF 01 · 四件套：出发点 → 步骤 → 退化自检 → 边界

把 r_H 从头算出来

完整推导体积收缩 + 对称性 + 不动点 + 霍普夫门槛 r_H = 470/19

出发点．ẋ = σ(y−x)，ẏ = rx − y − xz，ż = xy − bz，σ, r, b > 0。

1体积收缩．散度只对线性部分有贡献：两个二次项 xz、xy 都不含被求导的那个变量（∂(−xz)/∂y = 0，∂(xy)/∂z = 0），故对散度没有贡献：

∇·f = −σ − 1 − b = −13.667 < 0（常数）

由刘维尔型论证：小体积元按 V(t) = V₀e−(σ+b+1)t 收缩。所以任何有界吸引子体积为零。

2对称性．令 S: (x, y, z) ↦ (−x, −y, z)。逐式检查：σ((−y)−(−x)) = −σ(y−x) ✓；r(−x) − (−y) − (−x)z = −(rx − y − xz) ✓；(−x)(−y) − bz = xy − bz ✓。三个式子同时变号或不变号，故 S 把解映成解。

3不动点．ẋ=0 ⇒ y = x。ż=0 ⇒ xy = bz ⇒ x² = bz。ẏ=0 ⇒ x(r − 1 − z) = 0。于是：x = 0 ⇒ 原点；x ≠ 0 ⇒ z = r−1、x = ±√(b(r−1))，即 C±（要求 r > 1）。

4在 C± 处线性化．取 q = √(b(r−1))，雅可比矩阵

A = [[−σ, σ, 0], [1, −1, −q], [q, q, −b]]

算三个系数（a₁ = −tr A，a₂ = 二阶主子式之和，a₀ = −det A）：

a₁ = σ+b+1，　a₂ = b(σ+r)，　a₀ = 2σb(r−1)

得到特征方程 λ³ + a₁λ² + a₂λ + a₀ = 0。

5霍普夫条件．若三根中有一对纯虚数 ±iω、第三根为 −c，则多项式必等于 (λ²+ω²)(λ+c) = λ³ + cλ² + ω²λ + cω²。比较系数：c = a₁，ω² = a₂，且 a₀ = a₁a₂。代入第 4 步：

2σb(r−1) = (σ+b+1)·b(σ+r)　⇒　r(σ−b−1) = σ(σ+b+3)

即 r_H = σ(σ+b+3)/(σ−b−1)。取 σ = 10、b = 8/3：(470/3)/(19/3) = 470/19 ≈ 24.7368。此时 ω² = b(σ + r_H) = (8/3)(34.7368) ≈ 92.6，ω ≈ 9.62，第三根 −c = −(σ+b+1) = −13.667，与数值一致。

退化自检．令 r = 1：a₀ = 0，特征方程退化为 λ[λ² + a₁λ + a₂] = 0，一根为零、其余两根实部为负——正是叉式分岔该有的样子（原点把稳定性交给 C±）✓。再令 σ = b+1（分母为零）：r_H → ∞，门槛消失，与「σ − b − 1 → 0」的读法一致 ✓。

失效边界．① 这只说明「在 C± 上有一对特征值穿过虚轴」，决定超/亚临界还要看第一李雅普诺夫系数（§8.2）；洛伦兹这里是亚临界，所以分岔后轨道不是落在小环上，而是被甩到远处。② r_H 的表达式依赖 σ、b；换参数就要重算。③ 以上全是局部信息，奇怪吸引子的存在性与结构不在这个推导的射程内。

§9.2 洛伦兹方程的简单性质
PROOF 02 · 一维映射的指数

为什么帐篷形必然给出正的李雅普诺夫指数

完整推导链式法则 → 指数的平均式 → 与三维流的对照

出发点．洛伦兹映射 zn+1 = f(zn)，把相邻两个 z 的局部极大值联系起来。

1误差怎么传．设两条轨道的峰分别是 zn 与 zn+δn，则

zn+1 + δn+1 = f(zn + δn) ≈ f(zn) + f′(zn)δn ⇒ δn+1 ≈ f′(zn) δn

合法前提：δ 足够小（局部线性化）；f 连续可微。

2迭代 N 次．把上式连乘：

δN = δ₀ Πk=0N−1 f′(zk)　⇒　(1/N)ln|δN/δ₀| = (1/N)Σ ln|f′(zk)|

取 N → ∞ 的极限就是映射的李雅普诺夫指数 λmap = ⟨ln|f′|⟩：它是对轨道遍历分布的加权平均，不是对 z 的均匀平均。

3为什么帐篷形给出正数．分两段看：两臂的 |f′| 通常大于 1（陡处 3–5），峰顶附近则接近 1。两者按轨道遍历加权，得到几何平均斜率约 1.94，即 ⟨ln|f′|⟩ ≈ ln 1.94 = 0.665 > 0（本章实测值）。符号由「陡」决定，大小由「多陡」决定。

4与三维流对照．每次迭代对应一段平均回归时间 T̄（相邻峰之间的时间）。本章数据：400 个时间单位里有 531 个峰，T̄ = 0.753；分段拟合得 ⟨ln|f′|⟩ ≈ 0.665。于是

λflow ≈ ⟨ln|f′|⟩ / T̄ = 0.665 / 0.753 ≈ 0.883

而直接对三维流做双轨道重正化测得 λ = 0.919（dt = 0.008）。两条独立路径差 4%，量级与来源都对上了。

退化自检．若 f 是恒等映射（f′ ≡ 1），则 λmap = 0：误差不放大，轨道周期或不动。λ = 0 恰好是「周期/准周期」与「混沌」的分界 ✓。

边界．① 这个推导假设映射是严格一维的；洛伦兹映射只是近似一维（点有厚度），所以 λmap 只是近似。② 局部线性化要求 δ 小、f 可微；峰顶附近 f′ 变化剧烈，那一小段会被放大误差。③ 把 λmap/T̄ 换算成 λflow 时，前提是回归时间与轨道无关得足够好——这只是近似。

§9.4 洛伦兹映射
PITFALLS · 反例与边界

五个容易踩的坑

1　把「长得像」当混沌

看起来杂乱的时间序列，可能是三条频率不可通约的准周期叠加。判据是 λ 的符号与截面结构，不是眼睛。

2　把长暂态当吸引子

r = 24 那个例子：λ 为正、加长暂态也不变（本章给了六组对照）。但它的吸引子仍是不动点。要分清「轨道现在在哪儿」和「最终会去哪儿」。

3　忘了参数

「洛伦兹系统混沌」只在特定参数下成立。σ = 10、b = 8/3 时门槛是 r_H = 24.74；换了 σ、b，门槛跟着变，σ − b − 1 → 0 时混沌区整个消失。

4　数值上把 λ 算错

不重正化就溢出；步长太大稳定性就变（本章用了 dt = 0.008/0.004/0.002 三档对照）；暂态太短会测到暂态瞬时增长率。三条都要检查。

5　以为「混沌 = 随机」

洛伦兹方程里没有随机数。给定初值，未来唯一确定。不预测不是因为抛了骰子，而是因为精度不够——这两件事完全不同。

一句话总结边界

本章所有数字都属于 σ = 10、b = 8/3、特定的积分步长与窗口。换一个，就要重算——但「三个区 + 长暂态 + 两叶」这套结构是稳的。

TAKE AWAY · 三句话

带走三句话

一、连续流要混沌，至少三维。二维被 P–B 定理锁死（不动点或闭轨），洛伦兹加的那一维让「既不收敛也不重复」成为可能。三个方程、两个二次项就够了。

二、判断混沌看 λ 的符号，不是看图形。λ > 0 表示相邻轨道指数分离；本章 r = 28 时 λ ≈ 0.92。而 λ > 0 也有可能只是长暂态——r = 24 就是活教材：换积分器、缩步长、拉长暂态，λ 仍在 +0.74~+0.80，但吸引子仍是不动点。

三、三维可以压成一维。只记 z 的峰，就得到帐篷形的洛伦兹映射；映射斜率的对数平均就是李雅普诺夫指数（本章两法互证：0.883 vs 0.919）。下一章的全部内容，都在这一条线索上展开。

回到本章开头的问题

为什么「确定性」与「可预测」是两件事？

因为误差按 eλt 长：精度换时间的汇率是指数的。想让预报多活一倍时间，初值精度就得提高 eλT 倍——很快就不够用了。
