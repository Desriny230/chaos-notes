§5.0 · 引言

为什么先学线性：因为它是唯一能算完的

前三章的系统都只有一个变量（一个数，或者一个角）。真实的动力学系统一般有两个：位置与速度、兔与羊、两个人对彼此的好感。从两个变量起，相空间就成了平面，几何一下子丰富起来。

在跳进非线性之前，先把线性这一片扫干净。理由有两个：

一、线性系统的解可以完全写出来。答案是一个矩阵的指数 eAt，而 2×2 的情形能彻底分类——只有六种相图，一张表说完。

二、非线性系统的局部行为就是线性的。在任何"双曲"平衡点附近，非线性项是次要的，相图与它的一阶近似拓扑等价（第 6 章的 Hartman–Grobman 定理）。所以这一章不是玩具，它是后面所有章的第一近似。

先学会用 τ 和 Δ 两个数说出相图的名字。以后每遇到一个非线性系统，第一件事都是：在平衡点处线性化，然后看这两个数。
§5.0 引言
§5.1 · 定义与例子

线性系统：两个变量，四张卡片

两个变量的线性系统，写成矩阵形式就是

ẋ = ax + by ， ẏ = cx + dy ⟺ ẋ = Ax ， A = [[a, b], [c, d]]

线性的意思是：右边对 (x, y) 是一次齐次的——没有常数项、没有平方项、没有 xy。于是原点 (0,0) 永远是不动点，而且叠加原理成立：两条解加起来还是解，乘个常数还是解。

三个立刻能想到的例子：

· 阻尼谐振子：mẍ + bẋ + kx = 0。令 y = ẋ，得到 ẋ = y、ẏ = −(k/m)x − (b/m)y。所有二阶线性方程都能这样化成一阶系统——这是本章最常用的一招。

· 两个互相影响的量：放射性衰变链、线性化的种群竞争、两个房间之间的热传导。

· 非线性系统在不动点附近：把 f 做一阶泰勒展开，扔掉高阶项，得到的正是 ẋ = Jx，J 是雅可比矩阵。这就是为什么必须先把线性分类做干净。

§5.1 定义与例子
§5.1 · 解的结构

解的骨架：特征值与直线解

试一个指数形式的解 x = eλtv（v 是常向量）。代进 ẋ = Ax：

λ e^{λt} v = e^{λt} A v ⟹ A v = λ v

于是解的问题变成了求特征值 λ 与特征向量 v。解存在（v ≠ 0）的条件是行列式为零：

det(A − λI) = λ² − τλ + Δ = 0 ， τ = a + d = tr A ， Δ = ad − bc = det A λ₁,₂ = [ τ ± √(τ² − 4Δ) ] / 2

这两个数 τ（迹） 与 Δ（行列式） 就够决定一切了——4 个矩阵元里，只有这两个组合影响相图的形状。

直线解（eigenline）：沿着特征向量 v 的方向，轨迹是一条直线：x(t) = c eλtv。λ < 0 就朝原点直线冲进来，λ > 0 就沿直线逃出去。其它所有轨线都是这两条直线解的"混合"——一般解是

x(t) = c₁ e^{λ₁t} v₁ + c₂ e^{λ₂t} v₂

所以看相图时先找那两条直线，剩下的都是它们之间的过渡。特征向量定骨架，特征值定生死。

§5.1 定义与例子
§5.1 · 化成一阶系统

二阶方程怎么变成两个一阶

本章的工具只吃"一阶系统"（ẋ = Ax），可物理定律几乎都以二阶形式出现。转换配方只有一句话：把每个高阶导数起一个新名字，当成独立变量。

配方。对 ẍ = g(x, ẋ)，令 y = ẋ：

ẋ = y ， ẏ = g(x, y)

三个例子，同一招：
· 阻尼振子 ẍ + bẋ + kx = 0 → ẋ = y、ẏ = −kx − by，即 A = [[0,1],[−k,−b]]；
· RLC 串联电路：以电荷 q 为变量得 Lq̈ + Rq̇ + q/C = 0，与振子严格同构（q↔x、L↔m、R↔b、1/C↔k）；
· 钟摆 θ̈ = −sin θ → θ̇ = ω、ω̇ = −sin θ。这一条不是线性的，但下面会用线性化把它接回本章。

状态变量怎么选？不唯一（也可以用总能量），但不同选法之间差一个可逆线性变换，而可逆变换不改变特征值、也不改变相图的拓扑。所以 τ 与 Δ 是系统本身的属性，不是你记号的属性。

代价：维数翻倍，而且"位置"和"速度"现在是平权的两个坐标——画出来的图不再是"位置随时间"，而是速度对位置。这就是后面所有相图的语言。

§5.2 · 六张相图

六张相图，一次看完

取同一族的矩阵 A = [[0,1],[−Δ,τ]]（迹 = τ、行列式 = Δ），只改 τ 与 Δ，数值积出六种相图。所有轨线都满足 ẋ = Ax，视觉差别全部来自特征值。

结点（node）：两个特征值同号且都是实的。全部轨线都钻进（或逃出）原点，除了两条直线解，别的都弯着走。鞍点（saddle）：一正一负。四条直线解把平面切成四块，两块进、两块出——鞍点永远不稳定，哪怕"进来"的方向看起来很像稳定。焦点（focus）：共轭复根，轨线绕圈+螺旋。中心（center）：纯虚根，轨线是闭合的椭圆。退化结点：重根，轨线要么全是直线（星结点），要么只剩一条直线解。

§5.2 · 分类图

一张图装下全部六种相图

把 λ = [τ ± √(τ²−4Δ)]/2 的符号与类型画到 (τ, Δ) 平面上，六种情形自然分成六个区域。

分界只有三条：
· Δ = 0（横轴）：Δ 变号意味着两个特征值乘积变号——从"同号"变成"异号"，也就是从结点/焦点变成鞍点。
· τ = 0：两根之和为零。对复根来说就是实部为零——从稳定变不稳定，中间穿过中心。
· Δ = τ²/4（一条抛物线）：判别式为零，复根变实根——焦点与结点的分界。

记住这三条线，剩下的靠"落在哪个格子"就能叫出名字。这张图是全书的交通地图：第 6 章以后每遇到一个平衡点，你都会回来查它。

迹—行列式平面：抛物线 Δ = τ²/4 分开结点与焦点，横轴 Δ = 0 分开鞍点，竖轴 τ = 0 分开稳定与不稳定。金点是中心（临界）。

§5.2 线性系统的分类
§5.2 · 稳定性判据

一个判据：τ 负、Δ 正

定理

对 ẋ = Ax（A 为 2×2 常矩阵），原点渐近稳定 ⟺ τ < 0 且 Δ > 0。此时所有解都指数地趋于 0。

证明只用到两根之和与两根之积。由特征多项式，λ₁ + λ₂ = τ，λ₁λ₂ = Δ。分两种情形：

实根。Δ > 0 说明两根同号（乘积正）；τ < 0 说明两根之和为负；同号且和为负 ⟹ 两根都是负的 ⟹ 都收敛。反过来若有一点不稳定（某根 ≥ 0），要么和 ≥ 0，要么乘积 ≤ 0——都与条件矛盾。

复根 σ ± iω。此时 λ₁λ₂ = σ² + ω² > 0（所以 Δ > 0 自动满足），而 λ₁+λ₂ = 2σ = τ。收敛就看实部 σ = τ/2 的符号：τ < 0 ⟺ σ < 0 ✓。

两种情形合起来，判据成立。三个自检：① 鞍点 Δ < 0，判据立刻拒绝 ✓；② 中心 τ = 0，落在边界上——判据说"不满足"（确实不渐近稳定）✓；③ 一维退化成 ẋ = ax：这时 τ = a、Δ = 0，判据给出"不稳定"（Δ 不为正），而一维的正确答案是 a < 0 时稳定——所以二维判据不能直接套一维，因为一维的 A 是奇异的（Δ=0）。

边界：判据给出的是线性系统的全局结论。用在线性化上时，必须先确认平衡点是双曲的（Re λ ≠ 0），而且结论只是局部的——远离原点，非线性项可能翻盘。

§5.2 线性系统的分类
§5.2 · 退化情形

三条边界线上：最脆的地方

一、Δ = 0（矩阵奇异）。有零特征值，原点不再是孤立不动点——整条直线（特征向量方向）上全是不动点。相图里你会看到一条"停滞线"，轨线沿平行方向流向它。这时"稳定/不稳定"这套针对孤立点的词汇要重新说：那条线上每一点的横向行为（τ < 0 时收敛、> 0 时发散）由另一个特征值定，而沿线的方向是中性的——所以它是稳定但不渐近稳定（或反过来），不是一维意义下的"半稳定"。

二、τ² = 4Δ（重根）。两根相等，但相图有两种样子，取决于 A 能不能对角化：
· 可对角化 → 星结点，所有方向都是直线解，轨线笔直冲向原点；
· 不可对角化（缺特征向量）→ 退化结点，只有一条直线解，其余轨线都切着它进来。
判别法：算 A − λI 是否为零矩阵。

三、τ = 0 且 Δ > 0（中心）。这是最要紧的一个退化。它不双曲：特征值纯虚，实部恰为零。往左挪一点（加一点阻尼）就是稳定焦点，往右挪一点就是不稳定焦点。中心是一根针尖上的平衡——现实里任何一点耗散都会把它变成螺旋。

这三条线不是"数学上的边角料"，它们是分岔的舞台。第 3 章说"分岔都发生在 λ = 0"；在二维里，"λ 的实部过零"就是 Hopf 分岔（第 8 章）。所以：判据失效的边界，正是新现象出生的地方。

§5.3 · 恋爱动力学

恋爱动力学：原书那个著名又可疑的模型

把两个人的好感当成两个变量：R = 罗密欧的爱，J = 朱丽叶的爱（都可以是负的，负就是反感）。假设每个人的爱按线性规律演化：

Ṙ = aR + bJ ， J̇ = cR + dJ

四个系数各自有脾气：

· a > 0：越爱越想爱（渴望型，eager）；a < 0：越爱越冷静（谨慎型）。
· b > 0：对方爱我，我就更爱；b < 0：对方越追，我越退。

于是"人格组合"直接翻译成矩阵，而矩阵直接翻译成相图。这一章学的所有东西，此刻都能用上：τ = a+d 是两人自我反馈之和，Δ = ad−bc 是"自我反馈 × 自我反馈 − 互相激励 × 互相激励"。

举个能算的例子：Ṙ = J、J̇ = −R。τ = 0、Δ = 1 → 中心：他越热她越冷，她越冷他越热，永远绕圈，谁也不收敛。再换一组：Ṙ = J、J̇ = 3R + 2J。τ = 2、Δ = −3 → 鞍点：一个方向烧成失控，另一个方向冷到冰点。下一页就是这两张图。

§5.3 · 两种结局

两种结局：绕不完的圈，和回不来的岔路

中心型（τ=0, Δ>0）：轨线是闭合的椭圆。两个人热度的相位差固定地转，幅度由初值决定。它永远不收敛，也永远不爆炸——这是"相敬如冰、又离不开"的数学版本。

鞍点型（Δ<0）：四条直线解把平面切成四块。初始好感稍微偏一点，就决定了这对人是"越烧越旺"还是"越走越远"——结局对初值极其敏感，这是鞍点最典型的脾气（也是第 1 章敏感性话题的线性祖先）。

这两张图还教会一件事：看 τ 与 Δ 的符号，就能在不算任何轨迹的情况下说出结局。Δ 的符号决定"是绕还是岔"，τ 的符号决定"往里收还是往外散"。这正是本章要训练的手感。

§5.3 恋爱
§5.3 · 边界

这个模型哪里荒诞，哪里真有用

四处荒诞（都必须说出口）

① 无饱和：线性意味着好感可以无限增长，可是人会累、会习惯、会麻木。
② 无阈值：真实感情有"不感兴趣就是不来电"的断层，线性模型里没有跳变。
③ 人格恒定：a、b、c、d 被当成常数，实际上人会变。
④ 叠加原理：模型说"你给我的影响"和"我自己的惯性"可以简单相加，真实心理不是这样。

两处真有用

① 它就是「局部线性化」本身：任何非线性恋爱模型（有饱和、有阈值）在平衡点附近都退化成本章这个 ẋ = Ax。所以这 4 个系数问的不是"这对人怎样"，而是"他们在平衡点附近稳不稳"。
② 它训练了这套语言：拿到一个系统，先算 τ 与 Δ，再叫出名字。这个动作后面每一章都要用。

原书把它放在这里，用意也不在"预测恋爱"，而在于：一个能算得干干净净、但显然不该照字面相信的模型，正好用来练习"模型与现实的边界"这件事。

顺带一句实话："中心型"在真实世界里几乎不可能持久——只要有一点耗散，τ 就不等于零，闭轨立刻变成螺旋。所以那对"永远绕圈"的情侣，在物理上是不存在的。

§5.2 · 用一次

把工具用一次：钟摆的两个平衡点

上一页把钟摆写成了 θ̇ = ω、ω̇ = −sin θ。它有两个不动点：最低点 (0, 0) 与正上方 (π, 0)。在每一点做一阶泰勒展开，就能查本章的分类表。

最低点 (0,0)。sin θ ≈ θ，于是 ω̇ ≈ −θ，雅可比矩阵 J = [[0,1],[−1,0]]。τ = 0、Δ = 1 → 中心：小摆动是等幅振荡，无量纲周期 2π。

正上方 (π,0)。令 θ = π + u，则 sin(π+u) = −sin u ≈ −u，于是 u̇ = ω、ω̇ ≈ +u。J = [[0,1],[1,0]]，τ = 0、Δ = −1 → 鞍点：正上方是山顶，一推就倒。

于是第 6 章那张钟摆相图的骨架，此刻已经知道了：一个中心，加上一圈鞍点，中间被分界线隔开。本章只做了局部的一阶分析，却已经把全局结构猜了出来——这就是线性化的力量。

但这里正好踩在本章的软肋上

这两个不动点的 τ 都恰为 0——都是非双曲的！中心那一行是分类表里唯一"会被高阶项整类改判"的格子。事实上：加上微小阻尼，最低点就变成稳定焦点；再给一个恒定力矩，还会失稳、长出极限环（第 7、8 章）。一阶分析给出骨架，但不说哪一支会活下来。

§5.2 线性系统的分类
§5.2 · 三步法

线性化三步法：以后每章都要用的动作

拿到一个非线性系统 ẋ = f(x,y)、ẏ = g(x,y)，判稳的固定动作只有三步：

① 找不动点：解 f = 0、g = 0（两个方程，一般是非线性的，可能有多个解）。
② 算雅可比矩阵：J = [[fx, fy],[gx, gy]]，然后在每个不动点处取数值。
③ 查表：算该点的 τ = tr J、Δ = det J，用上一页的分类表叫出名字、读出稳定性。

例题。系统 ẋ = x − x³、ẏ = −y。

① 不动点：x(1−x²) = 0 且 y = 0 → (0,0)、(±1,0)，共三个。
② 雅可比：J = [[1−3x², 0],[0, −1]]（每点只有对角元，很好算）。
③ 查表：
· (0,0)：J = [[1,0],[0,−1]] → τ = 0、Δ = −1 → 鞍点（特征值 +1、−1）；
· (±1,0)：J = [[−2,0],[0,−1]] → τ = −3、Δ = 2 → 稳定结点（特征值 −2、−1）。

所以这个系统的命运是：中间一个鞍点把平面分成两半，两边各有一个稳定结点。两条稳定轨线通向 ±1，中间那条通道被鞍点"卡住"。

第三步之后还有第四步：问一句"双曲吗"

只有当该点没有零实部特征值（双曲）时，线性化的结论才能搬到非线性系统上。这里三个点的特征值分别是 ±1 与 −2,−1，全都非零，所以全部可信。
注意：τ = 0 并不等于非双曲！(0,0) 的 τ = 0，但它是鞍点（特征值 ±1），照样双曲。判双曲只看 Re λ 是否为零，不看 τ。

§5.2 线性系统的分类
PROOF 01 · 完整推导

六种分类是算出来的，不是背出来的

完整推导特征多项式 → 判别式 → 六类 + 退化自检 + 边界

出发点．A 是 2×2 实矩阵，τ = tr A、Δ = det A。特征值满足 λ² − τλ + Δ = 0。

1判别式定"实还是复"．记 D = τ² − 4Δ。由求根公式，λ = (τ ± √D)/2：
D > 0 → 两个不同的实根；D = 0 → 重根；D < 0 → 一对共轭复根。

2实根情形看两根的符号．由韦达定理 λ₁λ₂ = Δ、λ₁+λ₂ = τ：
· Δ < 0 → 异号 → 鞍点（与 τ 无关）；
· Δ > 0 → 同号，符号由 τ 定：τ < 0 都负（稳定结点），τ > 0 都正（不稳定结点）。

3复根情形看实部．D < 0 时 λ = τ/2 ± i√(4Δ−τ²)/2。实部是 τ/2，虚部非零（所以一定在绕圈）：
· τ < 0 → 稳定焦点；τ > 0 → 不稳定焦点；
· τ = 0 → 中心（纯虚根，见推导 2）。
注意 D < 0 自动保证 Δ > τ²/4 ≥ 0，所以这一支不需要再判 Δ 的符号。

4重根．D = 0 时 λ = τ/2 是二重根。相图还要看 A 能否对角化：A = (τ/2)I → 星结点；否则退化结点（一个特征向量）。

退化自检．① 取简谐振子 A = [[0,1],[−1,0]]：τ = 0、Δ = 1 → 中心 ✓ 与常识一致。② 取 A = [[−1,0],[0,−2]]：τ = −3、Δ = 2、D = 1 > 0 → 稳定结点 ✓（两根 −1、−2）。③ 取 A = [[0,1],[1,0]]：τ = 0、Δ = −1 → 鞍点 ✓（两根 ±1，与"τ = 0 ⇒ 中心"不矛盾，因为要求 Δ > 0）。

边界．① 只对常系数线性系统成立；A 随时间变时要换工具。② D = 0 与 Δ = 0 上，相图由高阶细节决定，判据只剩"看 τ 的符号"。③ 用在非线性线性化上时，必须非双曲才失效：中心这一行是唯一会因高阶项整类改判的格子（第 6 章会给出例子：ẋ = −y + x(x²+y²)、ẏ = x + y(x²+y²)，线性化是中心，真实是发散螺旋）。

§5.2 线性系统的分类
PROOF 02 · 完整推导

中心为什么经不起扰动：守恒量作证

完整推导τ=0 且 Δ>0 ⇒ 存在正定守恒量 ⇒ 闭轨族

要证．设 τ = 0、Δ > 0。则存在正定二次型 H(x) = xᵀMx（M 对称正定），沿 ẋ = Ax 恒有 Ḣ = 0。于是每条轨线都躺在一条闭曲线 H = 常量上——这就是"中心"，而且解释了它为什么脆。

1先用 Cayley–Hamilton．2×2 矩阵满足 A² − τA + ΔI = 0。代入 τ = 0：

A² = −Δ I

也就是说，"做两次"等于"转半圈再缩放 −Δ"——这正是旋转的味道，也是纯虚特征值的代数版本。

2解 Lyapunov 方程．要 Ḣ = xᵀ(AᵀM + MA)x ≡ 0，只需找对称正定的 M 满足

AᵀM + MA = 0

对"伴随形" A = [[0,1],[−Δ,0]]，直接验证 M = diag(Δ, 1) 就是解：
AᵀM = [[0,−Δ],[1,0]]·[[Δ,0],[0,1]] = [[0,−Δ],[Δ,0]]，MA = [[Δ,0],[0,1]]·[[0,1],[−Δ,0]] = [[0,Δ],[−Δ,0]]，相加为零 ✓。
Δ > 0 时 M 正定，H = Δx² + y² 确实是个"碗"。

3结论．H 守恒 ⟹ 轨线被限制在椭圆 H = c 上；又因为 (0,0) 是唯一不动点、轨线不能相交，每条椭圆只能整条地成为一条轨线（闭轨）。一族同心椭圆，就是中心的相图。

退化自检．Δ = 1 时 H = x² + y²，回到简谐振子的机械能（差个 1/2）✓。若 A 不是伴随形而相似于伴随形（A = S[[0,1],[−Δ,0]]S⁻¹），把 M 换成 S⁻ᵀ diag(Δ,1)S⁻¹ 即可，正定性不变。

为什么"脆"．闭轨族是一整个连续集，它的存在完全依赖 Ḣ ≡ 0 这个等式。给矩阵加一点点扰动 τ = ε ≠ 0，则 Ḣ = εH ≠ 0（Δ = 1 时就写成 ε(x²+y²)），H 单调变化，椭圆立刻松开成螺旋。守恒量是个等式，而等式经不起扰动；这就是"中心不双曲、中心不可靠"的确切含义。

边界．① 这条守恒量只对线性系统给出；非线性系统的闭轨通常不是一族（孤立闭轨 = 极限环，第 7 章），那时"中心"与"极限环"必须严格区分。② 二维以上，纯虚特征值不代表存在守恒量（可能有共振）。③ 刘维尔/能量守恒的系统（如无阻尼摆）确实有守恒量，但那是非线性的特例，不能当成通例。
