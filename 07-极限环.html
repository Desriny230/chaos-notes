有些振动，振幅是系统自己定的

线性振子的振幅属于初值：你把它放多高，它就摆多高。
极限环的振幅属于方程：你放多高、多低，最后都落在同一条环上。

THE QUESTION · 一个不该成立的事实

钟表为什么不会停

把摆钟的摆当成钟摆：ẍ + (g/L) sin x = 0。它守恒，所以振幅完全由你放手的位置决定——推得高就摆得高。更要紧的是：只要有一点点摩擦，它迟早停下来。

真实的钟不是这样。摆锤上挂着一个擒纵机构，每半个周期给它补一点能量，被摩擦吃掉的正好补回来。于是不管你从哪儿起摆，最后都收敛到同一个振幅、同一个周期。

问题在相平面上就是一句话：这种「振幅由自己决定」的振动，画出来是什么形状？它不是一个点（没有静止），也不是一族闭合环（那是第 6 章的保守系统中心）。

线性振荡的振幅属于初值，非线性极限环的振幅属于方程。—— 本章要立住的一句话

这一章要回答的四件事

① 极限环和中心的闭轨，画出来几乎一样，凭什么分开？
② 怎么证明一个系统里没有闭轨？
③ 怎么证明一个系统里一定有闭轨？
④ 非线性只是「小扰动」的时候，能不能算一条近似的环？

§7.0 引言
EXAMPLE 7.1.1 · 先把环造出来

极坐标里造一个：ṙ = r(1 − r²)

先不管物理，人工造一个最干净的极限环。用极坐标写方程：

ṙ = r(1 − r²)，　θ̇ = 1，　r ≥ 0

径向和角向解耦了，可以分开看。把 ṙ = r(1 − r²) 当成一条直线上的流——第 2 章的工具直接能用：r* = 0 不稳定（f′(0) = 1 > 0），r* = 1 稳定（f′(1) = −2 < 0）。

回到相平面：所有轨道都以角速度 1 绕原点转，同时半径单调地走向 1。除原点外，任何初值最后都落在单位圆上。这条单位圆就是极限环：它是一条闭合轨道，而且附近没有第二条闭合轨道。

这个例子可贵的地方在于 r 方向是一维的，稳定性一眼可见。但绝大多数系统写不出这样干净的极坐标形式——这正是后面要庞加莱–本迪克松定理、李纳定理的原因。

DEFINITION · 一字之差

极限环是孤立的，中心是成族的

左右两张图，闭轨的「形状」几乎一样，差别在邻居。

谐振子的闭轨是一个连续族：能量是连续可调的参数，每换一个能量就换一条环。你放手高一点，环就大一点，永远不会被吸到别的环上去。

极限环则孤立：把环 Γ 自己挖掉，邻域里没有任何别的闭轨，所有轨道要么螺旋着进来、要么螺旋着出去。所以极限环是「闭轨里的不动点」——它能有稳定性，而中心的环不能。

这个类比在哪里不成立：环上的点本身并不吸引谁（同相位的点不会靠拢）；被吸的是整条轨道——t → ∞ 时轨道的极限集是这条环。它的稳定性还分内、外两侧（可以内稳外不稳，见 §7.1 的稳定性三档）。

§7.1 例子
DEFINITION · 稳定性分档

稳定性有三个档位，不是两个

极限环有内外两侧，所以「稳定」不是一个开关，而是一个三档的量：

稳定环（吸引）

两侧的轨道都螺旋着贴上来。这是唯一能在实验里稳定观测到的一类——范德波尔就是它。

不稳定环（排斥）

两侧的轨道都往外走。它自己看不见，但它常常是「内外两个吸引子之间的分水岭」（第 8 章的亚临界霍普夫分岔就会生出这种环）。

半稳定环（一侧吸、一侧推）

内侧被吸、外侧被推（或反过来）。它像个筛子：环内的轨道被赶到环上，环外的轨道被赶走，两侧的归宿完全不同。极坐标例子 ṙ = r(1−r²)²，在 r = 1 两侧 ṙ 都为正，于是环内往外、环外也往外。

怎么判档？取环上一点，沿法向看向外还是向内，等价于在极坐标里看 ṙ 在 r* 两侧的符号。这件事在极坐标里几乎免费，在一般相图里就要靠数值积分或庞加莱截面（第 8 章）。

两条边界：①「稳定」是局部结论，指环的邻域，不保证全平面都吸过来——吸引域可能被别的不动点或另一个环挡住；②半稳定环是结构不稳定的：参数一动它就会裂成一条稳定环加一条不稳定环，或者干脆消失。

EXAMPLE 7.1.2 · 范德波尔（van der Pol）振子

小振幅时加油门，大振幅时踩刹车

与简谐振子只差一项阻尼，但这一项的符号会变：

ẍ + μ(x² − 1)ẋ + x = 0，　μ ≥ 0

当 |x| < 1 时系数 μ(x²−1) < 0，是负阻尼：能量被灌进来，振幅变大。当 |x| > 1 时系数为正，是普通阻尼：能量被抽走，振幅变小。两条趋势在一个振幅上打平，那里就是极限环。

写成方程组（本章统一用这个形式）：ẋ = y，　ẏ = −x + μ(1 − x²)y

历史上，这个方程与第一代收音机使用的非线性电路有很深的联系；1920—1950 年间非线性振动研究的一大来源，就是无线电与真空电子管技术（原书 §7.4 开头也这样交代）。

它不是「加了一点非线性的振子」，而是一台自己给自己定振幅的机器。—— 用它记住极限环的脾气

CASE · 凡是「没有输入却有稳定节律」的系统

从收音机到心脏：极限环是「自带时钟」的最小模型

电子管振荡器

LC 回路自己会衰减，三极管把直流电源的能量按节律补进去，振幅就稳在一条环上。这是「振荡器」与「谐振器」的分界：谐振器只是挑频率，振荡器自己产生频率。

心脏起搏细胞

窦房结细胞自发去极化，节律稳定。模型层面，这就是一条稳定极限环；起搏器（pacemaker）的作用就是给它「推一把」，把它拉回环上。

神经元的重复放电

Hodgkin–Huxley 类模型在持续刺激下周期性放电，也是稳定极限环。刺激弱时它只回到静息点（不动点），过了阈值才开始周期性放电——这个「阈值」在第 8 章的霍普夫分岔里有正式名字。

边界提醒：把心脏说成「一条极限环」是最小模型。真实心肌是成千上万个耦合振子，会出现螺旋波、碎裂波——那已经超出本章二维相平面的能力（第 8 章 §8.6 会碰到耦合振子）。

§7.2 · 排除闭轨 · 方法一

梯度的流，回不到原高度

若系统是梯度系统：ẋ = −Vx，ẏ = −Vy（V 是某个标量势），则沿任何轨道

V̇ = Vxẋ + Vyẏ = −(Vx² + Vy²) = −|∇V|² ≤ 0

等号只在 ∇V = 0 处成立，也就是不动点。而一条闭轨走一圈必须回到原值 V。单调不增又不许严格下降，只能全程平着——可全程平着就意味着整条环都是不动点。矛盾。

所以：梯度系统没有闭轨。它只有「谷底」和「鞍点」，所有轨道最终滚进某个谷底。

边界：前提是「势真的存在」。范德波尔不是梯度系统——它的阻尼项写不成某个 V 的梯度（二维里「不是梯度」的判据是交叉导数不等：∂f₁/∂y − ∂f₂/∂x = 2 + 2μxy ≠ 0，原点附近等于 2）。找不到势，不等于没有闭轨，只说明这一招用不上。

数值算的等高线（5 个能级）与最速下降轨迹。系统 ẋ=x−x³, ẏ=−y，势 V=x⁴/4−x²/2+y²/2。绿点 (±1, 0) 是稳定结点，橙点 (0, 0) 是鞍点。四条轨迹没有一条能回到出发时的高度。
§7.2 排除闭轨
§7.2 · 排除闭轨 · 方法二

把「势」换成一个只降不升的尺子

梯度系统要求 V 是势（V̇ = −|∇V|² 是配方算出来的）。李雅普诺夫（Liapunov）的想法更宽松：随便找一个函数 V，只要它沿轨道只降不升，就够排除闭轨了。

排除闭轨的李雅普诺夫判据

设 D 是单连通区域，V 在 D 上连续可微。若沿轨道 V̇ ≤ 0，且 V̇ = 0 的点集里不含整条闭轨，则 D 内没有闭轨。

例 1（能量型）。阻尼摆 ẋ = y, ẏ = −sin x − γy（γ > 0），取能量 V = y²/2 + 1 − cos x，得 V̇ = −γy² ≤ 0。

注意这里的 V̇ 不是严格负的：它在整条 y = 0 上为零。「零集上无闭轨」这一条不能省——若有一条闭轨落在 y ≡ 0 里，就得有 ẏ = −sin x ≡ 0，即 x 恒为不动点，不是环。所以判据仍然可用，但必须把这句话说出来。

例 2（构造型）。系统 ẋ = −x(1+y²)，ẏ = −y(1+x²)，这个系统没有势，但有

V = ln(1+x²) + ln(1+y²) ⇒ V̇ = −2x²(1+y²)/(1+x²) − 2y²(1+x²)/(1+y²) < 0

除原点外严格为负。脚本在 41×41 网格上核验：V̇ 的最大值是 −0.0769（出现在最靠近原点的格点上），全负。所以该系统的轨道全都往原点收，不可能有环。

代价：找 V 是手艺活，没有通用配方。绝大多数实际系统里你也找不到——找不到，同样不等于有闭轨。

§7.2 排除闭轨
§7.2 · 排除闭轨 · 方法三

先把方程「吹胖」，再看散度

杜拉克（Dulac）准则：若在单连通区域 D 上存在连续可微函数 g，使得 ∇·(g f) 在 D 内不变号且不恒为零，则 D 内没有闭轨。

为什么？设 Γ 是一条闭轨，围出区域 Ω。对 g f 用散度定理（二维的格林公式）：

∮Γ (g f)·n ds = ∬Ω ∇·(g f) dA

左边：在 Γ 上 f 与切线平行，故 f·n = 0，左边恒为 0。右边：被积函数不变号且不恒为零，故积分严格非零。0 = 非零，矛盾。

例题（原书例题 7.2.5）。证明 ẋ = y, ẏ = −x − y + x² + y² 没有闭轨。取 g = e−2x：

∇·(g ẋ) = ∂x(e−2x y) + ∂y[e−2x(−x−y+x²+y²)] = −2e−2xy + e−2x(−1+2y) = −e−2x < 0

全平面为负，故无闭轨。退化自检：取 g ≡ 1，准则退化为「散度不变号」——这是线性系统第 5 章用过的老结论。但注意：散度不变号只是充分条件，范德波尔的散度是 μ(1−x²)，随 x 变号，它照样有环。

§7.3 · 存在性

证明「一定有一条环」的唯一通用工具

庞加莱–本迪克松（Poincaré–Bendixson）定理

假设：① R 是平面上一个封闭有界子集；② ẋ = f(x) 在包含 R 的开集上是连续可微的向量场；③ R 不含任何不动点；④ 存在一条局限在 R 内的轨道 C（从 R 内出发，并且永远在 R 内运动）。
结论：C 要么本身就是闭轨，要么当 t → ∞ 时盘旋逼近一条闭轨。

四条里最不好验证的是 ④。工程上的做法是把它换成一句更好查的话：让 R 的边界上流一律指向内部。这样任何从 R 内出发的轨道都出不去，条件 ④ 自动满足。

于是「证明有环」变成了一道几何题：造一个环形区域，检查内边界流朝外、外边界流朝里、环带里没有不动点。

诚实提醒：定理只保证至少一条。它不说有几条，不说唯一，也不说稳定。下一节那个例子里恰好唯一，那是对 ṙ 的符号算得干净才有的运气，不是定理给的。

§7.3 · 动手造一个

把 ṙ 算干净，环带就自己站出来

取系统

ẋ = −y + x(1 − x²/4 − y²)
ẏ = x + y(1 − x²/4 − y²)

换极坐标（x = rcos θ, y = rsin θ）算出来很干净：

θ̇ = 1，　ṙ = r(1 − y² − x²/4) = r[1 − r²(sin²θ + cos²θ/4)]

因为 sin²θ + cos²θ/4 ∈ [1/4, 1]：

· 在 r = 0.5 这个圆上：ṙ ≥ 0.5·(3/4) = 0.375 > 0，整条内边界上流都朝外；
· 在 r = 3 这个圆上：ṙ ≤ 3·(1 − 9/4) = −3.75 < 0，整条外边界上流都朝里；
· 环带内没有不动点：这个系统里 θ̇ ≡ 1 ≠ 0，所以 r > 0 处根本不可能有不动点；唯一的不动点是原点 r = 0，它不在环带里。

四条假设齐了，所以环带 0.5 ≤ r ≤ 3 里至少有一条闭轨。而这里我们还能算出它是椭圆 x²/4 + y² = 1。

这个例子是构造出来的：现实里很少能把 ṙ 算得这么干净。算不干净时，要么用李纳定理（下一节），要么只能数值。

§7.3 庞加莱-本迪克松定理
§7.3 · 一个改变全书走向的推论

二维相平面里，没有混沌

把定理的结论读一遍：有界、不含不动点的轨道，最终只能去两个地方——一个不动点，或者一条闭轨。没有第三种去处。

而「混沌」要求的正是第三种去处：轨道永远不重复、也不收敛，被一个复杂几何对象吸住。所以在二维自治系统里，混沌不可能发生。这不是「很难找到」，是定理禁止。

定理的适用边界

① 必须是二维。三维以上失效——多出来的一个维度就够让轨道「永不重复也不收敛」，第 9 章的洛伦兹方程就在三维。
② 必须是自治（右端不显含 t）。受迫系统要先把 t 变成第三个变量，那时已经是三维了。
③ 要求 f 连续可微。

于是全书的路被劈成两半

第 2—8 章（一维流、平面相图、极限环、分岔）属于「没有混沌」的世界：所有轨道都有归宿。
从第 9 章起升到三维，奇怪吸引子才第一次有可能出现。

这就是为什么本章值得花一整节来证明一个「存在性」定理：它不只是给你一条环，它给整个二维世界画了边界。

§7.4 · 李纳（Liénard）系统

不用造俘获区，只核对两个函数的形状

一大类自激振荡器都能写成这个形式（本章后文统一叫李纳系统）：

ẍ + f(x)ẋ + g(x) = 0　⇔　ẋ = y，　ẏ = −g(x) − f(x)y

力学解释：单位质量的物体，受非线性阻尼 −f(x)ẋ 与非线性回复力 −g(x)。范德波尔就是 f = μ(x²−1)、g = x 的特例。

李纳定理（条件 + 结论）

设 f、g 连续可微，g 为奇函数且 x > 0 时 g(x) > 0；f 为偶函数；令 F(x) = ∫₀x f(s)ds，要求 F 在 (0, a) 上为负、在 x = a 处为零，x > a 时为正值且单调不减，x → ∞ 时趋于 +∞。则系统有唯一的稳定极限环，且它环绕原点。

核对范德波尔：f = μ(x²−1) 是偶函数 ✓；g = x 是奇函数且在 x > 0 上为正 ✓；F = μ(x³/3 − x) 在 (0, √3) 上为负、在 x = √3 处为零、x > 1 后单调递增到 +∞ ✓。所以 μ > 0 时范德波尔有唯一稳定环。

脚注：原书 §7.4（p215）条件 (4) 印作「f(−x) = −f(x)（即 f(x) 是一个偶函数）」，公式与括注互相矛盾。此处按「f 为偶函数」取，依据是同页例题 7.4.1 用 f = μ(x²−1)（偶函数）去验证条件 (1)–(4) 满足——若按负号，那个例子根本过不了。

定理值钱的地方：P–B 要你手造俘获区（几何题），李纳定理只要你核对「f 在原点附近为负、远处为正」——物理上就是小振幅加油门、大振幅踩刹车。F(x) 就是累积的阻尼功，F 变号的点 a 标出了「油门」与「刹车」的分界。

边界：定理只说「唯一稳定环存在」，不给它的形状、周期，也不给收敛快慢。要这些数，回到数值或 §7.6 的近似方法。

§7.5 · 松弛振荡（relaxation oscillation）

两个时间尺度，一个环

§7.5 松弛振荡
§7.6 · 弱非线性振子（weakly nonlinear oscillator）

把非线性当小扰动，然后只看慢变量

本节处理这一族方程：

ẍ + x + εh(x, ẋ) = 0，　0 ≤ ε ≪ 1，h 光滑

它代表线性振子 ẍ + x = 0 的小扰动。两个标准例子：

· 范德波尔（弱非线性写法）：ẍ + x + ε(x²−1)ẋ = 0
· 达芬（Duffing）：ẍ + x + εx³ = 0

符号提醒：这里的 ε 和 §7.1 范德波尔方程里的 μ 是同一个物理量，只是原书 §7.6 专门用 ε 强调「它很小」。后文凡写 ε，都指弱非线性强度。

基本想法（Krylov–Bogoliubov 平均法）：ε 小时，解在一个周期内几乎就是 x = r cos(t+φ)；但 r 和 φ 会在很多个周期里慢慢漂移。于是把 r、φ 当成慢变量，把快变量 t 平均掉。

慢变量的变化率是 O(ε)，所以要在 O(1/ε) 个周期之后才看得出来。这既是它好用的原因，也是它失效的边界。
§7.6 弱非线性振子
PROOF 01 · 出发点 → 替换 → 平均 → 退化自检 → 边界

平均法：r 该往哪儿走

完整推导范德波尔方程的振幅方程 ṙ = (ε/2)r(1−r²/4)

出发点．把 ε(x²−1)ẋ 移到右边：

ẍ + x = ε(1 − x²)ẋ

1变量替换．设

x = r(t) cos θ，　ẋ = −r(t) sin θ，　θ = t + φ(t)

这是一次把 (x, ẋ) 换成 (r, θ) 的可逆替换（r > 0 时雅可比为 r ≠ 0，故合法）。注意 r、φ 都随 t 变：不能把 x = r cos θ 直接对 t 求导得 −r sin θ，还要加上 ṙ 和 φ̇ 的贡献。

2第一个方程．把 x = r cos θ 求导，令其等于 −r sin θ：

ṙ cos θ − r sin θ (1 + φ̇) = −r sin θ ⇒ ṙ cos θ = r φ̇ sin θ　(i)

3第二个方程．把 ẋ = −r sin θ 再求导，代入原方程：

−ṙ sin θ − r cos θ (1+φ̇) + r cos θ = −ε r sin θ (1 − r²cos²θ)

把 −r cos θ(1+φ̇) 与 +r cos θ 这两项合并成 −r cos θ · φ̇（常数 1 与 1 相消，只剩 φ̇），再用 (i) 把 φ̇ 代掉（φ̇ = ṙ cosθ/(r sinθ)）：

−ṙ (sin θ + cos²θ / sin θ) = −ε r sin θ (1 − r²cos²θ)

左括号 = 1/sin θ，于是

ṙ = ε r sin²θ (1 − r²cos²θ)，　φ̇ = ε sinθ cosθ (1 − r²cos²θ)

4平均．ε 小，所以在一个周期里 r、φ 几乎不变，把右边对 θ 在 0→2π 上取平均（用 ∫sin²=π、∫sin²cos²=π/4、奇函数积分为 0）：

⟨ṙ⟩ = (εr/2π)(π − r²π/4) = (ε/2) r (1 − r²/4)，　⟨φ̇⟩ = 0

5找不动点、判稳．r* = 0 与 r* = 2。对 ( ε/2)r(1−r²/4) 求导：在 r=0 处为 +ε/2 > 0（不稳定），在 r=2 处为 −ε < 0（稳定）。这就证明了极限环半径 ≈ 2 且稳定。

6解出来．令 u = r²，得 u̇ = εu(1−u/4)，分离变量积分：

r(t) = 2 / √(1 + (4/r₀² − 1) e−εt)

退化自检．令 ε → 0：ṙ = 0、φ̇ = 0，解退化成 x = r₀cos(t+φ₀)——正是线性谐振子，闭轨成族、振幅由初值定。新公式在旧情形下必须回到旧公式，这一步过了。

失效边界．① 被平均掉的量是 O(ε)，误差在 O(1/ε) 时间后累积到 O(1)，所以它只管「前 1/ε 个周期」；② 它对形状没有发言权；③ 它给出的是近似位置，不是存在性证明（存在性要靠 §7.4 李纳定理）；④ 一阶 φ̇ = 0 不等于周期不变——真实频移是 O(ε²)，平均法一阶看不见。

§7.6 弱非线性振子
PROOF 02 · 另一条路，同一个答案

能量平衡：一周期收支相抵，得到 A = 2

完整推导谐波平衡（harmonic balance）——不用极坐标

出发点．沿一条闭轨，能量 E = (ẋ² + x²)/2 走完一周期必须回到原值：

∮ dE = ∮ Ė dt = 0

1算 Ė．范德波尔方程两边乘 ẋ（合法：ẋ 是给定的函数，乘上去不改变解的集合）：

ẋẍ + xẋ = ε(1 − x²)ẋ² ⇒ Ė = ε(1 − x²)ẋ²

这里 Ė 的符号完全由 (1−x²) 决定：|x|<1 时能量涨，|x|>1 时能量跌。「加油门／踩刹车」在这一行里就是显式的。

2一周期的收支．

ε ∮ (1 − x²) ẋ² dt = 0

3谐波假设．猜测环上的解近似为纯正弦 x = A cos t（则 ẋ = −A sin t，周期 2π）。代入：

∫₀2π (1 − A²cos²t) A² sin²t dt = A²·π − A⁴·(π/4) = 0

用的是 ∫sin² = π、∫cos²sin² = π/4。于是 A² = 4，即

A = 2

4交叉验证．平均法给 r* = 2，能量法给 A = 2。两条完全不同的路线落到同一个数上，这是最好的自检。

退化自检．去掉非线性（ε → 0），Ė ≡ 0 恒成立，任何 A 都满足平衡式——方程对振幅没有任何要求，正是「闭轨成族」。新公式确实回到了旧情形。

失效边界．谐波平衡假设了波形是纯正弦，所以：① 精度只有 O(ε)；② 它算不出周期（周期是假设成 2π 的）；③ 对 μ 大的范德波尔，真实波形是锯齿，这时的「2」只是最大值恰好仍在 2 附近（见下页数值），推导本身已经不成立。

为什么还值得学它．因为它把「环在哪里」变成了一句守恒式：一周期内注入的能量 = 抽走的能量。这句话对任何自激振荡器都成立，也是工程上设计振荡器最常用的心算。

§7.6 弱非线性振子
NUMERICAL CHECK · 把解析解和数值解叠起来

平均法能信到什么程度

左 ε = 0.1、右 ε = 0.5，都从 r₀ = 0.3 出发。金虚线是平均法解 r(t) = 2/√(1+(4/r₀²−1)e−εt)（平均法的 r 指 x 的振幅），青色是四阶龙格–库塔算出的 √(x²+ẋ²)。两点要分清：青线比金线整体略高/略低的部分是两种量之间 O(ε) 的系统偏差（√(x²+ẋ²) 只在纯正弦时等于振幅）；线上的毛刺才是 r 在一个周期内的抖动，被平均法抹掉了。

左图（ε = 0.1）：两条线几乎重合，青线只带一层薄毛刺——那是 r 在每个周期内的 O(ε) 抖动，平均法把它抹平了。收敛的时间尺度是 1/ε = 10：图横轴到 6/ε；按公式，4 个 1/ε 时只到 1.5，要将近 6 个 1/ε 才接近 2。

右图（ε = 0.5）：趋势仍然对（单调升到 2），但解析曲线明显偏慢，毛刺厚度约占 2 的 10%。这说明平均法的误差不是「算错了 2 这个数」，而是「算错了走多快、抖多大」。

这也解释了钟表为什么「起振慢」：机械振子的等效 ε 很小，到达稳定振幅需要很多个周期。想让振荡器快点起来，只能把非线性做强——那就进入松弛振荡的地盘了。

§7.6 弱非线性振子
PITFALLS · 反例与边界

五个容易踩的坑

1　数值上「看到」闭合曲线 ≠ 有极限环

分辨率不够时，一圈圈缓慢外扩的螺旋看起来就是闭合的。要确认：积分更长时间看半径是否还在单调变化，或者用庞加莱截面（第 8 章）看穿越点是否收敛到一点。

2　P–B 只给「至少一条」

它不说有几条、不说唯一、不说稳定。ṙ 的符号算得干净时（如 §7.3 那个例子）才有唯一性；一般系统里可以有多条。

3　三条排除法都不是「找不到就说明有」

没有势（不是梯度系统）、找不到 V、找不到 g——都只说明这一招用不上，不说明有闭轨。

4　平均法的精度是「量纲化」的

它只保证 O(ε) 精度、只在 O(1/ε) 时间尺度内有效，而且一阶频移为零时容易误判「周期不变」——真实频移可能是 O(ε²)。

5　极限环 ≠ 一切周期性运动

受迫摆被周期性外力推着转，它的周期来自外部，不是极限环。极限环的定义要求系统自治（右端不显含 t）。受迫系统归第 8 章管。

一句话总结边界

本章所有工具都在二维、自治、f 连续可微这三个前提下成立。出了这个框——三维、受迫、不连续——结论要全部重来。

TAKE AWAY · 三句话

带走三句话

一、极限环是孤立的闭轨。它把邻近的轨道吸进来或推出去；振幅与周期由方程决定，不由初值决定。中心的闭轨成族，振幅由初值决定——这是两者唯一的、也是全部的区别。

二、证明的技巧是一对：要排除闭轨，用势、李雅普诺夫函数或杜拉克函数；要证明存在，用庞加莱–本迪克松（造俘获环带）或李纳定理（核对 f、g 的形状）。两条路都要求二维、自治、光滑。

三、弱非线性时，平均法把二维问题压成一维。一阶结果 ṙ = (ε/2)r(1−r²/4) 给出 r* = 2 且稳定。它便宜、好用，但只对 ε 小、只在前 O(1/ε) 个周期内可信。

回到第 1 页的问题

钟表不会停，因为擒纵机构每半周期补一点能量，把摆按在一条稳定极限环上：推得高就多抽一点，推得低就多补一点，最后总回到同一振幅。

「振幅由系统自己定」这件事，在相平面上就长成一条孤立的闭合曲线——这就是极限环。
