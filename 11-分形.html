§11.0 引言 · 动机

「体积为零」，等于「不存在」吗

第 9 章算过：洛伦兹系统的体积按 e−13.667t 收缩。所以任何吸引子的三维体积都是零。可轨道明明在里面跑个不停——它不可能只是一堆点。

矛盾出在「体积」这个量太粗。用体积给一个薄片量大小，得到的永远是 0；用长度量，又永远是 ∞。需要一个能取中间值的尺子——那就是维数。

思路：换尺子看标度

用边长 ε 的盒子去盖住集合，数需要多少个盒子 N(ε)。
· 一条线段：N ∝ ε−1
· 一块面：N ∝ ε−2
· 康托尔集：N ∝ ε−0.631

指数不是整数，就说明它「介于」线段与面之间。

这一章的两个层次

几何层：康托尔集、康托尔尘、科赫曲线——都是能画出来的规矩图形，维数能算准（§11.2–11.3）。
动力学层：奇怪吸引子——画不出来那么规矩，只能靠盒计数与关联维数去量（§11.4–11.5）。

一句提醒：这一章的「维数」有好几种（自相似维数、盒维数、关联维数、点态维数）。它们对规矩图形给出同一个数，对奇怪吸引子会略有差别——差别本身就是信息。

§11.1 可数与不可数
§11.1 · 可数与不可数

「点很多」有两个意思，别混

康托尔集的总长度是零（§11.2 会算）。那它是不是只剩几个点？不是。它和整条线段的点一样多——都是不可数的。

两个概念要分开：

基数（有多少个点）

能与自然数一一对应的叫可数；否则叫不可数。整数、有理数都是可数的；实数区间不可数。康托尔集虽然「删掉了那么多」，剩下的点仍然可以跟 [0,1] 一一对应（§11.2 用三进制给出这个对应）。

测度（占多长）

长度、面积、体积这类「量」。康托尔集的长度是 0。「长度为 0」与「点很少」是两件事：它点极多（不可数），却一个长度都不占。

这正是分形麻烦的地方：常规的「长度/面积」在这类集合上失效——要么是 0，要么是 ∞，没有中间值。维数就是补这个空的那个量。

类比与它的失效处：可以把维数想成「放大看有多密」；但别把它想成「长得像几维」——一条康托尔尘看起来像一片雾，维数却只有 0.63。另一个常见误解是「不可数就一定占长度」：有理数在 [0,1] 里稠密（任何小区间都有无穷多个），却可数、总长度为零；康托尔集不可数，长度也是零。稠密、可数、测度、维数，是四把不同的尺子。

§11.1 可数与不可数
数值生成的前六级：第 n 级剩 2ⁿ 段，每段长 3−n，总长 (2/3)ⁿ。n 增大时总长趋于 0，但段数指数增长——两个趋势打架，最后的集合就是「点多、长度为零」。
§11.2 · 康托尔集

删掉中间三分之一，一直删下去

从区间 [0, 1] 开始：
· 第一步删掉中间 1/3，剩 [0, 1/3] 与 [2/3, 1]；
· 第二步各删中间 1/3，剩 4 段；
· 第 n 步剩 2ⁿ 段，每段长 3−n。

总长度：Ln = 2ⁿ·3−n = (2/3)ⁿ → 0。所以极限集合的长度为零。

可它不是空的：每一步保留下来的端点全都在里面（比如 0、1、1/3、2/3 ……），而且还有无穷多非端点。剩下的集合记作 C，就是康托尔集。

为什么值得从它开始：它是「自相似」最简单、也最容易算准的例子。它的维数能一行算出来，而算法对奇怪吸引子同样适用。

§11.2 康托尔集
§11.2 · 三进制

康托尔集＝三进制里没有数字 1 的点

把 [0, 1] 里的数写成三进制 0.a₁a₂a₃…（每个 ai ∈ {0, 1, 2}）。第一步删掉中间 1/3，删掉的正是第一位是 1的所有数；第二步删掉第二位是 1 的数；依此类推。

所以：C = {0.a₁a₂… (三进制) : 每个 ai ∈ {0, 2}}。

为什么它不可数：每个 0/2 序列都对应 C 里一个点，而这样的序列与 [0,1] 的二进制序列一一对应。用对角线法可以证明：任何可数清单都漏掉某个点（把第 n 个点的第 n 位改成另一个值即可）。所以 C 与 [0,1] 等势——点一样多。

一个小陷阱：端点 1/3 = 0.1000…（三进制）里有数字 1，可它在 C 里。并不会矛盾——同一个数可以有两种展开，写成 0.0222… 就没有 1 了。这类「双重表示」的端点在处理分形时经常要单独小心（本章不是重点，但写代码时会撞上）。

这两段合起来的结论很反直觉：长度为零的集合，可以和整个区间一样多。「多少」这件事，看你用哪把尺子量。

§11.2 康托尔集
§11.2 · 推广

把「删中间」搬到正方形里

康托尔集是把一维线段的中间删掉。把同样的动作搬到正方形里：分成 3×3 = 9 个小格，删掉中间那个（以及四条边上的中间格？）——常见的两种做法：

· 只留四个角格 → 4 份、每份 1/3 大 ⇒ D = ln4/ln3 = 1.2619（这叫康托尔尘）；
· 删掉中心那一个格 → 8 份、每份 1/3 大 ⇒ D = ln8/ln3 = 1.8928（这是谢尔宾斯基地毯的开头一步）。

再往上一维：立方体分 27 格、只留 8 个角 ⇒ D = ln8/ln3 = 1.8928——和上面地毯同一个数，因为「份数与缩小比」相同。维数只由这两个数决定，与你在几维空间里画它无关。

为什么这件事重要

它说明：维数不是「外部空间给的」，而是集合自己长出来的。一个住在三维里的集合，维数可以是 1.89、也可以是 0.63。所以第 9 章那个「体积为零的吸引子」并不奇怪——它只是一个维数约 2 的集合被塞进了三维空间。

术语提醒：「康托尔集」（一维，删中间三分之一）、「康托尔尘」（二维四角版）常被混着叫；报维数时请把 m 与 r 写出来，最不容易出错。

§11.3 · 自相似分形的维数

一份变几份，就能算出维数

若一个集合由 m 个一模一样的缩小副本拼成，每个副本是原来的 1/r 倍（r > 1），就称它自相似。这时维数由一条「守恒式」给定：

m · (1/r)D = 1　⇒　D = ln m / ln r

直觉：总「容量」按 (1/r)D 缩水，一共 m 份，缩完正好拼回原来的大小，所以乘积必须是 1。

验证一下这条式子在熟悉的对象上是对的：

· 线段：m = 2、r = 2 ⇒ D = ln2/ln2 = 1 ✓
· 正方形：切成 4 份、每份 1/2 ⇒ D = ln4/ln2 = 2 ✓
· 立方体：8 份、1/2 ⇒ D = 3 ✓

退化自检过了：对一切整数维的对象，公式给回整数。所以它不是新发明，而是「维数」这个概念的推广。

三个经典例子（本章数值生成）

· 康托尔集：2 份、1/3 大
　D = ln2/ln3 = 0.6309
· 科赫曲线：4 份、1/3 大
　D = ln4/ln3 = 1.2619
· 谢尔宾斯基三角形：3 份、1/2 大
　D = ln3/ln2 = 1.5850

三个都不是整数。这就是「分形」这个词的数学含义：维数是分数的集合。

§11.3 自相似分形的维数
三个自相似集合（都由脚本数值生成，不是手绘示意图）：左边康托尔集第 3 级，中间科赫曲线第 3 级，右边谢尔宾斯基三角形第 3 级。三者的维数分别是 0.631、1.262、1.585——从「比线还少」到「比线多、比面少」。

把这三种「分数维」放在一条尺子上看就明白了：

0（一个点）→ 0.63 康托尔集 → 1（线）→ 1.26 科赫曲线 → 1.58 谢尔宾斯基 → 2（面）

读法：维数在 1 与 2 之间的集合，「比线更占地方，但还没铺满一个面」。这在老几何里是矛盾的——正因为如此，Mandelbrot 才给它们起了「分形」这个名字（维数不是整数）。名字是描述，不是定义：严格的判据仍然是维数。

§11.3 自相似分形的维数
§11.4 · 盒维数

画不出自相似，也能量

对康托尔集这种规矩图形，「几份、多小」一眼可见。可奇怪吸引子根本没这么规矩，你怎么说它「由 m 份组成」？盒计数把公式换成一句能执行的话：

用边长 ε 的盒子（网格）盖住集合，数出至少含一个点的盒子个数 N(ε)；若

N(ε) ∝ ε−D（ε → 0）

则指数 D 就是盒维数：D = −limε→0 ln N(ε) / ln ε。

实操就是画一张 log N 对 log(1/ε) 的图，取直线的斜率。本章脚本对康托尔集（第 14 级，16384 段）取 ε = 3−k、k = 1…9，测得的斜率是 0.630930，与 ln2/ln3 = 0.630930 相同（四舍五入到四位是 0.6309）。这不是巧合：对自相似集，盒计数与自相似维数必然相等（推导见本章最后一篇）。

为什么取 ε = 3−k：因为康托尔集在 1/3 的整数次幂尺度上最「规整」，其它 ε 会看到台阶状的涨落。这一条在选择尺度时很重要——选错尺度，直线就不直。

§11.4 盒维数
左：康托尔集的盒计数（9 个尺度，斜率 0.6309 = ln2/ln3）。右：洛伦兹吸引子的关联维数（3000 个点、7 个尺度 r，斜率 D₂ ≈ 2.02）。两张图都是 log-log，直线斜率就是维数。

右图说明的是另一件事：奇怪吸引子没有「份数」可数，但它有点对。C(r) 定义为「随机取两点、距离小于 r 的概率」，若它也按幂律走，斜率就是关联维数 D₂（§11.5）。

这两个数不必相等：对洛伦兹吸引子，本章用 3000 点测 D₂ = 2.02；用 12 万点做三维盒计数测到 1.81。理论上只有 D₂ ≤ D₀ 这条不等式，没有等号；这 0.2 的差距里既有这条不等式，也有有限采样偏差——盒计数在稀疏区域要被很多点才统计到，点数不够就偏低。下一页专门讲这件事。

这也解释了为什么做维数要「报参数」：点数、尺度范围、拟合区间换一下，第三位小数就会变。审稿人问维数时，先问这三个。

为什么「直线」这件事本身就值得一说：双对数下是直线，等价于 N(ε) ∝ ε−D 对所有尺度都成立——也就是没有特征尺度。这正是分形与「一般的粗糙物体」的分界：一块石头有颗粒尺度，放大到那里直线就断了；康托尔集在任何一级放大都长一个样，直线一直延下去。所以「无标度」比「自相似」更接近本质，也更适合用标度指数（维数）来描述。

§11.4 盒维数
§11.4 · 实操

直线不直的时候，别硬拟合

坑一：点数不够

盖住 N 个盒子至少要 N 个点。若点数与盒子数同量级，N(ε) 会被「点的个数」卡住，斜率被拉低——本章洛伦兹三维盒计数 1.81 就是这么来的（点不够）。

坑二：尺度范围太窄

吸引子的特征尺度只有一两个量级，很难画出「长直线」。至少要跨越 1.5 个量级，斜率才稳定。

坑三：均匀 ≠ 非均匀

盒计数只看「有没有点」，不看「有多少点」。所以它对非均匀分布不敏感；要抓非均匀，得用点态维数或关联维数（§11.5）。

本章的实测数字（可复算）

康托尔箱计数（16384 段）
　ε=1/3 … 1/3⁹　斜率 0.6309

洛伦兹三维盒计数（12 万点）
　ε=5 … 0.5　N：190 → 12171
　斜率 1.81

洛伦兹关联维数（3000 点）
　r=1.5 … 10　斜率 2.02

两个洛伦兹的数差 0.2：前者是几何量（数盒子），后者是测度量（数点对）。对非均匀吸引子，它们本来就可以不同。

§11.4 盒维数
§11.4 · 实操细节

网格往哪儿摆，会改变第三位小数

盒计数看起来无懈可击，但有一个隐蔽的自由度：网格的原点放在哪儿。同一集合，同一 ε，网格平移半个盒子，占用的盒子数就可能变——尤其在点数不多、边缘稀疏的时候。

怎么减小这个偏差

① 用多个网格偏移各算一次再平均（代价是 ε 次计算）；
② 优先选与集合「同构」的尺度（康托尔集用 ε = 3−k，本章就是这么做的）；
③ 拟合时丢掉最小的一段（点数不够）与最大的一段（整体形状主导）。

对连续吸引子还要更小心

真实吸引子是连续集，你手上只有离散采样点。「盒子里有点」的判据在稀疏区会被点数卡住：明明集合经过，可样本里恰好没有点。这就是本章洛伦兹盒计数偏低（1.81）的主要来源。

一个可操作的判断：把点数加倍重算一次。如果维数明显升高，说明之前被点数卡住了；如果基本不变，那次测量才可信。这一招比任何拟合优度都实在。

与 §11.5 的关系：关联维数对网格完全不敏感（它只用点对距离），所以在点数有限时往往更可靠——这也是它成为工程首选的原因。

§11.4 盒维数
§11.3 · 迭代函数系统（IFS）

把「自相似」写成一组映射

上一页的「m 份副本」可以写成数学：给一组压缩映射 S₁, …, SK（每个都把距离缩小 r 倍以内），它们的不变集 A 满足

A = S₁(A) ∪ S₂(A) ∪ … ∪ SK(A)

这样的 A 唯一存在（压缩映射定理的直接推论：在「紧集」这个空间上，集合算子也是压缩的）。这就是迭代函数系统（iterated function system, IFS）。

如果所有 Si 的缩小比都是 1/r，那么 A 的维数就是 D = ln K/ln r。演示 02 的「混沌游戏」正是它的随机算法：随便从哪儿出发，反复「随机挑一个 Si 应用一次」，点会自动落进 A 并铺满它——不需要知道 A 长什么样。

两个必须带上的条件

① 开集条件：副本之间不能重叠得太厉害，否则 D = ln K/ln r 会高估（重叠部分的盒子只算一次）。
② 概率要单独给：混沌游戏里「挑哪个 Si」的概率 pi 不影响集合 A，却决定点在 A 上怎么分布——也就是决定 D₂ 与点态维数的分布。

最后这一点很重要：集合与测度是两件事。同一个谢尔宾斯基三角，换个概率分布，D₀ 不变、D₂ 却会变。第 12 章的重构只保证「集合对」，不保证「密度对」。

§11.3 自相似分形的维数
洛伦兹吸引子上 200 个采样点的局部标度指数 α（用 r = 2 与 r = 6 两个尺度估计）。中位数 1.95，范围 1.52–3.25。分布有宽度——这就是「非均匀」的直接证据。
§11.5 · 点态维数

同一个吸引子，各处的局部维数不同

盒维数给整个集合一个数，像是假设集合「处处一样密」。奇怪吸引子不是这样：有些区域轨道反复经过（密集），有些很少光顾（稀疏）。

于是定义点态维数：盯住集合上的一个点 x，数以它为圆心、半径 r 的球里有多少点 Nx(r)，若

Nx(r) ∝ rα(x)（r → 0）

则 α(x) 就是这一点处的局部维数。它随 x 变化，于是整个集合的「维数」其实是一个分布，不是一个数。

本章的做法（两尺度估计）：α ≈ ln[Nx(6)/Nx(2)] / ln(6/2)。200 个点算下来，中位数 1.95，但两端的点能到 1.5 或 3 以上。平均值≈D₂，但每一点的局部行为差很多。

§11.5 点态维数与关联维数
§11.5 · 关联维数（Grassberger–Procaccia）

不去管局部，直接数「近邻对」

点态维数要一个点一个点地估计，噪声大、计算贵。Grassberger 与 Procaccia 的办法聪明得多：把所有点对的距离都数一遍。

C(r) = (2/[N(N−1)]) · #{ i<j : |xi − xj| < r }

C(r) 就是「随机取两点、距离小于 r」的概率。若它按幂律走，斜率就是关联维数 D₂ = lim ln C(r)/ln r。

本章：3000 个洛伦兹点、7 个尺度（r = 1.5 … 10）得到 D₂ ≈ 2.02；只用两两距离，不需要网格，所以对网格偏移免疫。

关系：一般有 D₂ ≤ D₁ ≤ D₀。等号意味着分布足够均匀；洛伦兹的 2.02（D₂）与 1.81（D₀）就是不等号的有限采样版本（见前一页的说明）。

ln C(r) 对 ln r（3000 个点、7 个尺度）。金虚线是斜率 D₂ ≈ 2.02 的直线。纵轴从下往上增加，横轴从左往右增加——两个方向都取了对数，所以直线 = 幂律。
§11.5 点态维数与关联维数
§11.5 · 进阶：维数谱

一个数不够，就画一条曲线

上一页的直方图说明：点态维数 α 是个分布。那就把这个分布完整地记下来——对每个 α，问「局部维数等于 α 的那部分点，本身占多少维」？把这个「部分维数」叫做 f(α)，得到的曲线叫维数谱（多重分形的标准语言）。

几个可对照的极端

· 分布完全均匀（比如 r = 4 的逻辑斯谛映射）：所有点 α 相同，f(α) 塌缩成一个点，f 的峰值就是 D₀。
· 分布极不均匀（如洛伦兹、埃农）：曲线展开成拱形，峰值 = D₀，曲线越宽说明越「多标度」。

怎么读它

曲线的位置告诉你维数多大；曲线的宽度告诉你分布有多不均匀。只看 D₀ 时，这两样信息被压成了一个数——这就是为什么研究混沌的人常报整条曲线。

本章不做 f(α) 的数值：3000 个点远不够稳定地估计它（要先按 α 分层、再各层数盒子，点数需求是平方级的）。这里把它写出来，目的只有一个——让你知道「吸引子的维数」这件事在进阶层面长什么样，不至于把 D₀ 当成全部真相。

边界：维数谱的定义依赖「分层数盒子」的极限，对有限点集只能做近似；不同的估计方法（盒计数、关联、点态）给不同的近似曲线，互相不能直接套算。

§11.3 自相似分形的维数
PROOF 01 · 出发点 → 标度 → 解出 D → 自检 → 边界

为什么 D = ln m / ln r

完整推导从「盒子数随尺度怎么变」推出公式，并用康托尔集验算

出发点．用边长 ε 的盒子覆盖集合，N(ε) 为占用的盒子数。维数的定义式：N(ε) ∝ ε−D。

1自相似意味着什么．设集合由 m 个副本组成、每个副本是整体的 1/r 倍。用 ε 的盒子量整体，等价于用 ε·r 的盒子量每个副本（因为放大 r 倍后副本就成了整体）。所以

N(ε) = m · N(ε r)

合法性：这一步要求副本之间「不重叠到有体积共享」的程度（严格说要求开集条件），否则盒子会被两个副本共用，计数偏小。

2代定义式．设 N(ε) = A ε−D，代入第 1 步：

A ε−D = m · A (ε r)−D = m A ε−D r−D　⇒　1 = m r−D

即 m (1/r)D = 1，两边取对数：

D = ln m / ln r

3用康托尔集验算．m = 2（左右两半），r = 3（每半是整体的 1/3）：D = ln2/ln3 = 0.63093。本章盒计数实测 0.6309 ✓

4退化自检．线段：m = 2, r = 2 ⇒ D = 1 ✓；正方体：m = 8, r = 2 ⇒ D = 3 ✓；单个点：m = 1 ⇒ D = 0 ✓（一个点量不出任何长度）。对一切整数维对象，公式都回到整数——这是它可信的最硬证据。

失效边界．① 要求「严格自相似」：自然界的分形（海岸线、云）只是统计自相似，只能谈「在一定尺度范围内近似」。② 若副本之间有重叠（比如某些 IFS 里多个映射的像相交），公式要给「开集条件」才成立，否则要改用盒维数直接量。③ 这条公式不给点态信息：它只说整体，不说哪部分更密。

§11.3 自相似分形的维数
PROOF 02 · 两种定义的一致性

「几份」与「数盒子」为什么给出同一个数

完整推导先用 ε 与 ε·r 两档夹住 N(ε)，再取对数极限

出发点．自相似集 C = ⋃i=1m Si(C)，每个 Si 是缩小 1/r 的相似变换。

1上界．每个副本 Si(C) 是整体的 1/r 倍；用边长 ε 的盒子盖它，等价于用边长 ε·r 的盒子盖整体（把副本放大 r 倍就变回整体，ε 也跟着放大 r 倍）。所以每个副本至多要 N(ε·r) 个盒子，m 个副本合计给出一个覆盖：

N(ε) ≤ m · N(ε r)

2下界（副本分离）．另一头：自相似集的两个副本之间有一道最小间隙 δ0。取 ε < δ0，则任何一个 ε-盒最多只与一个副本相交，于是总数至少等于「分别覆盖每个副本」所需之和：

N(ε) ≥ m · N(ε r)

为什么是「下界」：每个副本至少要 N(ε·r) 个盒子才盖得住；而 ε < δ0 时盒子不能跨副本共用，所以总数不可能更少。代入康托尔核对：ε = 1/9 时 N = 4，右边 = 2·N(1/3) = 2·2 = 4 ✓。

3夹住并取对数．把第 1 步的上界与第 2 步的下界合起来：

m · N(ε r) ≤ N(ε) ≤ m · N(ε r)　⇒　N(ε) = m · N(ε r)

（严格说是相差一个 (1+o(1)) 因子。）迭代 n 次得 N(ε) ≈ mnN(ε rn)。取 ε rn = 1（即 n = ln(1/ε)/ln r）、令 n → ∞，常数项被 ln(1/ε) 除没，即得

Dbox = ln m / ln r

注意：单靠上界迭代夹不出这个结果（只会给出 −ln(Km)/ln r 这样的负数）；真正把它夹住的是「副本分离」这条下界。这也是为什么开集条件必须成立——它保证副本之间确实留有间隙。

4退化自检．取 m = rd（普通 d 维方块）：D = ln(rd)/ln r = d ✓。取 m = 1（一个副本，即无自相似结构）：D = 0 ✓（一个点）。

失效边界．① 上界在副本轻微重叠时仍成立（只是常数变差）；真正脆弱的是下界——副本一重叠，一个 ε-盒就能同时统计两个副本，N(ε) ≥ mN(ε r) 不成立，两边的夹子松开，两个维数就可能不同。这就是「开集条件」非要求不可的原因。② 这个论证只给「盒维数 = 自相似维数」，不能推出关联维数：后者看的是测度（点怎么分布），不是集合本身。所以对非均匀吸引子，D₂ 与 D₀ 本来就不必相等（本章洛伦兹：D₂ ≈ 2.02、D₀ ≈ 1.81）。

§11.4 盒维数
PITFALLS · 反例与边界

五个容易踩的坑

1　把维数当成「长得像几维」

康托尔尘画出来像一片雾，维数 0.63；谢尔宾斯基三角有无数个洞，维数 1.58。维数是标度关系，不是形状描述。

2　拿整数维的尺子硬套

用长度量康托尔集得 0，用面积量得 0，用「点数」量得无穷。这些都不矛盾——只是那把尺子不适合。

3　在错误的尺度上拟合

盒计数的直线只在某个区间里直。把小 ε 端（点数不够）或大 ε 端（整体形状主导）算进去，斜率会系统性偏小。

4　以为一个数就够

D₀（盒）、D₁（信息）、D₂（关联）一般不同。报「洛伦兹吸引子的维数是 2」时要说明是哪一个、怎么测的。

5　把嵌入维数当吸引子维数

你把三维数据画在二维纸上，量到的是「投影」的维数。第 12 章会用延迟嵌入说明：只要嵌入维数足够高，重构出来的吸引子维数才和原来一致。

一句话总结边界

维数是在给定尺度范围内测出来的一个数。这一章所有数字都带着「点数 / 尺度 / 拟合区间」三个前提，报数时必须一起报。

TAKE AWAY · 三句话

带走三句话

一、维数是「标度关系」，不是「坐标轴个数」。N(ε) ∝ ε−D 定义了一切：直线给 1、面给 2、康托尔集给 0.6309。整数维只是它的特例。

二、自相似集能用公式算，奇怪吸引子只能量。规矩图形用 D = ln m/ln r（本章验算：康托尔 0.6309、科赫 1.2619、谢尔宾斯基 1.5850）；吸引子用盒计数或关联维数（洛伦兹：D₂ ≈ 2.02）。

三、报维数必须带前提。点数、尺度范围、拟合区间、以及是哪一个维数——换一个，第三位小数就变。洛伦兹的 1.81（盒，12 万点）与 2.02（关联，3000 点）就是活例子。做实验的人问「维数是多少」，等价于问「你在什么尺度上、用什么尺子量的」。

回到本章开头的问题

「体积为零」为什么不是「不存在」？

因为体积这把尺子在这个集合上失效。换个尺子（数盒子）就得到 2.02 这个中间值——它既不是三维、也不是二维，所以它「存在，但很薄」。
